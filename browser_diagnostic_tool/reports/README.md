# Browser Diagnostic Reports

This directory stores report templates and examples for the standalone browser diagnostic tool.

Generated reports are written to:

`%LOCALAPPDATA%\WeMediaBaby\debug\browser_diagnostics\<platform>\<YYYYMMDD>\<test_run_id>\`

Standard files:

- `snapshots.json`
- `launch_context.json`
- `behavior_trace.json`
- `comparison_report.json`
- `comparison_report.html`
