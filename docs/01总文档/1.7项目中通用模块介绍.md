## 一、作品简介与话题（作品描述）

### 1. 作品简介话题解析

**作用**：在用户输入或粘贴的**作品简介**文字中，按统一规则识别 `#话题` 标签（例如多个话题、话题与正文混排、相邻话题、末尾标点等），供写库、统计标签、与平台侧话题字段对齐。

**典型能力**：

- 从整段简介中解析出话题列表（去重、顺序与界面展示一致）。
- 粘贴长文案时，对话题格式做规范化（例如话题之间补空格），减少从外部平台复制来的格式不统一问题。

**主要使用场景**：

- **单个视频 / 单个图文**任务创建页：保存任务时根据简介解析话题；与简介输入框展示逻辑一致。
- **批量视频**任务：生成待发布任务、统一描述配置、文案库匹配结果合并时，用同一套规则解析话题，避免「单条页和批量页数出来不一样」。
- **批量图文**（功能扩展时）：可直接沿用同一解析规则，无需再维护一套逻辑。

### 2. 作品简介编辑体验（界面侧）

**作用**：在简介输入框上提供一致的体验——字数提示、`#话题` 在输入框内的醒目显示、按空格确认话题后的刷新、粘贴后的自动整理等。

**主要使用场景**：

- 单个视频 / 单个图文任务创建页中的简介区域。
- 批量发布里「配置描述」弹窗中的统一简介输入区域。

## 二、配置与用户数据路径

### 1. 配置中心

**作用**：集中读写应用配置（如界面选项、批量发布偏好、媒体库路径等），支持本地持久化；在需要时还可与文件变更监听等能力配合，保证多处在读写的是同一份配置语义。

**主要使用场景**：主程序启动注册、设置页、各业务页保存/恢复勾选与偏好、媒体库根目录、浏览器相关选项、部分平台插件读取默认行为等。

### 2. 配置合并与默认值

**作用**：升级或新增配置项时，用「默认值骨架」补全用户旧配置文件里缺失的键，避免缺字段导致异常；合并写入时保持结构一致。

**主要使用场景**：任意写入应用配置的流程（含批量描述、声明原创等偏好持久化）。

### 3. 路径管理

**作用**：统一解析「数据目录、配置目录、用户可写目录」等，避免安装目录与工作目录混淆（尤其打包安装后）。

**主要使用场景**：配置中心落盘位置、浏览器用户数据目录、各平台发布步骤中涉及本地文件路径、诊断工具读取安装内资源等。

### 4. 安装包内置配置（平台包）

**作用**：从安装包内携带的只读资源中读取各发布平台所需的静态说明或清单（与可写的用户配置区分）。

**主要使用场景**：各平台「发布插件」加载自身说明或内置清单；部分服务读取捆绑元数据。

## 三、依赖注入、事件与发布流水线

### 1. 服务定位器（依赖注入）

**作用**：在程序内约定「单例式服务」的获取方式（如配置中心、缓存、部分业务服务），便于主窗口、页面、后台任务使用同一套实例。

**主要使用场景**：主窗口初始化、账号与发布相关页面、发布执行器、浏览器工厂等需要拿全局服务的地方。

### 2. 事件总线

**作用**：模块之间用「事件」松耦合通知（例如发布开始、结束、失败、全局提示等），发送方不必知道具体谁在监听。

**主要使用场景**：主窗口订阅发布类事件做提示或刷新；账号列表等页面响应业务事件。

### 3. 发布流水线（过滤器链）

**作用**：把一次「执行发布」拆成多阶段上下文，便于在统一骨架上扩展校验、执行、结果汇总等步骤。

**主要使用场景**：发布执行器驱动各平台实际发布流程。

## 四、媒体库与素材分配

### 1. 媒体库管理

**作用**：根据用户在设置里配置的媒体库根路径，解析「媒小宝媒体库」等标准子目录结构，为视频库、图片库、自动匹配素材等提供统一入口。

**主要使用场景**：设置页展示与保存媒体库路径；批量任务页的自动匹配视频；素材自动匹配服务按账号/账号组取本地文件。

### 2. 媒体库内分配策略（多账号 / 多目录）

**作用**：在媒体库场景下，把一批素材按策略分到多个「目标」（例如多个账号目录），用于素材归档或均衡分配类产品能力。

**主要使用场景**：视频库、图片库页面中的分配相关操作。

### 3. 批量任务中的素材取用策略

**作用**：与批量预览行生成配合，按「顺序 / 随机 / 循环」等策略从各账号独立池或共享池中取视频（及未来图文），并遵守「同一素材在同一轮不重复占用」等业务规则。

**主要使用场景**：批量视频任务创建页、素材自动匹配服务。

### 4. 跨列表的分配算法（通用数学层）

**作用**：将「若干物品」按选定策略分到「若干目标」，供批量任务里「时间 × 账号」等组合场景复用（与是否视频无关）。

**主要使用场景**：批量任务创建、预览与发布任务构建相关逻辑。

## 五、文案库（常规与随机）与作品编号

### 1. 文案库作品编号规则

**作用**：从文件名等来源识别「文案库条目」对应的作品编号格式（符合规则才参与和文案库自动匹配），避免误匹配。

**主要使用场景**：批量任务根据视频文件名匹配文案库；文案辅助逻辑。

### 2. Excel 导入文案

**作用**：将表格文件中的多行数据导入为文案库条目，供批量「自动匹配作品描述」等使用。

**主要使用场景**：文案库管理页面。

### 3. 批量文案辅助（标题 / 简介合并）

**作用**：在「统一填写标题简介」与「从文案库带出」同时存在时，按勾选组合成最终每条任务的标题和简介；话题解析已统一到「作品简介话题解析」模块，保证批量写库与单页一致。

**主要使用场景**：批量描述弹窗、批量生成任务时的字段合并。

### 4. 随机文案库系统

**作用**：支持按分类标签独立管理大规模的「随机短句/语料」，包含分类创建、重命名及数量实时同步。在最终拼装作品简介时，可按指定策略随机抽取该库内文案，极大地提升批量发布时文案的差异性。

**主要使用场景**：随机文案库管理页面、自动匹配与发布任务构建环节的话题补充。

## 六、发布后文件与其它通用能力

### 1. 发布后本地文件处理

**作用**：在发布流程结束后，按产品策略处理本地视频/封面等文件（例如移动、归档、清理临时项——具体策略以当前版本实现为准），避免成功发布后本地目录混乱。

**主要使用场景**：发布列表页在执行完成后的收尾逻辑。

### 2. 缓存管理（通用）

**作用**：为需要短期复用计算结果或列表数据的场景提供统一缓存入口。例如工作台页面的媒体库统计数据（通过 `media_library_stats_cache` 提供全局一致性读取），避免不同页面重复扫描磁盘。

**主要使用场景**：设置页、工作台概览页等与性能或重复请求相关的优化点。

### 3. 安全与权限（加密、角色能力）

**作用**：敏感信息加解密、基于角色的能力判断等横切能力，供登录、存储、部分 Pro 能力开关等使用。

**主要使用场景**：账号与会员相关流程、安全相关存储（随版本迭代可能扩展）。

### 4. 账号标签与分组系统

**作用**：在平台和账号维度提供灵活的「自定义标签」绑定和独立分组能力。支撑界面的排他（单选）或多选过滤交互，便于在海量账号池中实现精准圈选与规范化展示（例如未分类空值归一化显示）。

**主要使用场景**：账号管理列表页、批量发布配置前的账号选择面板等。

### 5. 数据采集与工作台统计

**作用**：统一汇总发布日志、状态与成功率数量，计算出「发布成功率」、「发布趋势」等核心指标，并进行数据同步与可视化呈现。针对跨线程事件（如后台任务发送的更新事件），统一通过 `QTimer.singleShot` 桥接回 UI 主线程，保障界面渲染的线程安全性与无阻塞。

**主要使用场景**：系统主界面（工作台 Workspace/Dashboard 页面）的看板更新。

## 七、界面公共组件（可复用界面块）

以下均为「多处页面复用的界面能力」，只列功能，不列实现方式。

| 模块能力 | 功能简述 | 典型出现位置 |
|----------|----------|----------------|
| 应用内统一弹窗基底 | 统一弹窗样式、按钮顺序、快捷键（如 Esc）行为 | 登录/注册、设置、账号与分组、批量各类配置弹窗、素材与发布相关对话框等 |
| 行选择表格 | 支持按行选择、橡皮筋框选等，适合大批量勾选 | 批量任务预览表、发布记录与回收站、视频库/文案库表格、账号列表等 |
| 右键菜单增强 | 与 Fluent 风格菜单配合的关闭、定位等行为 | 发布记录、批量预览、视频库等带右键菜单的表格 |
| 发布列表信息卡片 | 将单次发布任务拆成「概览 / 文案与描述 / 发布设置 / 日志」等区块展示 | 发布列表页执行发布时的详情区域 |
| 日志展示块 | 展示发布过程日志 | 发布列表页 |
| 视频预览块 | 任务创建或详情中的本地视频预览 | 单个任务创建页等 |
| 统计与骨架屏 | 数据未加载时的占位与简单统计展示 | 账号库等列表页 |
| 主窗口状态栏 | 底部简短状态或提示 | 主窗口 |
| 标签过滤器/气泡 | 提供点击切换单选、取消等交互反馈的标签展示组件 | 账号列表等需按分类筛选的页面 |
