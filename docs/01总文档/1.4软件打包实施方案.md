## 1. 方案概述

本项目采用 **双轨制打包策略**，以平衡开发效率与发布质量：

| 阶段       | 适用场景                    | 核心工具                         | 特点                                                     | 产物路径                 |
| :--------- | :-------------------------- | :------------------------------- | :------------------------------------------------------- | :----------------------- |
| **迭代期** | 内部测试、快速验证、QA 回归 | **PyInstaller** + **Inno Setup** | 🚀 极速构建 (<2分钟) ‧ 📦 调试友好 ‧ 🔓 代码无混淆       | `dist/fast/WeMediaBaby/` |
| **发布期** | 正式发版、交付客户          | **Nuitka** + **Inno Setup**      | 🛡️ 高安全 (转C++编译) ‧ ⚡ 高性能 (启动快) ‧ 🔒 防反编译 | `dist/secure/WeMediaBaby/` |

两种方案均通过 **Inno Setup** 生成 Windows 安装包，安装包输出到 `dist/installers/` 目录。

### 版本分发策略

| 发行模式（DistMode） | 说明 | 典型用途 | 打包脚本参数 |
| :--- | :--- | :--- | :--- |
| **OSS** | 开源社区版（不依赖闭源 `src/proprietary/`，Pro 功能入口默认隐藏） | 开源仓库源码 + 社区版安装包 | `-DistMode OSS` |
| **PRO** | 闭源完整版（含账号登录/订阅权限等闭源模块） | 正式发版/交付 | `-DistMode PRO` |
| **52POJIE** | 闭源离线特别版（全权限/弱化云端依赖的变体） | 特定渠道 | `-DistMode 52POJIE` |

> 说明：发行模式会被**固化进打包产物**（`config/dist_mode.json`）。运行时 `FeatureFlags` 优先读取环境变量 `APP_DIST_MODE`，若未设置则读取该文件，确保用户机器上双击运行也能识别版本。

## 3. 版本管理

### 3.1 版本号来源

项目采用 **单一权威版本源 (`version.json`)** 策略，构建脚本在运行时自动读取此文件中的版本号。

| 文件               | 用途                       | 由谁维护            |
| :----------------- | :------------------------- | :------------------ |
| `version.json`     | 权威版本号定义             | `update_version.py` |
| `pyproject.toml`   | 项目元数据版本号           | `update_version.py` |
| `setup_script.iss` | 安装包版本号               | `update_version.py` |
| `CHANGELOG.md`     | 变更日志                   | `update_version.py` |

**当前版本信息 (`version.json`)：**

```json
{
  "version": "1.0.7",
  "release_date": "2026-03-27",
  "notes": "发版后请在此填写更新说明。",
  "download_url": "https://gitee.com/chitangsuper/wemedia-baby/releases"
}
```

**已安装时再运行安装包**：`setup_script.iss` 在 `InitializeSetup` 中检测注册表卸载项（与 `AppId` 对应）；若已安装，则提示用户先卸载旧版，可选启动卸载程序，并结束本次安装；卸载完成后需重新运行安装包。静默安装（`/SILENT`）不弹窗，沿用 Inno 默认行为。若将来修改 `AppId`，须同步更新脚本内 `MyAppUninstallRegSubKey` 中的 GUID 段。

### 3.2 更新版本号

**方式一：使用交互菜单** (推荐)

```batch
# 从项目根目录运行（或双击 scripts\release\version.bat）
scripts\release\version.bat
```

按提示选择更新类型：

- `[1]` 补丁更新 (Patch)：`1.0.7` → `1.0.8`
- `[2]` 次版本更新 (Minor)：`1.0.7` → `1.1.0`
- `[3]` 主版本更新 (Major)：`1.0.7` → `2.0.0`

**方式二：命令行直接调用**

```bash
python scripts/release/update_version.py patch   # 补丁更新
python scripts/release/update_version.py minor   # 次版本更新
python scripts/release/update_version.py major   # 主版本更新
```

## 4. 迭代期方案 (PyInstaller + Inno Setup)

### 4.1 一键构建

`build_fast.ps1` 脚本已集成 **PyInstaller 构建 + Inno Setup 打包** 完整流程，一条命令即可完成：

```powershell
# 方式一：直接运行脚本
.\scripts\build\build_fast.ps1 -DistMode OSS

# 也可以构建 Fast 的 Pro/52pojie 变体（用于内部联调；正式发版建议用 Nuitka）
.\scripts\build\build_fast.ps1 -DistMode PRO
.\scripts\build\build_fast.ps1 -DistMode 52POJIE

# 方式二：通过交互菜单
.\scripts\build\build.bat  →  选 [1] → 选择 DistMode(OSS/PRO/52POJIE)
```

**脚本执行流程**：

1. 从 `version.json` 读取版本号
2. 检测 / 激活虚拟环境 (`.venv`)
3. 检查 / 安装 PyInstaller 依赖
4. 清理旧构建产物 (`dist/fast/`)
5. 执行 `PyInstaller` 构建 → 生成可执行文件到 `dist/fast/WeMediaBaby/`
6. 复制附加文件 (README、调试脚本)
7. 自动检测 **Inno Setup** 编译器 → 编译安装包到 `dist/installers/`

### 4.2 构建产物

| 产物              | 路径                                                   |
| :---------------- | :----------------------------------------------------- |
| 可执行程序目录    | `dist/fast/WeMediaBaby/`                               |
| 调试启动脚本      | `dist/fast/WeMediaBaby/debug_start.bat`                |
| 安装包 (自动生成) | `dist/installers/WeMediaBaby_Setup_Fast_[DistMode]_v[版本号].exe` |

### 4.3 PyInstaller 配置说明 (`main.spec`)

打包配置文件位于 `scripts/build/main.spec`，关键设置：

- **入口文件**：`main.py` (项目根目录)
- **打包模式**：目录模式 (非单文件)，使用 UPX 压缩
- **隐藏导入**：`qasync`、`pyside6_fluent_widgets`、`playwright`、`undetected_playwright`、`dns` 等
- **窗口模式**：无控制台窗口 (`console=False`)
- **应用图标**：`resources/icons/app.ico`

### 5.2 Nuitka 构建配置

## 10. 常见问题 (FAQ)

**Q: `build_fast.ps1` 执行后提示语法错误？**
A: 请确认 PowerShell 版本 ≥ 5.1，并以 `powershell -ExecutionPolicy Bypass -File scripts\build\build_fast.ps1` 方式运行。

**Q: Inno Setup 编译报错 "Source file not found"？**
A: 请先运行 `.\scripts\build\build_fast.ps1` 生成源文件到 `dist/fast/WeMediaBaby/` 目录。

**Q: Nuitka 编译极慢且占用大量资源？**
A: 首次超深度编译需要分析全系统依赖树并调动所有核心下载组装 C 编译器，后续会利用构建态缓存飞速加速。建议关闭极具干扰的杀毒软件，并确保固态硬盘 I/O 性能满血发力。

**Q: 打包时提示找不到 `src/plugins/pro/` 目录？**
A: 请确保已通过 `git pull` 同步最新代码。Pro商业插件位于 `src/plugins/pro/`（旧路径 `src/plugins_pro/` 已废弃）。如需打包Community版，请在 `config/feature_flags.py` 中禁用Pro功能。

**Q: 安装包安装后无法启动？**
A: 请检查目标机器是否已安装 VC++ 运行时库。Nuitka 构建通常自动处理此依赖，也可手动安装 `VC_redist.x64.exe`。

**Q: 如何打包特定平台的Community版？**
A: 在 `config/feature_flags.py` 中只启用需要的平台功能，禁用其他Pro功能后执行构建。
