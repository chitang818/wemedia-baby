## 一、整体架构

项目测试体系分三层，覆盖核心业务逻辑、基础设施和关键服务，**排除**需要真实浏览器环境的发布插件。

```
tests/
├── conftest.py              全局 fixtures（账号、Cookie、路径、Mock 服务）
├── helpers/
│   ├── factory.py           测试数据工厂（Account、Task、Cookie 等）
│   ├── db_helpers.py        Tortoise ORM 内存数据库辅助
│   └── async_helpers.py     异步测试辅助工具
├── unit/                    单元测试（~335 个用例，纯逻辑，无外部依赖）
└── integration/             集成测试（~64 个用例，含 DB / 文件系统）
```

## 四、一键测试脚本使用方法

### 方式一：命令行（推荐）

```bash
# 全量测试 + 生成 HTML 报告
python scripts/test/run_tests.py

# 仅单元测试
python scripts/test/run_tests.py unit

# 仅集成测试
python scripts/test/run_tests.py integration

# 快速模式（跳过 slow 测试）
python scripts/test/run_tests.py --quick

# 按关键字筛选
python scripts/test/run_tests.py --module encrypt

# 不生成覆盖率（加快速度）
python scripts/test/run_tests.py --no-cov

# 测试完成后自动打开报告
python scripts/test/run_tests.py --open
```

### 方式二：Windows 双击

双击 `scripts/test/run_tests.bat`，自动运行全量测试（兼容入口：`scripts/run_tests.bat`）。

## 六、配置说明

### pytest.ini

```ini
[pytest]
testpaths = tests
asyncio_mode = auto           # 自动处理 async def 测试函数
markers =
    slow: 慢速测试
    integration: 集成测试
    unit: 单元测试
addopts =
    --strict-markers
    -v
    --basetemp=.test-tmp      # Windows 临时目录权限隔离
```

### 依赖

```
pytest >= 7.4.3
pytest-asyncio >= 0.21.1
pytest-cov >= 4.1.0
pytest-mock >= 3.12.0
pytest-html >= 4.0.0
```

安装：`pip install pytest pytest-asyncio pytest-cov pytest-mock pytest-html`

## 七、新增测试建议

添加新功能时，遵循以下原则：

1. **纯函数/业务规则** → 写单元测试，放 `tests/unit/`
2. **涉及 DB/文件系统** → 写集成测试，放 `tests/integration/`，使用 `test_db` fixture
3. **浏览器/发布插件** → 不写自动测试，手工验证
4. **标记慢测试** → 加 `@pytest.mark.slow`，`--quick` 模式会跳过

```python
# 新建单元测试示例
import pytest

pytestmark = pytest.mark.unit

def test_my_function():
    from src.xxx import my_func
    assert my_func("input") == "expected"
```
