## 终端运行指南

本项目支持通过 `APP_DIST_MODE` 指定运行的发行模式：

- `OSS`：开源版
- `PRO`：专业版
- `52POJIE`：52pojie 版

运行时读取优先级为：**环境变量 `APP_DIST_MODE` > `config/dist_mode.json`（兜底）**。

---

## 方式一：终端临时设置（推荐，最灵活）

只对**当前终端窗口**生效，关掉窗口就失效。

### PowerShell（Windows）

```powershell
$env:APP_DIST_MODE="PRO"   # 可改为 OSS / 52POJIE
python main.py
```

### CMD（Windows）

```bat
set APP_DIST_MODE=PRO
python main.py
```

---

## 方式二：使用 `config/dist_mode.json`（不设置环境变量时的兜底）

适用场景：你不想每次都在终端里写环境变量；或者做发布包时希望把发行模式固化在构建产物里。

1) 打开 `config/dist_mode.json`，把 `dist_mode` 改成你要的模式，例如：

```json
{
  "dist_mode": "PRO"
}
```

2) 确保终端里 **没有设置** `APP_DIST_MODE`（否则会覆盖这个文件）：

```powershell
Remove-Item Env:APP_DIST_MODE -ErrorAction SilentlyContinue
python main.py
```

---

## 方式三：设置 Windows 系统环境变量（长期固定）

适用场景：你希望 **所有新开的终端/IDE** 默认都按某个模式运行（例如长期开发 PRO）。

- **设置**：在 Windows “环境变量”里新增 `APP_DIST_MODE=PRO`（用户变量或系统变量均可）
- **生效**：设置后需要**重新打开终端/重启 IDE**，再运行：

```powershell
python main.py
```

---

## 常见问题

### 1）我把 `config/dist_mode.json` 改成 `OSS`，为什么还是 PRO？

通常是因为你曾在当前终端执行过：

```powershell
$env:APP_DIST_MODE="PRO"
```

此时环境变量优先级更高，会覆盖 `dist_mode.json`。可用下面命令清掉：

```powershell
Remove-Item Env:APP_DIST_MODE -ErrorAction SilentlyContinue
```
