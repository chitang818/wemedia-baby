# 批量视频（批量图文）预览及发布任务生成逻辑

| 项目 | 内容 |
|------|------|
| **文档名称** | 批量视频（批量图文）预览及发布任务生成逻辑 |
| **文档版本** | v1.4.3 |
| **最后更新时间** | 2026-06-04 |
| **更新时软件版本** | 1.4.3 |

**文档简介**：本文说明批量视频/图文任务界面中标准三步操作流程、预览任务与发布任务的生成规则。**批量视频任务页仅支持定时发布**：②配置时间通过「设置发布时间排期」弹窗完成，不提供「立即发布」。

---


## 1. 名词解释

| 名词 | 含义 |
|------|------|
| **预览任务** | 显示在批量任务界面表格中的行。数量由**时间数**决定（单账号/单账号组），与账号组内有多少个子账号**无关**。 |
| **发布任务** | 在批量界面点击【添加到发布列表】后写入发布列表的任务。数量由**账号组内子账号数量**决定（单账号则一对一）。 |
| **视频池** | 用于给预览任务分配视频的来源集合，来自手动添加或媒体库自动匹配。 |

---

## 2. 标准三步流程

批量任务创建**必须**按以下顺序操作，界面按钮根据步骤完成情况联动启用/禁用：

```
①选择账号  →  ②配置时间  →  ③添加视频
```

| 步骤 | 操作 | 完成后效果 |
|------|------|-----------|
| **①选择账号** | 从账号库选择一个或多个账号/账号组 | 激活「②配置时间」按钮 |
| **②配置时间** | 打开「设置发布时间排期」，配置一个或多个定时时间点（仅定时，无立即发布） | 激活「③添加视频」按钮；若尚未添加视频，预览区按时间槽数显示占位行（见 §3.3 待配视频） |
| **③添加视频** | 手动选文件/文件夹，或从媒体库自动匹配 | 视频填入各时间槽，预览表显示完整任务行 |

> 说明：「②配置时间」未完成前，「③添加视频」按钮保持禁用。「①选择账号」未完成前，「②配置时间」按钮保持禁用。

## 3. 预览任务生成规则

### 3.1 预览任务数量

- **单账号或单账号组**：预览任务数 = **时间槽数**（每个时间槽一行）；视频按添加顺序逐槽填入；视频少于时间槽时，未分配的槽在预览中显示「待配置」。
- **多个独立账号（无账号组时）**：预览任务数 = **时间槽数 × 账号数**（与 §3.2 一致）；无视频时的占位行数也按该公式生成。
- **视频多于当前可分配槽位时**：以 `build_preview_tasks` 实际生成的预览行为准，多余视频可能暂时不出现在预览表中（取决于分配算法与是否已配满时间槽）。

*例：1 个账号组 + 3 个时间槽 + 2 个视频 → 3 条预览行，前 2 行绑定视频，第 3 行视频为「待配置」。*

### 3.2 多账号/多账号组

每个账号/账号组各自独立拥有时间槽数量的预览行，共享同一组时间配置。

*例：选 2 个独立账号 × 3 个时间槽 = 6 条预览行；各账号按顺序取视频池中的视频。*

### 3.3 预览表状态说明

| 状态 | 触发条件 | 表格显示 |
|------|---------|---------|
| 空（empty） | 未选账号 | 空表，状态文案"请先①选择账号" |
| 待配时间（no_time） | 有账号，未配置时间 | 每个已选账号一行占位（时间、文件列为「待配置」），状态文案"请②配置发布时间" |
| 待配视频（no_video） | 有账号+时间，尚未添加视频 | 占位行数：单账号/单组为 **N=时间槽数**；多个独立账号为 **N=时间槽数×账号数**。每行发布时间对应一时间槽，视频列为「待配置」 |
| 完整（full） | 账号+时间+视频均已配置 | 显示完整预览行 |

## 4. 发布任务生成规则（点击「添加到发布列表」时）

| 选择类型 | 发布任务数 |
|---------|-----------|
| 单账号 | 预览任务数（1:1） |
| 账号组 | 预览任务数 × 组内成员数 |
| 多个独立账号 | 各账号预览任务数之和 |

*例：选 1 个含 3 名成员的账号组，配置 2 个时间槽并添加 2 个视频 → 2 条预览行，点击「添加到发布列表」后生成 6 条发布任务（3 成员 × 2 视频）。*
