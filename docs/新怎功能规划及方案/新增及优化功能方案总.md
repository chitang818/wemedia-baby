#有问题的功能

1、账号库页面，当筛选为视频号后，页面仅显示已经登录的视频号账号，筛选功能生效。如果此时打开一个账号的浏览器，稍等片刻会发现筛选失效，修复；

2、待发布页发布失败的任务，点击复位状态后，重新发布，发布成功后任务中的视频文件没有移动，已经确定发布设置中设置的事发布后移动；

3、优化作品描述中话题的识别，如果导入的作品描述中包含类似“#中国 #美国 #韩国”这样的话题，则应该判断共有3个话题，话题判断的依据需要优化，明确#后面就是话题，明确#后面的文字只要连续，没有标点符号，没有空格，则为一个话题，比如“#我好快乐，你在哪”、“#我好快乐 ”、“#我好快乐”都是只有一个话题“我好快乐”定义什么为话题，话题就是#好后面连续的文字，没有任何标点符号空格等内容。

4、目前，批量视频任务页面的添加视频弹窗中，媒体库分配策略功能仅自动从视频库添加的视频生效，需要拓展为对所有添加视频的方式均生效，即手动添加多个视频、手动选择视频文件夹、手动选择从媒体库选择等方式均生效。媒体库分配策略修改为添加视频分配策略。

#新增的功能

1、软件主程序关闭窗口增加弹窗，提示关闭还是最小化到托盘，并增加记住选择复选框

2、修改抖音发布插件中的步骤三，之前是失败重试三次，修改为失败则不重试，输出步骤失败；

3、批量视频任务页面，在删除选中任务按钮右侧增加清空视频按钮，点击后则清空预览任务的视频匹配和配置描述设置；

4、账号管理页面中，在删除账号按钮右侧增加自动刷新登录状态按钮，点击口可设置自动刷新登录状态功能，设置开关，可打开或者关闭，如果打开，这按照设置的规则静默刷新已登录账号登录状态。设置的规则包含以下：复选框1，进入页面自动刷新，复选框2定时自动刷新，复选框2后面再添加设置定时时间的输入框。

5、账号管理页面表格在登录状态列后面新增列，列标题为：已发布最晚时间，显示该账号已发布的任务中定时时间最晚的时间，方便用户确认该账号已经发布到几号了；

6、待发布页，发布设置弹窗中增加一个发布前检测账号在线状态的功能，可手动开启或者关闭，开启后，点点击发布按钮后，则先对任务列表中的所有任务的账号执行刷新登录状态功能，如果所有账号都在线则自动继续执行发布任务，如果所有账号都掉线则弹窗提醒所有账号都掉线请登录后再点击发布，确定后终止发布任务跳转到账号管理页面，如果有部分账号掉线则弹窗显示掉线的账号，并询问是继续发布任务还是终止发布

7、目前账号管理页面中，如果打开已经登录的账号浏览器，账号平台昵称和cookie会更新。如果平台昵称修改了，且改昵称在媒体库中没有文件夹，会新建一个修改后名字的文件。这个逻辑需要修改。如果已登录账号的凭条昵称修改了，则修改改账号已经在媒体库中之前创建的账号文件夹的文件夹名称，而不是新建一个。只有新添加账号的时候才新建。同步账号后如果账号平台昵称和之前不一致则执修改之前的账号文件夹名称。这样就可以保证同一个账号一直使用一个文件夹。

8、软件中单视频任务和多视频任务页面中，如果添加视频是从媒体库自动添加，则会校验该视频是否已经在待发布页中使用，如果待发布页中已经有任务使用该视频则不会在自动匹配该视频在创建任务的预览界面。现在需要把这个功能进行扩展。当是手动选择添加视频或者添加视频文件夹的时候，也应该校验选择的视频或者文件夹中的视频是否已经在待发布页面中有任务使用，如果有的话则过滤掉并弹窗提醒用户。
