## 一、用户状态与等级定义

### 1.1 登录状态

| 状态 | 说明 | 判定方式（代码） |
| :--- | :--- | :--- |
| **未登录** | 用户未进行软件账号登录 | `CurrentUserService.is_logged_in()` 为 `False` |
| **已登录** | 用户已通过云端登录软件账号 | `CurrentUserService.is_logged_in()` 为 `True` |

### 1.2 会员等级（level）

| 等级 | 含义 | 高密商业平台发布权限 |
| :--- | :--- | :--- |
| **vip0** | 免费用户（新注册默认）| 无 |
| **vip1** | Pro 会员 | 有（需 `is_expired == False`）|

**Pro 权限判定方法**：`CurrentUserService.has_pro_permission()`  
→ 当且仅当 `level == "vip1"` 且 `is_expired == False` 时返回 `True`

### 1.3 发布权限（`check_publish_permission`）

**已登录的云端用户（vip0/vip1）直接通过发布权限校验**，不强制要求本地订阅或试用记录。本地订阅/试用校验仅作为"未登录或非当前用户"的回退兜底。

| 用户状态 | `check_publish_permission` 结果 |
| :--- | :--- |
| 已登录云端用户（user_id 匹配）| **直接返回 True**（无需本地订阅/试用）|
| 未登录回退 | 依次检查本地有效订阅 → 本地剩余试用次数 |
| 无订阅且无试用 | 返回 False（"用户无发布权限"）|

## 六、发布管道权限校验流程

> **源码**：`PermissionCheckFilterAsync.process()`  
> 发布任务执行时由 pipeline 自动执行，依次进行以下校验（有一项不通过则拒绝发布）：

```
1. 登录校验
   └─ is_logged_in()? 否 → "发布需要先登录"
   └─ user_id 是否与当前登录用户一致? 否 → "发布用户与当前登录用户不一致"

2. 高密商业平台校验（is_pro_platform 为 True 时）
   └─ has_pro_permission()? 否 → "需要 Pro 会员，请升级/续费"

3. 发布权限校验
   └─ 已登录云端用户 → 直接通过（vip0/vip1 均可发布标准通用平台）
   └─ 回退：本地有效订阅 或 剩余试用次数? 否 → "用户无发布权限，请检查订阅状态"

4. 试用次数校验
   └─ 已登录云端用户 → 直接通过
   └─ 回退：有效订阅 或 trial_count > 0? 否 → "试用次数已用完，请购买订阅"

5. 日发布数额度校验（daily_max_publish_count 不为 null 时生效）
   └─ 今日成功发布数 >= daily_max → "今日发布数量已达上限（N）"

6. 服务端校验（已启用云端认证且持有 token 时）
   └─ 调用 publish_check(token, platform, is_pro_platform)
   └─ allowed=False → 返回服务端提供的 reason
   └─ 网络异常 → 降级放行，记录日志
```

## 七、权限校验入口汇总

| 校验位置 | 校验内容 | 未通过提示/行为 |
| :--- | :--- | :--- |
| `single_task_creation_page._on_publish`（写入发布列表前）| 是否已登录 | 「发布前需要登录」|
| `single_task_creation_page`（选择高密商业平台，写入列表前）| 是否已登录 | 「使用 Pro 平台需要先登录」|
| `single_task_creation_page`（选择高密商业平台，写入列表前）| Pro 权限 | 「需要 Pro 会员，请升级/续费」|
| `publish_list_page._on_start_publish` | 是否已登录 | 「发布前需要登录」|
| `add_account_dialog`（选择高密商业平台）| 是否已登录 | 弹确认框，可选跳转登录 |
| `add_account_dialog`（选择高密商业平台，已登录）| Pro 权限 | 「当前为免费版，无法添加 Pro 平台账号。请升级 Pro 会员后使用。」|
| `AccountManagerAsync.add_account` | 账号数量上限（`max_login_accounts`）| 达到上限时拒绝添加 |
| `PermissionCheckFilterAsync`（发布管道）| 登录 + Pro + 发布权限 + 试用 + 日额度 + 服务端 | 各环节独立返回原因 |

## 八、导航与功能模块可见性

以下模块由功能包是否存在决定是否显示，与登录状态/会员等级无直接绑定：

| 模块 | 控制常量 | 说明 |
| :--- | :--- | :--- |
| 批量视频 | `BATCH_FEATURE_AVAILABLE` | 对应功能包存在时显示 |
| 批量图文 | `BATCH_FEATURE_AVAILABLE` | 同上 |
| 数据中心 | `DATA_CENTER_AVAILABLE` | 同上 |
| 评论及私信 | `INTERACTION_FEATURE_AVAILABLE` | 同上 |
| 个人中心 | `SUBSCRIPTION_PAGE_AVAILABLE` | 同上 |

> **注意**：当前导航模块可见性与登录/会员等级无显式联动，可能出现"能看到入口但无权限使用"的体验，后续可考虑优化。
