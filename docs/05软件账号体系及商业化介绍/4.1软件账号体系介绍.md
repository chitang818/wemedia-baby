## 一、目标与范围

- **登录与鉴权**：用户通过用户名+密码登录软件，支持「记住我」本地持久化。
- **身份与联系信息**：支持用户名、可选邮箱、可选手机号；预留微信ID（wechat_id）供后续绑定/扫码登录。
- **安全与审计**：注册与登录时记录客户端 IP（register_ip、last_login_ip），便于安全审计与风控。
- **商业化与权益**：通过 VIP 等级（vip0 免费版、vip1 Pro）及到期时间、各项额度（登录账号数、分组数、日发布数）控制功能与用量。

详细字段定义见同目录《软件账号字段对照表》。

## 二、账号字段概览

软件账号包含 **14 类内容**，核心字段包括：

| 类别     | 字段示例 | 说明 |
|----------|----------|------|
| 身份登录 | username, password | 用户名唯一、密码仅云端存储且不返回 |
| 联系信息 | email, phone, wechat_id | 邮箱/手机号注册或资料可选；wechat_id 为预留 |
| 时间     | create_time, last_login_at | 注册时间、最后登录时间（毫秒时间戳） |
| IP 信息  | register_ip, last_login_ip | 注册时与每次登录时记录的客户端 IP |
| 会员权益 | level, expire_time, is_expired | vip0/vip1，权益到期时间及是否过期 |
| 额度     | max_login_accounts, max_account_groups, daily_max_publish_count | 发布账号数、分组数、日发布数上限 |

新注册用户默认为 **vip0（免费版）**，权益期 **10 年**；VIP0 默认额度（如登录账号数 10、分组数 5、日发布数 30）由云端常量配置，详见《软件账号字段对照表》。

## 三、注册与登录流程

### 3.1 注册

- 用户输入：**用户名**（必填）、**密码**（必填），**邮箱**、**手机号**为可选。
- **微信ID（wechat_id）**：预留字段，注册时不填写，供后期账号绑定微信或扫码登录使用。
- 桌面端在注册请求中携带 **client_ip**（见下节），云端据此写入 **register_ip**，并在首次登录逻辑中可同时写入 **last_login_ip**。
- 注册成功后，云端为该用户设置 `level=vip0`、`expire_time` 为注册日起 10 年，并写入上述额度默认值。

### 3.2 登录

- 用户输入：用户名、密码；可选勾选「记住我」由桌面端本地安全存储凭据。
- 桌面端在登录请求中携带 **client_ip**，云端校验通过后更新 **last_login_at**、**last_login_ip**，并生成短期 **token**（如 1 小时有效）写入云端存储；响应 `data` 中返回用户信息与权益字段（含 **token**、level、expire_time、is_expired、各项额度等）。
- 桌面端使用返回的 `data` 调用 `CurrentUserService.sync_from_cloud_data(data)`，同步当前用户、**token** 与权限，供各模块使用。token 用于发布前服务端校验（见下节）。

### 3.3 公网 IP 获取与上报（register_ip / last_login_ip）

- **桌面端**：在发起注册或登录请求前，通过访问 **http://ip.3322.net/** 获取当前公网 IP，并在请求体中以 **client_ip** 字段上报。
- **云端**：优先使用请求体中的 **client_ip** 写入 **register_ip**（注册时）和 **last_login_ip**（登录时）；若请求中未提供 client_ip，则使用 HTTP 请求头 **X-Forwarded-For** 或 **remote_addr** 作为 fallback。
- 这样可尽量保证记录的是用户真实公网 IP，便于安全审计与风控。

### 3.4 发布前服务端校验

- 该步骤**仅在**「已启用云端认证」且用户「已通过云端登录并持有 token」时执行；默认配置下云端认证为启用状态（代码中配置了 AUTH_API_BASE），因此通过云端登录的用户在发布前会进行服务端校验。
- 执行时桌面端调用云端 **publish_check** 接口：携带 token、platform、is_pro_platform，由云端校验 token 有效且未过期，并在为 Pro 平台时校验用户为 vip1 且未过期。
- 若服务端返回 **allowed=false**，则本次发布被拒绝，并提示 reason（如「登录已过期，请重新登录」「需要 Pro 会员，请升级/续费」）。
- 若服务端返回 **allowed=true**，则继续执行发布流水线。
- **网络异常**（如无法访问云端）时，桌面端采用**降级策略**：仅凭本地校验通过即放行，不阻断发布，仅记录日志。未启用云端认证或无 token 时，不调用 publish_check，仅做本地校验。
- 通过「本地校验 + 服务端校验」双重机制，在云端可用时提高权限可信度，降低仅靠本地篡改绕过限制的可能；详见《腾讯云SCF云函数+对象存储/COS版云函数与对象存储介绍》中的发布前校验说明。

## 四、云端与桌面端职责

### 4.1 云端（如腾讯云 SCF + COS）

- 存储：账号数据存于 `data/users.json`（用户名、密码、email、phone、wechat_id、create_time、last_login_at、register_ip、last_login_ip、level、expire_time 及各项额度）；登录生成的短期 token 存于 `data/tokens.json`（token → username、过期时间）。
- 注册：校验用户名唯一性，写入上述用户字段及 register_ip（来自 client_ip 或 fallback），新用户设为 vip0、10 年权益及默认额度。
- 登录：校验用户名与密码，更新 last_login_at、last_login_ip（来自 client_ip 或 fallback），生成短期 token 写入 tokens 存储，返回不含密码的用户信息与权益字段（含 **token**、is_expired）。
- 发布前校验（publish_check）：根据请求体中的 token 校验是否有效且未过期，从 users 中取对应用户；若 is_pro_platform 为 true 则校验 level 为 vip1 且未过期；仅返回 allowed 与 reason，不返回用户敏感信息。

### 4.2 桌面端

- **AuthApiClient**：负责注册/登录及**发布前校验**的 HTTP 请求；提供 `get_public_ip()`（访问 ip.3322.net），注册/登录请求体均带 **client_ip**；提供 `publish_check(token, platform, is_pro_platform)` 调用云端 publish_check 接口。
- **CurrentUserService**：保存当前用户信息及云端返回的 **token**（含 email、phone、wechat_id、create_time、register_ip、last_login_ip、额度、level、expire_time、is_expired）；`sync_from_cloud_data(data)` 与云端返回保持一致（含 data.token）；提供 `get_token()`、`get_user()`、`get_user_id()`、`get_max_login_accounts()`、`get_max_account_groups()`、`get_daily_max_publish_count()`、`is_logged_in()`、`has_pro_permission()` 等。
- **发布流水线**：在权限过滤器（PermissionCheckFilterAsync）中，本地校验通过后，若已启用云端认证且存在 token，则调用 `publish_check`；仅当服务端返回 allowed 为 true 时继续发布，否则拒绝并提示 reason；网络异常时降级为仅本地通过即放行。
- **注册对话框**：支持可选填写邮箱、手机号；不提供 wechat_id 输入（预留）。
- **个人中心**：展示权益到期时间等；不展示最后登录时间；若已「记住我」，进入页面时可后台同步云端权限。

## 五、VIP 与权益约定

- **vip0**：免费版，新注册即为此等级，权益期 10 年，额度由云端 VIP0 默认常量决定（如登录账号数 10、分组数 5、日发布数 30）。
- **vip1**：Pro 会员，在未过期（is_expired 为 false）时可使用 Pro 平台发布等功能。
- 桌面端 **has_pro_permission()**：当且仅当 `level == "vip1"` 且 `is_expired == false` 时返回 True。
- 各等级具体额度以云端存储或后台配置为准，详见《软件账号字段对照表》中的「等级与权限约定」章节。

---

## 六、与商业化的关系

- 账号体系是商业化的基础：通过 **level**、**expire_time**、**is_expired** 及 **max_login_accounts**、**max_account_groups**、**daily_max_publish_count** 控制可用的平台与用量。
- 后续可在此基础上扩展：付费开通/续费 Pro、权益包、活动赠送等，均由云端更新上述字段，桌面端通过登录或权限同步接口获取最新状态。

## 七、不同用户类型的软件功能说明

以下说明**非注册用户**、**已注册免费用户（vip0）**、**已注册 Pro 用户（vip1，未过期）**在软件内可享受的功能范围，与当前实现一致。

- **标准通用平台**：抖音（douyin）、快手（kuaishou），免费用户可用。
- **高密商业平台**：视频号（wechat_video）、小红书（xiaohongshu）、哔哩哔哩（bilibili）、微博（weibo）、头条（toutiao）、百家号（baijiahao）、多多视频（duoduoshipin）、切号（qiehao），需 Pro 会员且未过期方可添加账号与发布。

### 7.1 非注册用户（未登录）

| 功能类别 | 说明 |
|----------|------|
| **浏览与设置** | 可打开软件、浏览界面结构、使用与登录无关的设置项。 |
| **添加发布账号** | **不可用**。添加任意平台账号前均需先登录软件，未登录会提示「Pro 插件需要登录软件后使用」或引导登录。 |
| **单条发布** | **不可用**。点击发布会提示「发布前需要登录」。 |
| **发布列表（批量发布）** | **不可用**。启动自动发布队列前会校验登录，未登录提示「发布前需要登录」。 |
| **账号组** | 未登录时无当前用户身份，无法按用户维度创建/管理账号组（依赖登录后额度与身份）。 |
| **订阅/权益页** | 可打开页面；从云端同步权益、展示到期时间等需已登录且已开启云端鉴权，未登录时相关同步会跳过。 |

**小结**：未登录仅能「看看」软件，不能添加账号、不能发布、不能使用账号组与云端权益同步。

### 7.2 已注册免费用户（vip0，已登录）

| 功能类别 | 说明 |
|----------|------|
| **添加发布账号** | **仅限社区平台**。可添加抖音、快手等社区平台账号；**不可添加 Pro 平台**（视频号、小红书、哔哩哔哩等），选择 Pro 平台会提示「当前为免费版，无法添加 Pro 平台账号。请升级 Pro 会员后使用。」 |
| **单条发布** | 可发布到**已添加的社区平台账号**；若所选账号包含任一 Pro 平台，会提示「所选平台需要 Pro 会员，请升级/续费」。 |
| **发布列表（批量发布）** | 可启动自动发布队列；任务中若包含 Pro 平台，执行时会被权限过滤器拦截并提示需 Pro 会员。 |
| **额度限制** | 受云端返回的 vip0 默认额度约束：**最大登录账号数**（如 10）、**最大账号组数**（如 5）、**日发布最大数量**（如 30），超出后不可继续添加或发布。 |
| **订阅/权益页** | 可查看当前等级、权益到期时间（免费版默认 10 年）及额度；若开启「记住我」，进入页面时可从云端同步最新权限。 |

**小结**：免费版可完整使用标准通用平台（抖音、快手）的添加账号与发布能力，并受账号数/分组数/日发布数上限限制；高密商业平台不可用。

### 7.3 已注册 Pro 用户（vip1，未过期）

| 功能类别 | 说明 |
|----------|------|
| **添加发布账号** | **全部平台**。可添加标准通用平台（抖音、快手）与所有高密商业平台（视频号、小红书、哔哩哔哩、微博、头条、百家号、多多视频、切号），无平台限制。 |
| **单条发布** | 可发布到任意已添加账号（社区 + Pro），不会因 Pro 平台被拦截。 |
| **发布列表（批量发布）** | 可正常执行含 Pro 平台的批量任务，权限检查通过。 |
| **额度限制** | 按云端配置的 Pro 额度（通常高于免费版或不限），如更大 max_login_accounts、max_account_groups、daily_max_publish_count。 |
| **订阅/权益页** | 可查看 Pro 状态、到期时间及当前额度；到期后 is_expired 为 true，Pro 能力收回，按免费版逻辑处理。 |

**小结**：Pro 会员在未过期时可使用全部平台的添加账号与发布功能，并享受更高或不受限的额度；过期后与免费版一致。

---

**实现说明**：上述约定已在代码中落实。添加账号前强制登录（账号页入口校验）；添加账号时校验 `max_login_accounts`（AccountManagerAsync）；创建账号组前校验登录及 `max_account_groups`（账号组页）；发布任务执行前在流水线中先做本地校验（登录身份、Pro、订阅/试用、`daily_max_publish_count` 等），在已启用云端认证且持有 token 时再调用云端 **publish_check**，仅当服务端返回 allowed 为 true 时继续发布，网络异常时降级放行。未登录时不可添加账号、不可创建账号组；免费版仅限社区平台，Pro 平台需 vip1 且未过期。
