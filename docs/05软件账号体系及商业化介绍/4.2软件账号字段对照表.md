## 一、账号字段包含内容（汇总）

软件账号包含以下 14 类内容，对应字段名及含义如下：

| 序号 | 内容项 | 字段名 | 类型/取值 | 说明 |
|------|--------|--------|-----------|------|
| 1 | 用户名 | username | string | 唯一标识，用于登录 |
| 2 | 密码 | password | string | 仅云端存储（建议哈希），不返回 |
| 3 | 邮箱 | email | string | 注册或资料可选填写 |
| 4 | 手机号 | phone | string | 注册或资料可选填写 |
| 5 | 微信ID | wechat_id | string | 预留字段，供后期账号绑定微信/扫码登录使用，注册时不填写 |
| 6 | 注册时间 | create_time | 时间戳（毫秒） | 账号创建时间 |
| 7 | 最后登录时间 | last_login_at | 时间戳（毫秒） | 每次登录成功时更新 |
| 8 | 注册IP | register_ip | string | 注册时服务端记录的客户端 IP |
| 9 | 最后登录IP地址 | last_login_ip | string | 每次登录成功时服务端记录的客户端 IP |
| 10 | VIP等级 | level | string | vip0=免费版，vip1=Pro |
| 11 | 等级到期时间 | expire_time | 时间戳（毫秒） | 权益/会员到期时间 |
| 12 | 最大登录账号数量 | max_login_accounts | int | 可添加的「发布账号」数量上限 |
| 13 | 最大分组数量 | max_account_groups | int | 可创建的账号组数量上限 |
| 14 | 日发布最大数量 | daily_max_publish_count | int | 当日可发布视频条数上限 |

## 三、字段说明（按用途）

### 3.1 身份与登录

| 字段名 | 含义 | 说明 |
|--------|------|------|
| **username** | 用户名 | 用户登录时使用的账号，全局唯一。可为邮箱或自定义名称。 |
| **password** | 密码 | 仅用于登录请求与云端校验；云端应以 bcrypt 等哈希存储，禁止明文或可逆加密。桌面端不持久化密码（「记住我」为本地混淆存储）。 |
| **user_id** / **id** | 用户 ID | 整型，用于内部关联（如发布记录、订阅）。云端未返回时，桌面端由 username 哈希派生稳定整数。 |

### 3.2 联系信息

| 字段名 | 含义 | 说明 |
|--------|------|------|
| **email** | 邮箱 | 注册或资料可选填写；用于找回密码、通知或展示。 |
| **phone** | 手机号 | 注册或资料可选填写；用于验证、找回密码或通知。 |
| **wechat_id** | 微信ID | 预留字段；供后期实现「账号绑定微信」「微信扫码登录」时由系统写入，注册时不填写。 |

### 3.3 会员与权益

| 字段名 | 含义 | 说明 |
|--------|------|------|
| **level** | VIP等级 | `vip0`：免费版；`vip1`：Pro 会员。Pro 功能（如部分平台发布）需 level=vip1 且未过期。 |
| **expire_time** | 等级到期时间 | 毫秒级 Unix 时间戳，即权益/会员到期时间。当前时间大于此值视为已过期，按免费版处理。新注册免费版权益期为 10 年。 |
| **is_expired** | 是否已过期 | 由服务端根据当前时间与 expire_time 计算，桌面端直接用于展示与权限判断。 |

### 3.4 时间信息

| 字段名 | 含义 | 说明 |
|--------|------|------|
| **create_time** | 注册时间 | 毫秒级时间戳，账号创建时写入，用于统计或展示。 |
| **last_login_at** | 最后登录时间 | 毫秒级时间戳。每次登录成功后由云端更新并可选返回；用于审计或后台展示。 |

### 3.5 IP 信息

| 字段名 | 含义 | 说明 |
|--------|------|------|
| **register_ip** | 注册IP | 注册时服务端记录的客户端 IP 地址，用于安全审计。 |
| **last_login_ip** | 最后登录IP地址 | 每次登录成功时服务端记录的客户端 IP，用于安全审计与风控。 |

**IP 获取与上报**：桌面端在注册/登录前通过 **http://ip.3322.net/** 获取公网 IP，在请求体中以 **client_ip** 上报；云端优先使用 `client_ip` 写入 register_ip（注册时）与 last_login_ip（登录时），若无则使用请求头 X-Forwarded-For 或 remote_addr。

### 3.6 限额（权益数量）

| 字段名 | 含义 | 说明 |
|--------|------|------|
| **max_login_accounts** | 最大登录账号数量 | 允许绑定的「发布账号」数量上限，超出后不可再添加。未返回或 null 时桌面端可不校验。 |
| **max_account_groups** | 最大分组数量 | 允许创建的账号组数量上限。未返回或 null 时可不校验。 |
| **daily_max_publish_count** | 日发布最大数量 | 当日可发布视频条数上限，按自然日或业务规则统计。未返回或 null 时可不校验。 |

## 四、使用位置对照

### 4.1 云端存储（COS `data/users.json` 或 CloudBase 集合）

- 存储字段：`username`, `password`（或 `password_hash`）, `email`, `phone`, `wechat_id`, `create_time`, `last_login_at`, `register_ip`, `last_login_ip`, `level`, `expire_time`, `max_login_accounts`, `max_account_groups`, `daily_max_publish_count`。其中 email、phone、wechat_id 为可选。
- 登录时：校验密码后更新 `last_login_at`、`last_login_ip`，并返回需给客户端的字段（不含密码）。

### 4.2 登录接口返回 `data`

- 返回字段：`username`, `level`, `expire_time`, `is_expired`, `last_login_at`, `max_login_accounts`, `max_account_groups`, `daily_max_publish_count`，可选 `user_id`, `email`, `phone`, `wechat_id`, `create_time`, `register_ip`, `last_login_ip`。
- 桌面端据此调用 `CurrentUserService.sync_from_cloud_data(data)` 同步当前用户与权限。

### 4.3 桌面端当前用户（CurrentUserService）

- 保存字段：与登录返回一致，可含 `email`, `phone`, `wechat_id`（来自注册或登录返回）。
- 提供方法：`get_user()` 返回完整字典，`get_user_id()`, `get_max_login_accounts()`, `get_max_account_groups()`, `get_daily_max_publish_count()`, `is_logged_in()`, `has_pro_permission()` 等供各模块使用。

## 五、等级与权限约定

### 5.1 等级含义与 Pro 权限

| level | 含义 | Pro 权限 |
|-------|------|-----------|
| vip0 | 免费版 | 无 |
| vip1 | Pro 会员 | 有（且 is_expired 为 false 时生效） |

- **has_pro_permission()**：当且仅当 `level == "vip1"` 且 `is_expired == false` 时返回 True。

### 5.2 VIP 等级权益约定

各等级对应的权益由云端配置决定，桌面端按登录返回的 `max_login_accounts`、`max_account_groups`、`daily_max_publish_count` 及 `level` 进行校验。下表为**参考约定**（当前 COS 版新注册 vip0 默认值），实际以云端存储或后台配置为准。

| 权益项 | 说明 | VIP0（免费版） | VIP1（Pro 会员） |
|--------|------|----------------|------------------|
| **登录账号数量** | 可添加的「发布账号」数量上限（各平台绑定账号） | 10 | 由云端配置，通常更高或不限 |
| **账号组数量** | 可创建的账号组数量上限 | 5 | 由云端配置，通常更高或不限 |
| **每日最大发布视频数** | 当日可发布视频条数上限 | 30 | 由云端配置，通常更高或不限 |
| **高密商业平台发布** | 是否可添加/使用高密商业平台（如视频号、小红书、哔哩哔哩、微博、头条、百家号、多多视频、切号）| 不可用 | 可用（未过期时） |
| **权益到期** | 免费版默认 10 年；Pro 按开通时长 | 注册日起 10 年 | 按开通/续费时间 |

- 若云端未返回上述额度字段（为 null 或未配置），桌面端可不做对应限额校验或采用本地默认策略。
