## 概述

账号管理是媒小宝的核心功能模块,用于管理所有已绑定的自媒体平台账号。通过账号管理,您可以添加、删除、查看和验证账号,以及管理账号的登录状态和Cookie信息。

## 主要功能

### 1. 账号统计概览

页面顶部展示三个统计卡片:

- **账号总数**: 显示已绑定的账号总数
- **在线账号**: 显示登录状态正常的账号数量
- **离线账号**: 显示需要重新登录的账号数量

### 2. 账号列表管理

#### 2.1 账号列表展示

以表格形式展示所有账号信息,包括:

- **平台**: 账号所属平台(抖音、快手、视频号、小红书等)
- **平台昵称**: 账号在平台上的昵称
- **登录状态**: 在线/离线状态,用不同颜色标识
- **最后登录时间**: 最近一次登录的时间
- **操作**: 快速操作按钮(切换、更新、删除等)

#### 2.2 筛选和搜索

- **平台筛选**: 通过下拉菜单筛选特定平台的账号
  - 支持: 全部平台、抖音、快手、视频号、小红书（显示范围受平台配置与发行模式影响）
- **关键词搜索**: 在搜索框中输入账号昵称或关键词进行模糊搜索
  - 支持实时搜索(300ms防抖)

### 3. 添加账号

点击"添加账号"按钮,支持以下方式添加账号:

#### 3.1 浏览器登录方式

当前添加账号流程以 `src/ui/pages/account/view.py` 为准，采用“先占位、后更新”的方式：先创建待登录账号记录和 `profile_folder_name`，再打开对应平台浏览器，最后用登录结果更新占位账号。账号数据目录统一使用 `PathManager` 生成的 `%LOCALAPPDATA%\WeMediaBaby\data\{platform}\{profile_folder_name}`。

**平台差异化处理**：

- **普通平台（抖音、快手、视频号等）**：通过 Playwright 持久化浏览器上下文打开登录页，登录监控成功后提取 Cookie、昵称与状态。
- **小红书**：跳过指纹配置，使用 `DetachedChromeLauncher` 打开普通 Chrome Profile；用户关闭 Chrome 后，`XhsProfileSyncService` 会尝试通过 `ChromiumCookieReader` 与本地身份读取器同步 Cookie、昵称和在线状态。
- **发布可用性**：账号页可维护平台账号，不等于该平台已经接入统一发布入口；小红书发布插件当前未注册到 `PluginManager.PLUGIN_REGISTRY`。

**添加账号流程**：

1. 点击“添加账号”按钮。
2. 选择平台，系统创建待登录占位账号和独立 profile 目录。
3. 根据平台打开对应浏览器：自动化平台统一使用 Patchright 控制本地 Chrome 持久化上下文，小红书登录仍可使用独立普通 Chrome 模式。
4. 用户在浏览器中手动完成登录。
5. 系统同步 Cookie、昵称、头像和登录状态，更新占位账号记录。
6. 账号列表触发刷新，其他页面下拉框通过数据库读取最新账号。

#### 3.2 当前平台边界

- **抖音**：OSS 默认开放，支持账号登录维护与单次发布。
- **快手**：插件代码已注册，按发行模式与权限入口开放。
- **视频号**：Pro feature flag 开放，支持账号登录维护与发布插件入口。
- **小红书**：支持普通 Chrome 登录维护和 Cookie/身份同步；统一发布入口未注册，不能按“已可自动发布”描述。

#### 3.3 自动昵称提取

系统会自动从登录页面提取账号昵称:

- 优先从页面元素提取
- 如果页面提取失败,尝试从Cookie提取
- 如果都失败,使用默认名称"新账号\_{平台}"

### 4. 删除账号

选中一个或多个账号后,点击"删除账号"按钮:

#### 4.1 删除确认

- 弹出确认对话框,显示要删除的账号信息
- 提供"同时删除Cookie和发布记录"复选框(默认勾选)

#### 4.2 删除内容

- **数据库记录**: 删除账号的基本信息
- **Cookie 文件**: 删除账号目录下的 `cookies.json`
- **浏览器数据**: 删除 `browser/user_data` 等浏览器持久化目录（含 Chromium Cookie 库、缓存等）
- **发布记录**: 可选删除该账号的所有发布记录

### 5. 刷新列表

点击"刷新列表"按钮,重新加载账号列表:

- 从数据库获取最新的账号信息
- 更新账号的登录状态
- 刷新统计数据

### 6. 右键菜单操作

在账号列表中右键点击账号,可以执行以下操作:

- **切换账号**: 切换到该账号并打开浏览器
- **更新Cookie**: 手动更新账号的Cookie信息
- **查看详情**: 查看账号的详细信息
- **删除账号**: 删除选中的账号

### 7. 账号验证

系统会自动验证账号的登录状态:

- **Cookie验证**: 检查Cookie文件是否存在且有效
- **HTTP验证**: 通过HTTP请求验证账号是否在线
- **状态更新**: 自动更新账号的登录状态

## 浏览器方案

账号维护默认使用本机 Chrome 持久化 Profile。普通平台通过 Playwright 服务打开可见浏览器并监控登录状态；小红书使用普通 Chrome 脱离 Playwright 维护登录态，关闭浏览器后再同步 Cookie 与身份信息。旧版“内置 `QWebEngineView` 混合方案”不再作为当前账号添加主流程描述。

## Cookie管理

### Cookie存储

- Cookie 以 **明文 JSON**（`cookies.json`）存储在本地账号目录下
- 规范路径：`%LOCALAPPDATA%\WeMediaBaby\data\{platform}\{profile_folder_name}\cookies.json`（目录名以数据库中的 `profile_folder_name` 为准，不是展示昵称）
- 浏览器内登录态另由同目录下 `browser\user_data` 持久化；关闭浏览器时可额外导出 `browser\storage_state.json` 作快照（业务读取仍以 `cookies.json` 为准）

### Cookie清理

删除账号时可选择清理 Cookie 与数据目录:

- 删除账号根目录下的 `cookies.json`
- 删除整个账号 profile 目录（含 `browser\user_data` 等）
- 确保重新登录时是全新的浏览器环境

## 使用场景

1. **首次使用**: 添加第一个账号,开始使用媒小宝
2. **多账号管理**: 添加多个平台的多个账号,统一管理
3. **账号维护**: 定期检查账号状态,及时处理离线账号
4. **Cookie更新**: 当账号登录过期时,手动更新Cookie
5. **账号清理**: 删除不再使用的账号,释放存储空间

## 注意事项

### 登录安全

- 所有登录操作在本地浏览器中完成,不经过第三方服务器
- Cookie 以本地明文文件保存，请妥善保管数据目录、勿外传 `cookies.json`
- 建议定期更新 Cookie,保持账号活跃

### 删除账号

- 删除账号前请确认是否需要保留发布记录
- 默认勾选"同时删除Cookie和发布记录",避免残留数据
- 删除后无法恢复,请谨慎操作

### 账号状态

- 在线状态不代表账号一定可用,仅表示Cookie有效
- 建议定期手动验证账号状态
- 如果账号频繁离线,可能是平台安全策略导致,建议手动登录

### 昵称提取

- 快手账号需要导航到创作者中心才能提取昵称
- 如果昵称提取失败,可以手动修改账号昵称
- 昵称仅用于显示,不影响账号功能

## 常见问题

### Q: 添加账号后显示"新账号\_{平台}",如何修改?

A: 这是昵称提取失败的默认名称。可以通过以下方式解决:

1. 重新添加账号,确保登录后停留在创作者中心页面
2. 使用"更新Cookie"功能重新提取昵称
3. 手动修改账号昵称(功能开发中)

### Q: 删除账号后重新添加,为什么还是显示原来的账号?

A: 可能是浏览器Cookie未清理干净。解决方法:

1. 删除账号时确保勾选"同时删除Cookie和发布记录"
2. 重启软件后再添加账号
3. 手动清理浏览器user_data目录

### Q: 账号状态显示离线,但实际可以登录?

A: 这是Cookie验证失败导致的。解决方法:

1. 点击"刷新列表"重新验证
2. 使用"更新Cookie"功能更新Cookie
3. 重新添加账号

### Q: 支持哪些平台?

A: 账号页会按平台配置和发行模式展示可维护平台；当前主线需要区分“账号维护”和“发布入口”：

- 抖音：账号维护与发布入口默认开放。
- 快手、视频号：账号维护和发布入口按发行模式/权限入口开放。
- 小红书：账号普通 Chrome 登录维护已落地，发布入口尚未注册。

更多平台以 `config/feature_flags.py`、`config/platforms/` 与 `PluginManager.PLUGIN_REGISTRY` 的同步状态为准。
