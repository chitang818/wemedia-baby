## 4. 主要技术特性

- **本地 Cookie 存储**：平台 Cookie 以明文 `cookies.json` 与同目录下 Chromium `user_data` 持久化在本地 `AppData/data/{platform}/{profile}/`，不经过任何第三方服务器；请妥善保管数据目录。
- **浏览器方案可配置**：支持"纯净方案 (Undetected Playwright)"和"混合方案 (Playwright + QWebEngineView)"两种浏览器驱动模式，可在设置中切换。
- **HTTP 在线状态验证**：刷新列表时，对每个账号发起真实 HTTP 请求，准确判断 Cookie 是否仍有效，而非仅依赖本地文件存在性。
- **自动昵称提取**：登录后从页面 DOM 元素或 Cookie 字段中自动提取账号昵称，无需手动输入。
