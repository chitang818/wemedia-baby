## 1. 功能概述

指纹浏览器是本软件账号隔离与反风控体系的基础层。通过对 Playwright 浏览器启动时注入 JavaScript，伪造各类浏览器指纹参数，使不同账号呈现出不同且自洽的运行环境特征，降低平台批量检测命中率。

---

## 2. 指纹参数伪造

### 2.1 基础指纹

| 参数 | 说明 |
| :--- | :--- |
| `User-Agent` | 浏览器版本标识字符串 |
| 屏幕分辨率 | `screen_width / height / avail_width / avail_height` |
| 时区 | 固定为 `Asia/Shanghai`（中国大陆）|
| 语言 | 主语言 `zh-CN`，附列 `zh / en` |

### 2.2 硬件指纹

| 参数 | 可选值 |
| :--- | :--- |
| CPU 核心数（`hardware_concurrency`）| 4 / 8 / 12 / 16 |
| 内存大小（`device_memory`）| 4 / 8 / 16 / 32 GB |
| 显卡信息（`webgl_renderer / vendor`）| WebGL 渲染器、供应商字符串 |

### 2.3 高级指纹

| 参数 | 说明 |
| :--- | :--- |
| Canvas 指纹 | 画布渲染噪声注入 |
| WebGL 指纹 | 3D 渲染参数伪造 |
| AudioContext 指纹 | 音频上下文输出噪声 |
| 字体列表 | 常见系统字体模拟 |

## 3. 反检测技术

### 3.1 自动化工具检测绕过

通过 Playwright 启动时注入脚本，清除以下自动化工具痕迹：
- 删除 `window.navigator.webdriver` 等 Playwright/Puppeteer 特有属性
- 伪造 `chrome.runtime`、`window.external` 等对象
- 清除 14 个常见自动化检测标识

### 3.2 Headless 模式检测绕过

- 伪造 `window.outerWidth` / `outerHeight`（避免为 0）
- 补全 `chrome.runtime` 对象（Headless 通常缺失）

### 3.3 WebRTC IP 泄露防护

- 拦截 `RTCPeerConnection`，过滤真实本地 IP 地址，防止 WebRTC 旁路探测

### 3.4 其他防护

- Media Devices 伪造（麦克风/摄像头设备列表）
- Permissions API 模拟（9 种权限）
- `Intl` 国际化对象一致性对齐
- Battery API 伪造

## 4. 指纹一致性检查（`FingerprintConsistencyChecker`）

**源码**：`src/infrastructure/browser/fingerprint_checker.py`

每次生成或加载指纹后，自动执行4项一致性校验并自动修复：

| 检查项 | 规则 |
| :--- | :--- |
| **屏幕参数** | `avail_width ≤ screen_width`；`avail_height < screen_height`；`color_depth == pixel_depth` |
| **硬件参数** | CPU ≥12 核时内存不得 <8G；CPU ≤4 核时内存不得 >16G |
| **UA 与 Platform** | User-Agent 含 `Windows` → Platform 为 `Win32`；含 `Mac` → `MacIntel`；移动UA → 修复 `maxTouchPoints > 0` |
| **语言与时区** | `locale` 以 `zh` 开头时，`timezone_id` 强制修正为 `Asia/Shanghai`；`languages[0]` 与 `locale` 保持一致 |

## 5. 指纹持久化

| 文件 | 路径 | 说明 |
| :--- | :--- | :--- |
| 指纹配置 | `data/{platform}/{account}/browser/fingerprint_config.json` | 每账号独立存储，下次打开浏览器自动加载 |

- **生成方式**：随机生成（推荐，自动生成所有参数）或自定义（手动选择部分参数，其余仍随机）
- **修改建议**：同一账号应保持指纹一致，频繁修改可能触发平台风控

## 6. 行为模拟（`HumanBehavior`）

**源码**：`src/infrastructure/browser/human_behavior.py`

提供多种拟人行为工具方法，发布流程中的防风控层调用这些方法：

| 方法 | 说明 |
| :--- | :--- |
| `mouse_move()` | 三次贝塞尔曲线鼠标移动（20-40步分段，每步添加 ±1px 微抖动）|
| `type_text()` | 逐字符输入，延迟 50-150ms，大写/数字/符号延迟 ×1.5，2% 概率打错字并 Backspace 修正 |
| `scroll()` | 分段滚动（5-10步），每段随机停留 0.3-1.5s 模拟阅读 |
| `click_in_bounds()` | 在元素有效区域内随机选点，贝塞尔移动后点击（18-35步），避免持续定点中心 |
| `random_delay()` | 简单随机延迟（毫秒级）|
| `click_with_delay()` | 点击前后各插入随机延迟 |
| `hover_element()` | 悬停在元素上 0.5-2s |
| `read_page()` | 随机阅读页面 2-8s（含随机滚动）|

## 7. 浏览器方案说明

**源码**：`src/infrastructure/browser/browser_manager.py`

当前账号浏览器以 `UndetectedBrowserManager` 为核心，实际启动策略由 `src/infrastructure/browser/browser_launch_policy.py` 读取 app_config 决定：

| 模式 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| `real_browser`（默认） | 使用本机 Chrome 持久化上下文，尽量减少 JS 指纹改写和异常启动参数 | 当前主路径 |
| `compat_stealth` | 保留 legacy stealth 脚本和部分指纹改写，兼容旧环境 | 旧账号或特殊机器排障 |
| 小红书 `detached_chrome` 登录维护 | 账号页打开普通 Chrome，不附加 Playwright，关闭后读取 Profile 同步 | 小红书登录/账号维护 |

## 8. IP 地理位置匹配（`ip_matcher.py`）

**源码**：`src/infrastructure/browser/hardware_profiles.py`

使用代理时的可选功能，根据代理 IP 的实际地理位置，自动调整指纹的时区、语言、Locale 设置，保持 IP 与浏览器指纹的一致性。
