## 2. 界面主要板块

### 2.1 欢迎语（单行）

- 展示用户名、当天日期与「账号与发布统计」提示，占用更少纵向空间。

### 2.2 数据统计卡片（顶部一行 4 格）

- **今日发布**：当天发布任务数；副标题为成功 / 失败细分。
- **待执行任务**：批量任务或待发布页签队列；副标题为等待 / 执行中或批量完成率。
- **发布成功率**：近 7 天成功率；副标题为近 7 天完成条数。
- **素材库（合并）**：视频与图片库素材总数；鼠标悬停数字可查看已占用 / 未占用明细。

### 2.3 公告栏（默认展开，可折叠）

- 位于 KPI 行下方、快速操作区上方；可点击标题栏收起。
- 每条公告独占一行：左侧彩色图标、标题与正文以「·」分隔，正文过长时末尾省略显示。

### 2.4 快速操作区

- 位于公告栏下方、账号统计/发布统计双列区上方。
- 2 行 × 3 列紧凑卡片（约 64px 高），六个常用入口：添加账号、单/多视频任务、发布任务、单/多图文任务。

### 2.5 账号统计（半宽，与发布统计并排）

- **顶部摘要**：账号总数（全页仅此处展示总量）、在线 / 离线、已接入平台数。
- **下方横向条形统计**：顶部彩色堆叠条总览占比，每行展示平台名、数量、占比与渐变进度条；平台超过 5 个时合并为「其他」。

### 2.6 发布统计（与账号统计并排，各占半宽）

- 与「账号统计」卡片同一行左右并列（约 1:1 宽度），高度对齐（约 300px）。
- 展示**全部账号**的发布节奏：账号名前**绿点**表示在线、**红点**表示离线；列内容为账号名、**已发布最晚时间**、**到期提醒**（今天 / 剩余 N 天 / 已逾期等；离线账号第三列为「账号离线」）。在线账号按紧急程度优先排序，离线账号靠后；半宽布局下账号名可缩短显示，三列均保留。

## 3. 信息刷新机制

- 页面可见时约每 60 秒自动刷新；账号更新、发布队列变化会触发 debounce 刷新。
- 仪表盘与媒体库统计均有内存与磁盘缓存，冷启动可秒开上次数据。

## 4. 深色/浅色主题适配

工作台组件均跟随应用主题切换配色。
