## 1. 概述

为保持项目 UI 的统一性和交互体验的一致性，特制定本弹窗组件标准化规范。所有新开发的弹窗应遵循本规范，现有弹窗在重构时也应逐步对齐。

项目主要基于 `qfluentwidgets` 库构建 UI，弹窗统一基于 `MessageBoxBase` 进行扩展；**业务弹窗应优先继承** `src.ui.components.base_dialog` 中的 **`AppMessageBoxBase`**（在 `MessageBoxBase` 之上统一顶栏与关闭按钮、**父窗口解析为顶层窗口**以保证全窗遮罩，以及 **ESC 快捷键** 与子控件焦点兼容）。

---

## 2. 弹窗分类

项目中存在三种弹窗形式，适用于不同场景：

| 类型 | 基类 | 适用场景 | 示例 |
|------|------|----------|------|
| **业务弹窗** | `AppMessageBoxBase`（推荐）或 `MessageBoxBase` | 需要自定义 UI 的表单、配置、选择类弹窗 | 登录、账号选择、时间配置 |
| **轻量提示/确认** | `fluent_dialogs` 工具函数 | 仅需标题+文本的信息提示、警告、确认框 | 删除确认、操作成功/失败 |
| **原生窗口弹窗** | `QDialog` | 需要独立窗口的特殊场景（如浏览器控制） | Playwright 登录、浏览器控制 |

### 2.1 选择原则

```
需要自定义 UI 布局？ → AppMessageBoxBase / MessageBoxBase（业务弹窗）
只需要标题 + 文本 + 确定/取消？ → fluent_dialogs 工具函数
需要独立窗口或系统级交互？ → QDialog
```

选用 **`QDialog`** 时，建议与 `AppMessageBoxBase` 对齐体验：父窗口使用 `resolve_top_level_window_parent`，ESC 使用 `install_escape_reject_shortcut`（均见 `src.ui.components.base_dialog`）。

## 3. 业务弹窗规范（MessageBoxBase / AppMessageBoxBase）

### 3.1 继承

**推荐**：继承 `AppMessageBoxBase`，构造函数传入 **`header_title`**，由基类在白色卡片**最上方**生成顶栏：**左侧** `SubtitleLabel` 显示弹窗主标题，**右侧**为关闭按钮（与主流桌面软件一致，且与取消/ESC 等价）。

```python
from src.ui.components.base_dialog import AppMessageBoxBase

class MyDialog(AppMessageBoxBase):
    def __init__(self, parent=None):
        super().__init__(parent, header_title="我的弹窗")
        # 勿再将主标题 SubtitleLabel 放入 viewLayout
        self.widget.setMinimumWidth(400)
        # ... 业务内容只加到 self.viewLayout ...
```

若直接继承 `qfluentwidgets.MessageBoxBase`，需自行保证风格一致，且**必须**自行处理父窗口解析（见 **§3.5**），否则易出现遮罩不覆盖左侧导航等问题；新项目请优先使用 `AppMessageBoxBase`。

```python
from qfluentwidgets import MessageBoxBase
from src.ui.components.base_dialog import resolve_top_level_window_parent

class MyDialog(MessageBoxBase):
    def __init__(self, parent=None):
        super().__init__(resolve_top_level_window_parent(parent))
```

**降级处理**：如果 `qfluentwidgets` 不可用，回退至 `QDialog` 或 `QWidget`：

```python
try:
    from qfluentwidgets import MessageBoxBase
    FLUENT_WIDGETS_AVAILABLE = True
except ImportError:
    FLUENT_WIDGETS_AVAILABLE = False
    from PySide6.QtWidgets import QDialog
    MessageBoxBase = QDialog

class MyDialog(MessageBoxBase if FLUENT_WIDGETS_AVAILABLE else QWidget):
    ...
```

### 3.2 顶栏标题栏（必须）

- **主标题**只能通过 `super().__init__(..., header_title="...")` 设置，显示在顶栏左侧，与右上角关闭按钮同一行。
- **禁止**将主标题 `SubtitleLabel` 再添加到 `viewLayout` 顶部（会造成双标题或位置不符合规范）。
- 顶栏创建后，实例上的 **`self.titleLabel`** 指向该 `SubtitleLabel`，可在运行动态修改文案（例如 `AccountSelectionDialog` 在「添加到账号组」场景下 `setText`）。
- 内容区内仍可使用 `SubtitleLabel` / `BodyLabel` 作为**区块小标题**（如详情里的「基本信息」），与顶栏主标题区分。

### 3.3 初始化顺序

`__init__` 中的初始化应按以下顺序执行：

```python
def __init__(self, parent=None):
    super().__init__(parent, header_title="标题")
    # 1. 设置最小宽度（可选）
    self.widget.setMinimumWidth(400)
    # 2. 构建业务 UI（仅内容区，不含主标题）
    self._setup_ui()
    # 3. 配置底部按钮
    self.yesButton.setText("确定")
    self.cancelButton.setText("取消")
    # 4. 重排按钮顺序
    self._reorder_buttons()
```

### 3.4 宽度设置

- 最小宽度建议：简单弹窗 `300-400`，中等弹窗 `500-600`，复杂弹窗 `680+`
- 使用 `self.widget.setMinimumWidth()` 设置
- 如需限制高度：`self.widget.setMinimumHeight()`

### 3.5 父窗口与全窗口遮罩（必读）

`qfluentwidgets` 的 `MaskDialogBase`（`MessageBoxBase` 的基类）在初始化时按 **Qt 父控件的宽高** 铺开半透明遮罩。若父控件是主窗口里的**子页面**（例如 `FluentWindow` 中 `stackedWidget` 内的页面），遮罩只会盖住这一块区域，**左侧导航栏往往不会变暗**，与「打开弹窗后整窗背景压暗」的规范不一致。

**`AppMessageBoxBase` 已在构造函数中统一处理**：将调用方传入的 `parent` 解析为 **`parent.window()`**（顶层 `QWidget` 窗口），再交给 `MessageBoxBase`。因此业务子类可直接：

```python
super().__init__(parent, header_title="我的弹窗")
```

其中的 `parent` 可以是当前页面、表格、`self` 等任意祖先在主窗口内的控件，**无需**再手写 `parent.window()`。

若**不**经过 `AppMessageBoxBase`（例如直接 `MessageBoxBase(parent)`、或独立 `QDialog`），请使用与基类相同的解析规则，避免遮罩范围错误：

```python
from src.ui.components.base_dialog import resolve_top_level_window_parent

super().__init__(resolve_top_level_window_parent(parent))
```

**非 MessageBox 系的模态窗口**（如 `QProgressDialog`）若希望模态范围与主窗口一致，建议父控件同样使用 `self.window() or self`。

## 4. UI 元素规范

### 4.1 标题与文本

| 元素 | 组件 | 说明 |
|------|------|------|
| **主标题（弹窗名）** | 顶栏 `SubtitleLabel` | 通过 `header_title` 传入，**不要**放入 `viewLayout` |
| 内容区说明 | `BodyLabel` | 次要信息设为灰色 |
| 内容区分块标题 | `SubtitleLabel` / `BodyLabel` | 表单内小节标题，可与顶栏主标题并存 |
| 小字提示 | `CaptionLabel` | 辅助说明 |

```python
# 主标题：仅在 super 中指定
super().__init__(parent, header_title="弹窗标题")

desc = BodyLabel("说明文本", self.widget)
desc.setTextColor('#999999', '#999999')
self.viewLayout.addWidget(desc)
```

### 4.2 布局

- 内容添加到 `self.viewLayout`
- 不同段落间使用 `self.viewLayout.addSpacing(8)` 或 `addSpacing(16)`
- 复杂布局可嵌套 `QHBoxLayout` / `QVBoxLayout` 再用 `addLayout` 添加

### 4.3 底部按钮

**按钮排序**：统一为**取消在左，确定在右**。

```python
def _reorder_buttons(self):
    """取消在左，确定在右"""
    button_layout = getattr(self, "buttonLayout", None)
    if button_layout is None:
        button_layout = self.buttonGroup.layout()
    if button_layout:
        button_layout.removeWidget(self.yesButton)
        button_layout.removeWidget(self.cancelButton)
        button_layout.addWidget(self.cancelButton)
        button_layout.addWidget(self.yesButton)
```

**按钮文本**：

| 场景 | 确定按钮 | 取消按钮 |
|------|----------|----------|
| 默认 | "确定" | "取消" |
| 登录/注册 | "登录" / "注册" | "取消" |
| 保存配置 | "保存" | "取消" |
| 多步流程 | "确定" / "下一步" | "上一步" |
| 仅展示 | "关闭" | 隐藏 (`self.cancelButton.hide()`) |
| 删除确认 | "删除" | "取消" |

**隐藏按钮**：不需要某个按钮时使用 `hide()` 而非 `setVisible(False)`。

## 5. 交互规范

### 5.1 遮罩与背景

`MessageBoxBase` 自带半透明遮罩层，提供模态弹窗的视觉反馈（背景变暗）。

**必须遵守**：
- **不要**调用 `self.setMaskColor(QColor(0, 0, 0, 0))`
- 完全透明的遮罩会导致：背景不变暗、ESC 键失效、用户无法感知模态状态
- 保持默认遮罩即可

**遮罩是否盖住整个主窗口（含左侧导航）**：取决于 Qt 父控件是否为**顶层窗口**，详见 **§3.5**；继承 `AppMessageBoxBase` 时已自动按顶层窗口挂载。

**嵌套弹窗**：如果弹窗内部需要再打开弹窗（如添加账号流程中 平台选择 → 指纹配置），子弹窗的默认遮罩即可正常工作，无需额外处理。

### 5.2 键盘交互

**ESC 关闭**（必须保证「任意子控件有焦点时也能关闭」）：

仅重写对话框自身的 `keyPressEvent` **不够**：焦点在 `LineEdit`、`PlainTextEdit`、`TableWidget` 等子控件上时，按键事件往往到不了对话框，`Esc` 可能无效。

- **`AppMessageBoxBase`** 已统一实现：顶栏关闭按钮、`keyPressEvent(Escape → reject)`，以及 **`QShortcut`（上下文 `WidgetWithChildrenShortcut`）** 绑定 `reject()`。继承该基类的业务弹窗**一般无需再重复实现 ESC 逻辑**（保留 `super().keyPressEvent` 即可；若子类仍重写 `keyPressEvent`，请继续 `reject()` 后 `return` 或交给基类）。
- **独立 `QDialog`**（不继承 `AppMessageBoxBase`）建议在 `__init__` 中调用：

```python
from src.ui.components.base_dialog import install_escape_reject_shortcut

install_escape_reject_shortcut(self)
```

（可与 `resolve_top_level_window_parent` 配合使用。）

**参考实现**（无 Shortcut 时的兜底写法，优先以基类/工具函数为准）：

```python
def keyPressEvent(self, event):
    if event.key() == Qt.Key.Key_Escape:
        self.reject()
        return
    super().keyPressEvent(event)
```

**回车确认**：关键输入框应绑定 `returnPressed` 到确认逻辑：

```python
self.name_edit.returnPressed.connect(self._on_confirm)
```

### 5.3 按钮绑定

`yesButton` 默认绑定 `accept()`，`cancelButton` 默认绑定 `reject()`。

如需自定义校验，应先断开默认绑定：

```python
self.yesButton.clicked.disconnect()
self.yesButton.clicked.connect(self._on_confirm)

def _on_confirm(self):
    if not self._validate():
        return
    # 校验通过
    self.accept()
```

### 5.4 弹窗调用

**同步调用**（推荐）：

```python
# 继承 AppMessageBoxBase 时，传当前页面即可，基类会解析为顶层窗口
dialog = MyDialog(self)
if dialog.exec():
    result = dialog.get_result()
```

**异步调用**（用于需要 `await` 的场景）：

```python
dialog = AccountSelectionDialog(parent)  # 与同步场景相同，基类负责 parent → window()
dialog.set_data(accounts, groups)
dialog.show()
result = await future  # 通过 finished 信号设置 future
```

### 5.5 parent 选择

| 场景 | parent 取值 | 说明 |
|------|-------------|------|
| 从主窗口内页面/控件弹出（`AppMessageBoxBase`） | `self` 或任意在主窗口内的控件 | 基类内部转为 `window()`，遮罩覆盖**整块主窗口（含左侧导航）** |
| 从主窗口内页面弹出（直接 `MessageBoxBase` / 手写遮罩） | `self.window() or self` 或 `resolve_top_level_window_parent(self)` | 见 **§3.5**，否则易出现仅右侧内容区变暗 |
| 从弹窗中弹出子弹窗 | `self` 或 `self.parent()` | 子弹窗的 `window()` 仍为最外层主窗口时，遮罩同样覆盖该顶层窗口 |
| 独立 `QDialog`（无 Fluent 遮罩） | `resolve_top_level_window_parent(self)` 推荐 | 模态与居中相对主窗口更一致 |
| `QProgressDialog` 等 | `self.window() or self` | 避免进度框只模态住内容子区域 |

## 6. 轻量提示规范

### 6.1 fluent_dialogs 工具函数

对于只需标题 + 文本的简单弹窗，**必须使用** `fluent_dialogs` 工具函数，**禁止**直接使用 `QMessageBox` 或 `qfluentwidgets.MessageBox`：

```python
from src.ui.utils.fluent_dialogs import show_info, show_warning, show_error, show_confirm

# 信息提示（仅确定按钮）
show_info(self, "提示", "操作完成")

# 警告提示（仅确定按钮）
show_warning(self, "警告", "该操作不可撤销")

# 错误提示（仅确定按钮）
show_error(self, "错误", "文件读取失败")

# 确认框（确定/取消），返回 bool
if show_confirm(self, "确认删除", "确定要删除这条记录吗？"):
    do_delete()

# 三按钮（是/否/取消），返回 'yes' | 'no' | 'cancel'
from src.ui.utils.fluent_dialogs import show_yes_no_cancel
result = show_yes_no_cancel(self, "保存", "是否保存当前修改？")
```

### 6.2 InfoBar 轻量反馈

对于操作结果的**即时反馈**（无需用户交互），使用 `InfoBar` 而非弹窗：

```python
from qfluentwidgets import InfoBar, InfoBarPosition

# 成功
InfoBar.success("操作成功", "已保存配置", parent=self, position=InfoBarPosition.TOP, duration=2000)

# 警告
InfoBar.warning("提示", "请先选择账号", parent=self, position=InfoBarPosition.TOP, duration=3000)

# 错误
InfoBar.error("失败", str(e), parent=self, position=InfoBarPosition.TOP, duration=5000)
```

**选择依据**：

| 场景 | 方式 | 示例 |
|------|------|------|
| 需要用户确认才能继续 | `show_confirm` / 自定义弹窗 | 删除确认 |
| 操作成功/失败的即时通知 | `InfoBar` | 保存成功、加载失败 |
| 表单校验不通过 | `InfoBar.warning` | 请输入用户名 |
| 展示详细信息 | 自定义弹窗 | 发布记录详情 |

## 7. QDialog 弹窗规范

少数特殊场景需要使用 `QDialog`（如需要独立窗口标题栏、系统级交互）：

- `QDialog` 原生支持 ESC 关闭（通过 `reject()`），无需额外处理
- 应设置 `self.setModal(True)` 确保模态行为
- 应设置 `self.setWindowTitle(...)` 提供标题

## 8. 多步流程规范

添加账号等多步流程弹窗的处理模式：

```python
class AddAccountFlow:
    def show(self):
        # 第一步：选择平台
        step1 = PlatformSelectDialog(self.parent)
        if not step1.exec():
            return None

        # 第二步：配置指纹
        step2 = FingerprintConfigDialog(self.parent)
        step2.cancelButton.setText("上一步")  # 取消按钮改为"上一步"
        if not step2.exec():
            return self.show()  # 返回第一步

        return step2.get_result()
```

注意事项：
- 第二步及以后的取消按钮文字改为"上一步"
- 用户点击"上一步"时递归回到第一步
- 每一步都是独立的 `MessageBoxBase` 弹窗

## 10. 代码模板

### 10.1 标准业务弹窗

```python
from PySide6.QtCore import Qt
from qfluentwidgets import BodyLabel, LineEdit
from src.ui.components.base_dialog import AppMessageBoxBase

class MyDialog(AppMessageBoxBase):
    """弹窗功能说明"""

    def __init__(self, parent=None):
        super().__init__(parent, header_title="标题")
        self.widget.setMinimumWidth(400)

        self._setup_ui()

        self.yesButton.setText("确定")
        self.cancelButton.setText("取消")
        self._reorder_buttons()

    def _setup_ui(self):
        desc = BodyLabel("说明文本", self.widget)
        desc.setTextColor('#999999', '#999999')
        self.viewLayout.addWidget(desc)

        self.name_edit = LineEdit(self.widget)
        self.name_edit.setPlaceholderText("请输入...")
        self.name_edit.returnPressed.connect(self._on_confirm)
        self.viewLayout.addWidget(self.name_edit)

    def _reorder_buttons(self):
        button_layout = getattr(self, "buttonLayout", None)
        if button_layout is None:
            button_layout = self.buttonGroup.layout()
        if button_layout:
            button_layout.removeWidget(self.yesButton)
            button_layout.removeWidget(self.cancelButton)
            button_layout.addWidget(self.cancelButton)
            button_layout.addWidget(self.yesButton)

    def keyPressEvent(self, event):
        if event.key() == Qt.Key.Key_Escape:
            self.reject()
            return
        super().keyPressEvent(event)

    def _on_confirm(self):
        name = self.name_edit.text().strip()
        if not name:
            from qfluentwidgets import InfoBar
            InfoBar.warning("提示", "请输入名称", parent=self, duration=2000)
            return
        self.accept()

    def get_result(self) -> str:
        return self.name_edit.text().strip()
```

### 10.3 自定义校验弹窗

```python
from src.ui.components.base_dialog import AppMessageBoxBase

class ValidatedDialog(AppMessageBoxBase):
    def __init__(self, parent=None):
        super().__init__(parent, header_title="保存")
        self.widget.setMinimumWidth(400)
        # ... UI 构建 ...

        self.yesButton.setText("保存")
        self.cancelButton.setText("取消")
        self._reorder_buttons()

        # 断开默认绑定，使用自定义校验
        self.yesButton.clicked.disconnect()
        self.yesButton.clicked.connect(self._on_save)

    def _on_save(self):
        if not self._validate():
            return
        self.accept()

    def _validate(self) -> bool:
        if not self.name_edit.text().strip():
            InfoBar.warning("提示", "名称不能为空", parent=self, duration=2000)
            self.name_edit.setFocus()
            return False
        return True
```

## 11. 常见错误与注意事项

### 11.1 禁止使用

| 禁止项 | 原因 | 替代方案 |
|--------|------|----------|
| `self.setMaskColor(QColor(0, 0, 0, 0))` | 遮罩完全透明，背景不变暗，ESC 失效 | 保持默认遮罩 |
| 直接使用 `QMessageBox` | 与 Fluent 风格不统一 | 使用 `fluent_dialogs` 工具函数 |
| 直接使用 `qfluentwidgets.MessageBox` | 无法保证按钮排序等规范 | 使用 `fluent_dialogs` 工具函数 |
| 在 `showEvent` 中重设遮罩颜色 | 导致每次显示都丢失遮罩 | 不要覆写 `showEvent` 来设置遮罩 |

### 11.2 常见陷阱

1. **parent 传错**：弹窗的 `parent` 应为主窗口（`self.window()`），而非页面本身，否则遮罩可能只覆盖局部区域
2. **按钮排序时机**：`_reorder_buttons()` 应在按钮文字设置之后调用
3. **异步弹窗竞态**：`exec()` 是同步阻塞调用，在 `asyncSlot` 中使用时需注意事件循环状态
4. **inputDialogCode 比较**：`MessageBoxBase.exec()` 返回值可用 `bool()` 判断，也可与 `QDialog.DialogCode.Accepted` 比较

## 12. Checklist

新建或重构弹窗时，逐项检查：

- [ ] 继承自 `AppMessageBoxBase`（或经评审后使用 `MessageBoxBase`）
- [ ] 设置了 `self.widget.setMinimumWidth(...)`
- [ ] **主标题**通过 `super(..., header_title="...")` 设置顶栏，**未**将主标题放入 `viewLayout`
- [ ] 按钮顺序为 [取消] [确定]（调用 `_reorder_buttons`）
- [ ] 按钮文字符合场景语义
- [ ] 实现了 `keyPressEvent` 支持 ESC 关闭
- [ ] 关键输入框绑定了 `returnPressed`
- [ ] **没有**调用 `setMaskColor(QColor(0, 0, 0, 0))`
- [ ] **没有**在 `showEvent` 中操作遮罩颜色
- [ ] parent 参数传入了正确的窗口引用
- [ ] 自定义校验弹窗先 `disconnect` 了 `yesButton` 的默认绑定
- [ ] 简单提示/确认使用了 `fluent_dialogs` 工具函数而非直接创建弹窗
