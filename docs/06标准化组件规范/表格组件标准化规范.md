## 一、适用范围

- 卡片内 `TableWidget` / `QTableWidget`，以**行为单位**选择，支持**多行**与批量操作（删除、导出等）。
- 需要 **Excel 式橡皮筋框选**（与矩形相交的行进入选区）的页面。
- 不适用于：单元格级编辑表、单选列表、树形控件（需另拟规范）。

---

## 二、核心标准

| 项目 | 规范值 |
|------|--------|
| **控件类型** | `RubberBandRowSelectTable`（取代 `TableWidget`，支持左键拖矩形框选行） |
| **`::item` padding** | `padding-left: 2px; padding-right: 2px;`（通过 `setCustomStyleSheet` 覆盖 Fluent 默认 16px） |
| **选择模式** | `ExtendedSelection` + `SelectRows` |
| **ResizeMode** | 数据列统一 `Interactive`（可拖拽）；序号/操作/固定码值列保持 `Fixed` |
| **对齐** | 长文本列（文件名、标题、简介、内容）`AlignLeft \| AlignVCenter`；其余居中 |
| **setObjectName** | 每张表设唯一英文 objectName，用于 QSS 精准定向 |

### 框选操作说明

`RubberBandRowSelectTable` 的框选行为：

- **无修饰键**：从空白处拖出矩形，与矩形相交的行被选中（替换当前选区）。
- **Ctrl**：越过拖动阈值后合并原选区与框内行（加选）。
- **Shift + 点选**：交给 Qt 原生扩展选择处理。
- **鼠标移出表格**：框选不中断（对 viewport 做了 `grabMouse`）。

## 三、选择行为（与 Excel / 系统表格对齐）

| 操作 | 预期行为 |
|------|----------|
| 单击行 | 选中该行，清除其余选区（由 `ExtendedSelection` + 默认处理完成）。 |
| **Ctrl + 单击** | 切换该行是否选中，保留其余行（系统默认）。 |
| **Shift + 单击** | 从当前锚点扩展到点击行（系统默认）；**不建议**再叠加自定义「Shift+拖动画框」，以免与系统 Shift 扩展冲突。 |
| **左键拖动（无修饰键）** | 超过**拖动阈值（4px）**后进入**框选**：选区**替换**为与橡皮筋矩形**相交**的所有数据行。 |
| **Ctrl + 左键拖动框选** | 超过阈值时**快照当前选区**，再与框内行**取并集**（并集在阈值触发瞬间确定）。 |
| **Ctrl+A** | 若表格有焦点，应全选（`ExtendedSelection` 默认支持，勿拦截键盘）。 |
| **Delete / Backspace**（可选） | 对选中行执行业务上的「删除选中」；快捷键作用域建议为 `WidgetShortcut`，避免误删他处焦点内容。 |

**说明**：

- 拖动阈值用于区分**单击选行**与**开始框选**，避免轻微手抖误触框选。
- 框选命中规则：在 **viewport 坐标系**下，每行用 `rowViewportPosition` + `rowHeight` 与矩形求交；行宽取 `viewport.width()`，保证横向任意位置拖框都能选中整行。

## 四、技术要点（必做）

### 4.1 崩溃防护：QRubberBand parent 必须是 self

```python
# 正确：parent=self（table 本体）
self._rubber = QRubberBand(QRubberBand.Shape.Rectangle, self)

# 错误：parent=viewport()，会导致 Fluent StyleSheetManager 崩溃
# self._rubber = QRubberBand(QRubberBand.Shape.Rectangle, self.viewport())
```

**原因**：Fluent 的 `StyleSheetManager` 在执行 `setBorderRadius` / `setCustomStyleSheet` 时，会通过 `CustomStyleSheetWatcher` 遍历 widget 子控件并重新应用样式。若 `QRubberBand` 是 `viewport()` 的子控件，StyleSheetManager 遍历到它时会触发 C 层 access violation（segfault），导致软件无提示崩溃。

**修复后**：将 `QRubberBand` 的 parent 改为 `self`（table 本体），Fluent 原生的 `setBorderVisible`、`setBorderRadius`、`setCustomStyleSheet` 均可安全调用，无需重写这些方法。

**坐标补偿**：由于 `QRubberBand` 的父控件变为 table，橡皮筋几何坐标需从 viewport 坐标系转换到 table 坐标系：

```python
def _vp_offset(self) -> QPoint:
    """viewport 左上角相对于 table 自身的偏移。"""
    vp = self.viewport()
    if vp is None:
        return QPoint(0, 0)
    return vp.mapToParent(QPoint(0, 0))

# 使用：
offset = self._vp_offset()
rb.setGeometry(vp_rect.translated(offset))
```

### 4.2 Viewport 事件过滤器（Fluent 滞后问题）

Fluent `TableWidget` 常在 **viewport** 上安装内部过滤器，直接重写 `mouseMoveEvent` 可能导致**拖动中选区高亮滞后**。

**标准做法**：对 `table.viewport()` 安装**独立** `QObject` 事件过滤器，且在 **Fluent 之前**注册（先 `installEventFilter`，先于内部过滤器收到事件）。在 `MouseMove` 中：若本次为**自定义框选拖动**，返回 `true` **吞掉事件**，避免内部逻辑干扰；单击、未达阈值时返回 `false` 交给默认逻辑。

### 4.3 鼠标移出表格仍持续框选

**标准做法**：在**首次**越过框选阈值时，对 `viewport()` 调用 `grabMouse()`；在**左键松开**时 `releaseMouse()`，并保证异常路径下也能释放（至少在 `MouseButtonRelease` 中释放）。

### 4.4 选区更新与重绘

每次程序化更新选区后，对 **viewport** 与 **verticalHeader** 调用 `repaint()`（比仅 `update()` 更易立刻看到高亮），减少拖动过程中的视觉延迟。

### 4.5 选区实现的效率

行集合确定后，若存在**多段连续行**，应合并为若干 `(lo, hi)` 区间，用 `QItemSelection` + `ClearAndSelect`（第一段）与 `Select`（后续段）设置，避免对每一行单独 `select` 造成不必要刷新。

### 4.6 表格基础属性

```text
setSelectionBehavior(SelectRows)
setSelectionMode(ExtendedSelection)
setEditTriggers(NoEditTriggers)          # 若业务为只读预览
setDragEnabled(False)
setDragDropMode(NoDragDrop)
viewport().setMouseTracking(True)
```

### 4.7 主题切换

橡皮筋 `QRubberBand` 的样式建议在 **`changeEvent`** 中响应 `PaletteChange` / `StyleChange` / `ThemeChange`，根据 `isDarkTheme()` 重新 `setStyleSheet`，避免切换深浅色后框选颜色仍停留在旧主题。

### 4.8 勿对整表 `setToolTip`

在 Fluent / 深色主题下，对整表设置 `setToolTip` 易出现**黑底长条提示**，遮挡内容。**标准做法**：在卡片内用 **`BodyLabel`**（可换行）说明多选方式；需要提示时仅对**按钮**等控件设置 `setToolTip`。

## 五、文本省略与内边距的关系说明

Fluent 默认 `::item` padding 为 `16px`（见 `table_view.qss`），是导致"文字显示少"的根源。各页面通过 `setCustomStyleSheet` 覆盖为 `2px`：

```
列宽（columnWidth）
 └─ Qt 样式框架切出「可排版矩形」
       ├─ 减去 QSS ::item padding-left + padding-right（本规范 2px×2 = 4px）
       ├─ 减去 QStyle::PM_FocusFrameHMargin × 2（约 4～8px，随系统主题）
       └─ = 实际文字矩形宽度
```

以 150px 列宽、padding 2px×2、系统边距 8px 为例：  
可用文字宽度 ≈ 150 − 4 − 8 = **138px** ≈ **9.9 个汉字**

## 八、右键菜单与选区协同

- **无当前选区**时右键某行：应先选中该行再出菜单，避免用户以为在操作「当前行」实际选区为空。
- **已有选区**且右键点在某**已选行**上：保留多选，菜单操作作用于**所有选中行**。
- **已有选区**且右键点在**选区外**的行上：改为**仅选中该行**再出菜单（与常见文件管理器行为一致）。
- 右键点在**空白区域**（无 item）：可保留原选区并仍弹出菜单（便于对已选批量操作）。

## 十二、已知限制

- **拖动中途松开 Ctrl**：当前实现以**按下左键时**是否按 Ctrl 决定是否为「追加并集」，中途松 Ctrl 不改变本次拖动模式（与部分 Excel 版本细节可能不同，属可接受简化）。
- **超大行数**：极端行数下频繁框选仍可能较重，可考虑节流或合并更新（一般业务预览表行数有限）。
- **Shift+拖动画框**：本规范**不推荐**，与 `ExtendedSelection` 的 Shift 语义易重叠。

## 十三、后续扩展

### 列宽持久化

用户拖宽某列后，可通过 `QSettings` 保存每列宽度，键名格式：

```
table/<objectName>/col<N>/width
```

首次安装无历史宽度时，使用第六节基准值。

### Tooltip 补全

被省略的单元格可在 `helpEvent` 里弹出完整文本。Fluent 已在 `TableItemDelegate` 中提供了 `ItemViewToolTipDelegate` 机制，可视需求启用。
