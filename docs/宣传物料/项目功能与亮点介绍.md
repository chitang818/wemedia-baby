# WeMediaBaby (媒小宝) - 自媒体全平台矩阵运营神器

## 📖 项目简介

WeMediaBaby（媒小宝）是一款专为自媒体创作者和运营团队打造的 **Windows 桌面端自动发布与管理工具**。它致力于解决多平台、多账号内容分发过程中的繁琐重复劳动，通过先进的浏览器自动化技术，帮助用户一键将视频或图文高效发布到各大主流创作者平台，实现真正的“一次创作，全网分发”。

---

## 🌟 亮点特性 (Highlights)

### 1. 🚀 真正的“全平台”一站式分发
深度适配市面上主流的自媒体平台，告别频繁切换网页的痛苦：
- **短视频与社区**：抖音、快手、微信视频号、B站 (Bilibili)、小红书、多多视频
- **图文与资讯**：今日头条、百家号、微博、企鹅号
- **插件化架构**：所有平台适配均采用高内聚的插件化设计，新平台接入极其迅速，持续进化。

### 2. 🛡️ 极致安全的浏览器自动化与反风控
- 底层采用经过特殊深度优化的 **Patchright** 浏览器自动化框架，模拟真实人类操作轨迹，有效规避平台机器检测。
- 严格的**账号环境隔离**（Profile 隔离），每个账号拥有独立的指纹和缓存，确保矩阵运营时不串号、防关联。
- 本地化 Cookie 和登录态持久保存，免除频繁扫码登录的困扰。

### 3. 💻 现代化 Fluent Design 桌面级体验
- 抛弃臃肿的 Electron 套壳方案，基于 **PySide6 + Fluent Design** 打造原生的现代化 Windows 界面。
- 视觉惊艳、交互丝滑，提供真正桌面级的极速响应。
- 引入 `qasync` 异步非阻塞架构，即使后台正在执行高并发的批量发布任务，前台操作依然流畅不卡顿。

### 4. ⚙️ 高效、智能、可靠的发布流水线
底层的发布引擎采用了极其严谨的 `Pipeline` 流水线模式，确保每一次发布的极高成功率：
1. **智能拦截**：发布前自动进行权限检查与媒体规格验证（大小、格式限制）。
2. **环境预热**：自动无感加载对应账号的安全隔离环境。
3. **拟人执行**：调用对应平台插件执行拟人化上传与信息填写。
4. **结果归档**：详细记录发布日志、状态及报错截图，方便追溯。

### 5. 🧩 社区开源与 Pro 企业级能力无缝融合
- **社区开源版 (Community)**：提供强大的底层自动化框架和核心发布能力，让技术极客和个人创作者自由定制。
- **Pro 进阶矩阵管理**：内置优雅的降级与开关逻辑，只需开启权限即可获得企业级矩阵能力，包括：**批量定时任务、本地素材与文案库、带货推广商品自动挂载、多维度全网数据中心、以及统一评论互动管理**。
