## 页面结构与技术特征

### 结构概要

- **是否存在 iframe**：否（主文档直连）
- **是否存在 Shadow DOM**：**是（closed 模式）** ← 关键！发布按钮在 `xhs-publish-btn` Web Component 的 **closed Shadow DOM** 内
- **是否存在 contenteditable**：描述区使用标准 textbox 元素
- **其他**：发布控件使用 Web Component 封装，宿主为 `xhs-publish-btn` 标签，Shadow DOM 为 **closed** 无法从外部访问

### 层级示意

```
主文档 body
  └─ .publish-page-container
      └─ .publish-page-content
          └─ xhs-publish-btn[is-publish="true"]  # Shadow Host (CLOSED!)
              └─ #shadow-root (closed) ← 无法从外部访问
                    └─ button.ce-btn.bg-red  ← 实际发布按钮（红色，文案：「发布」或「定时发布」）
                    └─ button.ce-btn  ← 暂存草稿按钮（文案：「暂存离开」）
```

### 对自动化的影响摘要

- **Playwright 建议策略**：
  1. **唯一可靠方法**：使用 `host.evaluate()` 在 Shadow DOM 内部执行点击
     ```python
     host = page.locator("xhs-publish-btn").first
     await host.evaluate("""(el) => {
         const btn = el.shadowRoot.querySelector('button.ce-btn.bg-red');
         if (btn) btn.click();
     }""")
     ```
  2. **⚠️ 重要限制**：由于是 **closed Shadow DOM**，以下方法均**无效**：
     - `page.locator("xhs-publish-btn >> button")` 穿透符
     - 在页面上下文中运行的 `page.evaluate()` 无法访问 `shadowRoot`
     - 直接点击宿主元素（`host.click()`）不会触发 Shadow 内按钮
     - `dispatchEvent` 或 `pointerdown/pointerup` 模拟点击
  3. **坐标点击（理论可行，未验证）**：使用 Playwright 的 `page.mouse.click(x, y)` 模拟真实鼠标点击
     ```python
     # 需要 Playwright 的 mouse API，不是 dispatchEvent
     coords = await host.evaluate("""(el) => {
         // 这个 evaluate 在扩展上下文运行，可能有权访问 shadowRoot
         const sr = el.shadowRoot;
         if (!sr) return null;
         const btn = sr.querySelector('button.ce-btn.bg-red');
         if (!btn) return null;
         const rect = btn.getBoundingClientRect();
         return { x: rect.x + rect.width/2, y: rect.y + rect.height/2 };
     }""")
     if coords:
         await page.mouse.click(coords['x'], coords['y'])
     ```
- **已知限制**：
  - Shadow DOM 为 **closed**，Playwright 标准 `locator` 无法穿透
  - 在页面上下文中运行的 JavaScript 无法访问 `shadowRoot` 属性
  - 宿主元素有 `submit-disabled="true/false"` 属性，需等待解除后才能点击
  - 定时发布模式下，`submit-text` 从「发布」变为「定时发布」，但 Shadow 内按钮选择器不变

### 关键元素记录

| 元素功能 | 文案/Placeholder | 标签类型 | role/type 属性 | 父级/上下文 | class（含哈希） | ref（若有） | 可稳定查询 | 建议 Playwright API | 建议作用域 | 排他信息 | 操作结果 |
|----------|-----------------|----------|----------------|------------|----------------|------------|------------|---------------------|------------|----------|----------|
| 发布按钮（立即） | 「发布」 | `button` | `type="button"` | Shadow 根目录下 | `ce-btn bg-red` | - | **需 evaluate** | `host.evaluate("...shadowRoot.querySelector('button.ce-btn.bg-red')...")` | Shadow 内 | 与「定时发布」按钮是同一个元素，文案动态变化 | 触发发布流程 |

### Shadow DOM 穿透策略

**❌ 策略 1：Playwright `>>` 穿透符（不可用）**
```python
# 对 closed Shadow DOM 无效！不要使用
page.locator("xhs-publish-btn >> button.ce-btn.bg-red")  # 会失败
```

**✅ 策略 2：host.evaluate() 访问 shadowRoot（推荐）**
```python
# 获取宿主元素
host = page.locator("xhs-publish-btn").first

# 方法 A：直接点击 Shadow 内按钮
await host.evaluate("""(el) => {
    const btn = el.shadowRoot.querySelector('button.ce-btn.bg-red');
    if (btn) btn.click();
}""")

# 方法 B：先检测按钮状态再点击
await host.evaluate("""(el) => {
    const sr = el.shadowRoot;
    if (!sr) return false;
    const btn = sr.querySelector('button.ce-btn.bg-red');
    if (!btn) return false;
    // 检查按钮是否可点击
    const rect = btn.getBoundingClientRect();
    if (rect.width < 20 || rect.height < 8) return false;
    btn.click();
    return true;
}""")
```

**✅ 策略 3：坐标点击（兜底）**
```python
# 解析按钮中心坐标
host = page.locator("xhs-publish-btn").first
coords = await host.evaluate("""(el) => {
    const sr = el.shadowRoot;
    if (!sr) return null;
    const btn = sr.querySelector('button.ce-btn.bg-red');
    if (!btn) return null;
    const rect = btn.getBoundingClientRect();
    return { 
        x: rect.x + rect.width/2, 
        y: rect.y + rect.height/2 
    };""")

if coords:
```


### Closed Shadow DOM 的突破方法

**方法 1：Playwright 扩展上下文（推荐）**
```python
# Playwright 的 locator.evaluate() 在扩展上下文运行
# 可能有权访问 closed shadowRoot
host = page.locator("xhs-publish-btn").first
await host.evaluate("""(el) => {
    // 这个代码在扩展上下文运行，可能有特殊权限
    const sr = el.shadowRoot;
    if (!sr) {
        // 尝试通过内部方法访问
        for (let key of Object.getOwnPropertyNames(el)) {
            if (key.includes('shadow') || key.includes('root')) {
                const maybeRoot = el[key];
                if (maybeRoot && maybeRoot.querySelector) {
                    const btn = maybeRoot.querySelector('button.ce-btn.bg-red');
                    if (btn) { btn.click(); return true; }
                }
            }
        }
        return false;
    }
    const btn = sr.querySelector('button.ce-btn.bg-red');
    if (btn) { btn.click(); return true; }
    return false;
}""")
```

**方法 2：CDP 协议（高级）**
```python
# 使用 Chrome DevTools Protocol 直接访问 Shadow DOM
# 需要 Playwright 的 CDP 会话
cdp = await page.context.new_cdp_session(page)
# 通过 DOM 域命令访问 Shadow Root
node = await cdp.send('DOM.getNodeForNode', {
    'backendNodeId': host_backend_id,
    'depth': -1,
    'pierce': True  # 穿透 Shadow DOM
})
```

**方法 3：真实鼠标坐标点击（兜底）**
```python
# 使用 Playwright 的 mouse API 模拟真实点击
# 不依赖 Shadow DOM 访问，直接点击视觉位置
host = page.locator("xhs-publish-btn").first
box = await host.bounding_box()
# 估算按钮位置（右侧区域）

click_y = box['y'] + 30
await page.mouse.click(click_x, click_y)
```

## 特殊情况记录

### 1. Shadow DOM 封闭性（已验证：closed）

- **确认**：`xhs-publish-btn` 的 Shadow DOM 是 **closed** 模式

  ```python
  async def is_submit_unlocked(page: Page) -> bool:
  ```

### 3. 定时浮层遮挡

- **当前状态**：点击定时 checkbox 后，浮层未自动展开（`hasSchedulePicker: false`）
- **待验证**：可能需要点击「定时发布」文本或其他区域才会展开浮层
- **处理**：点击发布前先关闭浮层（如果展开），或等待浮层自动收起

### 4. 多个红色按钮（待验证）

- **推测**：Shadow DOM 内可能有多个 `button.ce-btn`
  - 第 1 个：「暂存离开」（非红色或红色）
  - 第 2 个：「发布」或「定时发布」（红色，主提交按钮）
- **处理**：
  - 优先匹配文案：`text == "发布"` 或 `text == "定时发布"`
  - 兜底：取倒数第 1 个（排除「暂存」「草稿」「离开」）

### 5. 点击测试结果

- **直接点击宿主元素**：无效（不会触发 Shadow 内按钮）
- **必须方法**：通过 `host.evaluate()` 在 Shadow 内部执行 `btn.click()`
- **坐标点击**：理论上可行，但需要精确估算按钮位置（未实际测试）

## Playwright 选择器优先级总结

| 优先级 | 选择器类型 | 示例 | 稳定性 |
|--------|-----------|------|--------|
| **最优先** | Web Component + Shadow 穿透 | `xhs-publish-btn >> button.ce-btn.bg-red` | 高（若 Shadow open） |
| **次优先** | host.evaluate() 访问 shadowRoot | 见步骤 2 策略 2 | 高（可访问 closed） |
| **次优先** | 坐标点击 | `page.mouse.click(x, y)` | 中（依赖布局稳定） |

```python
from playwright.async_api import Page

async def click_submit_button(page: Page, is_schedule: bool = False):
    """
    点击小红书发布按钮。
    通过 host._sr 访问 closed Shadow DOM 内部按钮。
    
    Args:
        page: Playwright page 对象
        is_schedule: 是否为定时发布模式
    
    Returns:
        bool: 是否成功触发发布
    """
    host = page.locator("xhs-publish-btn").first
    
    # 等待宿主可用
    await host.wait_for(state="visible")
    disabled = await host.get_attribute("submit-disabled")
    if disabled and str(disabled).lower() == "true":
        raise RuntimeError("发布按钮被禁用")
    
    # 通过 _sr 访问 Shadow DOM 并点击按钮
    result = await host.evaluate("""(el) => {
        const sr = el._sr;  // 内部 shadowRoot 引用
        if (!sr || typeof sr.querySelector !== 'function') {
            return { success: false, reason: '_sr not accessible' };
        }
        
        // 查找红色按钮
        const btn = sr.querySelector('button.ce-btn.bg-red');
        if (!btn) {
            return { success: false, reason: 'button not found' };
        }
        
        // 检查按钮文本
        const text = (btn.innerText || '').trim();
        const expectedText = el.getAttribute('submit-text');
        
        // 定时模式下验证按钮文案
        if (expectedText === '定时发布' && text !== '定时发布') {
            return { 
                success: false, 
                reason: 'button text mismatch',
                expected: expectedText,
                actual: text
            };
        }
        
        // 点击按钮
        btn.click();
        return { success: true, text: text };
    }""")
    
    if not result.get('success'):
        logger.warning(f"点击发布按钮失败：{result.get('reason')}")
        return False
    
    logger.info(f"成功点击发布按钮：{result.get('text')}")
    return True

async def wait_for_publish_success(page: Page, timeout_ms: int = 10000) -> bool:
    """
    等待发布成功。
    检测 URL 参数 published=true 或页面跳转。
    """
    import time
    
    start = time.time()
    while (time.time() - start) * 1000 < timeout_ms:
        # 检查 URL 参数
        url = page.url
        if 'published=true' in url:
            logger.info("检测到发布成功：URL 包含 published=true")
            return True
        
        # 检查是否跳转到笔记管理页
        if '/manage/note' in url or '/manage' in url:
            logger.info("检测到发布成功：已跳转到管理页")
            return True
        
        # 检查是否有成功 Toast
        toast = page.locator('[class*="toast"], [class*="message"]').first
        if await toast.count() > 0:
            text = await toast.inner_text()
            if '成功' in text or 'success' in text.lower():
                logger.info(f"检测到发布成功 Toast: {text}")
                return True
        
        await page.wait_for_timeout(500)
    
    logger.warning("等待发布成功超时")
    return False
```
