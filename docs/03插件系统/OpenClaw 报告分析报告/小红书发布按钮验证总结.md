## 核心发现

### 1. Closed Shadow DOM 的突破口

小红书 `xhs-publish-btn` 组件使用 closed Shadow DOM，但**保留了内部 `_sr` 引用**：

```javascript
const host = document.querySelector('xhs-publish-btn');
console.log(host.shadowRoot);  // null (closed)
console.log(host._sr);         // ✅ ShadowRoot 对象！
```

这是 Vue 或其他框架在创建 closed Shadow DOM 时保留的内部引用，用于组件内部访问。

### 2. Shadow DOM 内按钮结构

```javascript
const sr = host._sr;
const buttons = sr.querySelectorAll('button.ce-btn');

// 结果：2 个按钮
// Index 0: button.ce-btn.white     -> "暂存离开"
// Index 1: button.ce-btn.bg-red    -> "发布" 或 "定时发布"
```

**按钮位置**（相对于视口）：
- 暂存按钮：x:794, y:960, 尺寸：120x40
- 发布按钮：x:938, y:960, 尺寸：120x40（红色）

### 3. 发布流程验证

**点击前**：
- URL: `https://creator.xiaohongshu.com/publish/publish?from=homepage&target=video`
- 按钮文案：「定时发布」（已打开定时开关）

**点击后**：
- URL: `https://creator.xiaohongshu.com/publish/publish?source=&published=true`
- 页面跳转到上传页面
- URL 包含 `published=true` 参数

## 推荐实现方案

### 方案 A：通过 `_sr` 访问（推荐）

```python
from playwright.async_api import Page
import logging

logger = logging.getLogger(__name__)

async def click_submit_button(page: Page, is_schedule: bool = False) -> bool:
    """
    点击小红书发布按钮。
    
    Args:
        page: Playwright page 对象
        is_schedule: 是否为定时发布模式
    
    Returns:
        bool: 是否成功触发发布
    """
    host = page.locator("xhs-publish-btn").first
    
    # 等待宿主可见
    await host.wait_for(state="visible")
    
    # 检查是否被禁用
    disabled = await host.get_attribute("submit-disabled")
    if disabled and str(disabled).lower() == "true":
        logger.warning("发布按钮被禁用")
        return False
    
    # 通过 _sr 访问 Shadow DOM 并点击
    result = await host.evaluate("""(el) => {
        const sr = el._sr;  // 内部 shadowRoot 引用
        if (!sr || typeof sr.querySelector !== 'function') {
            return { success: false, reason: '_sr not accessible' };
        }
        
        // 查找红色按钮
        const btn = sr.querySelector('button.ce-btn.bg-red');
        if (!btn) {
            return { success: false, reason: 'button not found' };
        }
        
        // 检查按钮文本
        const text = (btn.innerText || '').trim();
        const expectedText = el.getAttribute('submit-text');
        
        // 定时模式下验证按钮文案
        if (expectedText === '定时发布' && text !== '定时发布') {
            return { 
                success: false, 
                reason: 'button text mismatch',
                expected: expectedText,
                actual: text
            };
        }
        
        // 点击按钮
        btn.click();
        return { success: true, text: text };
    }""")
    
    if not result.get('success'):
        logger.warning(f"点击发布按钮失败：{result.get('reason')}")
        return False
    
    logger.info(f"成功点击发布按钮：{result.get('text')}")
    return True


async def wait_for_publish_success(page: Page, timeout_ms: int = 10000) -> bool:
    """
    等待发布成功。
    
    检测标志：
    1. URL 包含 published=true 参数
    2. 页面跳转到笔记管理页
    3. 回到上传页面（非编辑模式）
    """
    import time
    
    start = time.time()
    while (time.time() - start) * 1000 < timeout_ms:
        url = page.url
        
        # 标志 1：URL 参数
        if 'published=true' in url:
            logger.info("检测到发布成功：URL 包含 published=true")
            return True
        
        # 标志 2：跳转到管理页
        if '/manage/note' in url or '/manage' in url:
            logger.info("检测到发布成功：已跳转到管理页")
            return True
        
        # 标志 3：回到上传页面（非编辑模式）
        if '/publish/publish' in url and 'from=homepage' not in url:
            # 检查是否有上传区域
            upload_area = page.locator('text="拖拽视频到此或点击上传"')
            if await upload_area.count() > 0:
                logger.info("检测到发布成功：已回到上传页面")
                return True
        
        await page.wait_for_timeout(500)
    
    logger.warning("等待发布成功超时")
    return False
```

### 方案 B：坐标点击（备选）

```python
async def click_submit_via_coords(page: Page) -> bool:
    """
    使用真实鼠标坐标点击发布按钮（兜底方案）。
    如果 _sr 方法失效，使用此方法。
    """
    host = page.locator("xhs-publish-btn").first
    
    # 获取宿主位置
    box = await host.bounding_box()
    if not box:
        logger.error("无法获取宿主元素位置")
        return False
    
    # 红色按钮位置：宿主右侧，距离右边约 180px
    # 按钮尺寸：120x40
    # 中心点计算：
    #   x = box.x + box.width - 180 + 60 = box.x + box.width - 120
    #   y = box.y + 45
    click_x = box["x"] + box["width"] - 120
    click_y = box["y"] + 45
    
    # 模拟真实鼠标点击
    await page.mouse.click(click_x, click_y)
    
    logger.info(f"通过坐标点击发布按钮：({click_x}, {click_y})")
    return True
```

## 注意事项

1. **`_sr` 的稳定性**：
   - `_sr` 是框架内部属性，不是公开 API
   - 如果小红书更新框架版本，可能改变属性名
   - 建议同时实现坐标点击作为兜底

2. **按钮文案验证**：
   - 定时模式下必须验证按钮文案
   - 避免误点「暂存离开」按钮

3. **发布超时处理**：
   - 建议设置 15-30 秒超时
   - 超时可重试 1-2 次
   - 仍失败则通知用户手动检查

4. **风控考虑**：
   - 模拟真实鼠标移动和点击
   - 添加随机延迟
   - 避免短时间内大量发布
