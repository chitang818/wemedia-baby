## 📋 选择器优先级说明

本页面是 React 动态渲染的单页应用，元素特点：
- **无固定 ID**：元素没有稳定的 `id` 属性
- **无 data-testid**：未设置测试专用属性
- **动态 class**：使用 CSS Modules，class 名含哈希值 (如 `button-dhlUZE`)
- **Aria-Ref**：Playwright 会话内稳定引用 (如 `e445`)
- **推荐策略**：使用 **文本内容 + CSS class 组合** 或 **XPath 文本匹配** 或 **Aria-Ref**

## 🎯 核心操作按钮

### 1. 发布按钮 ⭐

| 属性 | 值 |
|------|-----|
| **元素类型** | `BUTTON` |
| **显示文本** | `发布` |
| **CSS Class** | `button-dhlUZE primary-cECiOJ fixed-J9O8Yw` |
| **Aria-Ref** | `e445` |
| **data-attrs** | 无 |

**推荐定位方式：**

```javascript
// 方法 1: Aria-Ref (会话内最稳定)
await page.click('e445');

// 方法 2: CSS Class (推荐)
await page.click('.button-dhlUZE.primary-cECiOJ');

// 方法 3: 文本匹配 (最稳定)
await page.click('button:has-text("发布")');

// 方法 4: XPath
await page.click('//button[text()="发布"]');

// 方法 5: Role + Name (Playwright 最佳实践)
await page.getByRole('button', { name: '发布' }).click();
```

## 🔄 完整发布流程示例 (含 Aria-Ref)

```javascript
const { chromium } = require('playwright');

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  
  // 1. 导航到发布页面
  await page.goto('https://creator.douyin.com/creator-micro/content/post/image');
  
  // 2. 上传素材
  const fileInput = await page.$('input[type="file"]');
  await fileInput.setInputFiles(['image1.jpg', 'image2.jpg', 'image3.jpg']);
  
  // 3. 填写标题 (Aria-Ref)
  await page.fill('e166', '春日美食推荐');
  await page.getByPlaceholder('添加作品标题').fill('春日美食推荐');
  
  // 4. 填写描述
  await page.fill('e174', '春天的美食 #美食 #春日');
  
  // 5. 添加话题 (Aria-Ref)
  await page.click('e191');
  await page.fill('input[placeholder*="话题"]', '美食');
  await page.click('e200');
  
  // 6. 选择音乐 (Aria-Ref)
  await page.click('e326');
  await page.fill('e549', '周杰伦');
  await page.hover('e582');
  await page.waitForTimeout(1500);
  await page.click('e929');
  
  // 7. 设置可见性 (Aria-Ref)
  await page.click('e406');
  
  // 8. 设置发布时间 (Aria-Ref)
  await page.click('e435');
  
  // 9. 发布 (Aria-Ref)
  await page.click('e445');
  await page.getByRole('button', { name: '发布' }).click();
  
  // 10. 等待发布完成
  await page.waitForSelector('.success-toast');
  console.log('发布成功!');
  
  await browser.close();
})();
```

## 🎯 选择器稳定性对比

| 选择器类型 | 稳定性 | 推荐度 | 说明 |
|-----------|--------|--------|------|
| **Aria-Ref** | ⭐⭐⭐⭐⭐ (会话内) | 强烈推荐 | Playwright 会话内最稳定，刷新后变化 |
| `getByRole()` | ⭐⭐⭐⭐⭐ | 强烈推荐 | Playwright 最佳实践 |
| `getByPlaceholder()` | ⭐⭐⭐⭐⭐ | 强烈推荐 | 输入框首选 |
| `getByText()` | ⭐⭐⭐⭐ | 推荐 | 按钮/文本链接 |
| CSS Class | ⭐⭐⭐ | 一般 | Class 可能随版本变化 |
| XPath 文本匹配 | ⭐⭐⭐⭐ | 推荐 | 兼容性好 |
| ID 选择器 | N/A | 不可用 | 页面无稳定 ID |
| data-testid | N/A | 不可用 | 页面未设置 |

## ⚠️ 注意事项

1. **Aria-Ref 会话特性**：`e445` 等 Aria-Ref 在当前浏览器会话中稳定，但刷新页面或重新打开后会变化
2. **Class 名会变化**：CSS Modules 生成的 class 含哈希值，更新后可能变化
3. **优先使用文本匹配**：按钮文本相对稳定
4. **悬停触发元素**：音乐"使用"按钮需悬停 1-2 秒后才出现
5. **动态加载**：部分元素需等待页面加载完成
6. **弹窗处理**：音乐选择等弹窗需先等待出现再操作

## 📚 Playwright 最佳实践

```javascript
// ✅ 推荐：使用内置定位器
await page.getByRole('button', { name: '发布' }).click();
await page.getByPlaceholder('添加作品标题').fill('标题');

// ✅ 推荐：Aria-Ref (会话内)
await page.click('e445');
await page.fill('e166', '标题');

// ✅ 推荐：链式调用
await page
  .getByRole('button', { name: '选择音乐' })
  .click();

// ⚠️ 避免：硬编码 CSS 选择器
await page.click('.button-dhlUZE.primary-cECiOJ'); // 可能随版本失效

// ⚠️ 避免：过长的 XPath
await page.click('//div[2]/div[1]/div[3]/button[1]');
```
