| 步骤 11 发表视频 | 1. 页面跳转到视频管理页（URL 变化）<br>2. 视频列表顶部出现新视频<br>3. 新视频时间戳为当前时间（格式：YYYY 年 MM 月 DD 日 HH:mm）<br>4. 页面顶部显示 Toast"发表成功"（2-3 秒后消失） |

### 发表成功检测逻辑

```javascript
async function detectPublishSuccess(page) {
  // 1. 等待 URL 跳转
  await page.waitForURL('**/platform/post/list');
  
  // 2. 等待新视频出现
  const firstVideo = page.locator('[data-testid="video-item"]').first();
  await firstVideo.waitFor({ state: 'visible' });
  
  // 3. 获取时间戳
  const timestamp = await firstVideo.locator('[data-testid="video-timestamp"]').textContent();
  
  // 4. 验证时间戳为当前时间
  const now = new Date();
  const expectedDate = `${now.getFullYear()}年${String(now.getMonth()+1).padStart(2,'0')}月${String(now.getDate()).padStart(2,'0')}日`;
  
  return timestamp.includes(expectedDate);
}
```

## 其他事项记录

### 1. 登录态维护
- Cookies 名称：sessionid, wxuin
- 有效期：未测试（建议每次发布前验证登录状态）
- 失效表现：跳转到登录页

### 2. 页面 ref 属性说明
- 页面元素带有 `[ref=eXXX]` 属性（如 e1598, e1626 等）
- **稳定性标注**：⚠️ 未知（需持续观察是否稳定可查询）
- **使用建议**：仅作为候选选择器的补充，不建议作为首选定位方式

### 3. 动态内容
- 位置选项显示最近选择的位置
- 视频列表实时刷新
- Toast 提示 2-3 秒自动消失

### 4. 注意事项
- 发表按钮在未上传视频时可能为禁用状态
- 定时发表时间必须为未来时间
- 声明原创需勾选同意条款
