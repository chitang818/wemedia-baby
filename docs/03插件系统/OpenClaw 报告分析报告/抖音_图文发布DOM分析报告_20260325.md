### 6.3 音乐选择交互流程

1. **打开弹窗**：点击「选择音乐」按钮（e326）
2. **搜索音乐**（可选）：在搜索框输入关键词
3. **切换分类**：点击标签页（推荐/热门榜/收藏等）
4. **悬停音乐项**：鼠标悬停在音乐项上 1-2 秒
5. **使用按钮出现**：悬停后显示「使用」按钮（e929）
6. **点击使用**：确认选择该音乐
7. **弹窗关闭**：音乐应用到作品

## 特殊情况记录

### 1. 音乐选择弹窗的悬停交互

**问题**：音乐「使用」按钮不是常驻显示，需要鼠标悬停 1-2 秒后才出现。

**解决方案**：
```python
# 先悬停到音乐项
await page.hover('e582')  # 或 get_by_text('音乐名称')
# 等待按钮出现
await page.wait_for_timeout(1500)
# 点击使用按钮
await page.click('e929')  # 或 get_by_role('button', name='使用')
```

### 2. 哈希 Class 的脆弱性

**观察**：抖音使用 CSS Modules，class 名包含哈希后缀（如 `button-dhlUZE`）。

**建议**：
- 首选 Layer 1：`get_by_role`, `get_by_text`, `get_by_placeholder`
- 次选 Layer 2：`[role='dialog']`, `input[type='file']`, `:has-text('固定文案')`
- 兜底 Layer 3：保留哈希 class，但标注「易碎，需定期维护」

### 3. 弹窗无明确 role

**观察**：音乐选择弹窗没有 `role='dialog'` 属性，是右侧滑出的面板。

**建议**：
- 使用标题文案定位弹窗：`get_by_text('选择音乐')`
- 或结合父级容器缩小范围

### 4. 定时发布时间格式

**观察**：时间输入框显示格式为 `2026-03-28 10:00`。

**建议**：填充时保持相同格式，或根据平台要求调整。
