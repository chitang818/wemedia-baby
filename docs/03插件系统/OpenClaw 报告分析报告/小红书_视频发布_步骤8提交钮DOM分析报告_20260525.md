## 结构草图（Shadow DOM）

```
主文档 .publish-page-content
  └── xhs-publish-btn[is-publish="true"]     ← 宿主（不可直接 click）
        #shadow-root (closed)
        ├── button.ce-btn.bg-red             ← 常为「暂存离开」（需排他）
        └── button.ce-btn.bg-red             ← 主提交：「发布」或「定时发布」
```

**穿透方式（实采 2026-05-25）**：`host.evaluate` 内使用 `el._sr`（closed Shadow 内部引用）；`>>` 穿透符与页面侧 `shadowRoot` **无效**。

---

## 宿主属性（xhs-publish-btn）

| 属性 | 立即发布 | 定时发布 | 说明 |
|------|----------|----------|------|
| `is-publish` | `true` | `true` | 主发布宿主 |
| `submit-text` | `发布` | `定时发布` | 步骤8 模式判定首选 |
| `submit-disabled` | `false` / `true` | 常为 `true` 直至浮层关闭、失焦、表单校验通过 | 步骤8 必须等待非 `true` |
| `disabled` | — | — | 辅助 |

**注意**：点击目标必须是 Shadow 内 `button.ce-btn.bg-red`，**禁止**对宿主 `xhs-publish-btn` 做 `click()`。

---

## Shadow 内红钮（button.ce-btn.bg-red）

| 序号 | 典型文案 | 角色 | 定位策略 |
|------|----------|------|----------|
| 0 | 暂存离开 | 草稿 | **排除**，不得当作发布钮 |
| 1 | 发布 / 定时发布 | 主提交 | 按 `submit-text` 文案匹配；定时时宿主 `submit-text=定时发布` |

**排他**：全局 `button:has-text('定时发布')` 会命中「更多设置」开关，禁止用于步骤8。

---

## 与定时发布的联动

| 条件 | submit-disabled | 处理 |
|------|-----------------|------|
| 定时开关 ON，时间浮层仍开 | 常为 `true` | `dismiss_schedule_date_picker_and_wait` + 右侧空白点击 |
| 焦点在 `.post-time-wrapper` 内 input | 常为 `true` | `blur` + 点 `.publish-page-content-settings` 空白 |
| 浮层已关、时间已填、失焦完成 | 应变为 `false` | 再匹配 Shadow 主钮并点击 |

## 推荐选择器（代码已采用）

```python
# 点击（步骤8 主路径）
host = page.locator("xhs-publish-btn[is-publish='true']").first
await host.evaluate("""(el) => {
    const sr = el._sr;
    const btn = sr && sr.querySelector('button.ce-btn.bg-red');
    if (btn) btn.click();
}""")

# 成功判定
# URL: published=true 或 /publish/success
# 文案: text="发布成功"
```

## 失败诊断包字段说明

发布任一步骤失败且启用页面诊断时，诊断目录位于 `%LOCALAPPDATA%\WeMediaBaby\debug\diagnostics\xiaohongshu\YYYYMMDD\` 下。小红书会额外写入以下文件（通用文件 `page.html`、`screenshot.png`、`dom_snapshot.json`、`selector_probes.json`、`metadata.json` 仍保留）：

| 文件 | 内容 |
|------|------|
| `xhs_publish_snapshot.json` | `snapshot_xhs_publish_btn` 结果：宿主数量、`submit-disabled`、`submit-text`、定时浮层/焦点、Shadow 内按钮列表等 |
| `xhs_publish_probe.json` | 宿主 `evaluate` 探针：`_sr` / `shadowRoot` 可访问方式、`shadowButtons`、`evaluate_sr_red_button_state` 的 `ready` / `reason` |
| `platform_analysis.json` | 结构化中文分析：`hints`、`likely_causes`、`recommended_checks` |
| `分析说明.txt` | 同上分析的纯文本摘要，便于非技术人员阅读 |

**与通用快照的关系**

- `dom_snapshot.json` 仅遍历 **open** Shadow；`xhs-publish-btn` 为 **closed**，内部红钮不会出现在该文件中。若 `xhsPublishHostCount > 0`，`closedShadowNote` 会提示查阅 `xhs_publish_snapshot.json`。
- `selector_probes.json` 中的宿主 locator（`xhs_publish_host` 等）可作参考；**pierce（`>>`）对 closed Shadow 无效**，计数为 0 时请以 `xhs_publish_probe.json` 的 `srAccessMethod` 为准，分析摘要不会据此判定「缺少发布按钮」。

**metadata.json 小红书摘要字段**

- `xhs_publish_snapshot`：压缩版快照（步骤 8 失败前若已 attach，会一并写入）
- `xhs_submit_disabled`、`xhs_submit_text`、`xhs_sr_access_method`、`xhs_shadow_buttons`、`xhs_analysis_hints`

**步骤 8 与扩展采集去重**

- 步骤 8 失败前会将最新状态写入 `metadata._diagnostic_context.xhs_publish_snapshot`（及 `xhs_publish_snapshot_raw`）。
- 诊断插件 `capture_xiaohongshu_extras` 优先合并该 attach；若现场仍能采到宿主，以现场快照为准并标注 `source`。

**UI**

- 发布列表失败弹窗在平台为 `xiaohongshu` 时，会读取 `platform_analysis.json` 的 `hints` 展示「页面结构提示」。
