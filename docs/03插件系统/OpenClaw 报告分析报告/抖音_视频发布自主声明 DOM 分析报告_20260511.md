## 特殊情况记录

### 1. 「确定」按钮的状态变化
- **现象**：「确定」按钮初始为 disabled 状态，选择任一声明后才变为 enabled
- **自动化影响**：必须先选择声明，等待「确定」按钮启用后再点击
- **建议策略**：
  1. 先选择声明：`page.locator('[ref="e28"]').click()`
  2. 等待「确定」按钮启用：`page.locator('[ref="e35"]').wait_for(state='enabled')`
  3. 点击「确定」按钮：`page.locator('[ref="e35"]').click()`

### 2. 6 个声明选项的单选互斥
- **现象**：6 个选项是 radio 类型，互斥单选
- **自动化影响**：选择一个选项会自动取消其他选项的选中状态
- **建议策略**：直接使用 `get_by_role('radio', name='...')` 选择目标选项即可

### 3. 弹窗的关闭方式
- **关闭方式 1**：点击「确定」按钮（正常流程，保存选择）
- **关闭方式 2**：点击「取消」按钮（放弃选择）
- **关闭方式 3**：点击弹窗外部遮罩层（可能有效，需验证）

### 4. 无特殊结构
- 抖音视频发布页为普通 DOM 结构，无 Shadow DOM、无 iframe、无 contenteditable
- 所有元素均可通过标准 Playwright API 直接定位和操作

## 自动化代码示例（Python + Playwright）

```python
# 步骤 1：打开自主声明面板
page.locator('text=请选择自主声明').click()

# 步骤 2：等待弹窗出现并选择声明类型
dialog = page.get_by_role('dialog')
dialog.wait_for(state='visible')

# 选择「内容由 AI 生成」选项
page.get_by_role('radio', name='内容由 AI 生成').click()

# 步骤 3：等待「确定」按钮启用并点击
confirm_btn = page.get_by_role('button', name='确定')
confirm_btn.wait_for(state='enabled')
confirm_btn.click()

# 步骤 4：验证声明选择成功
selected_statement = page.get_by_text('内容由 AI 生成')
selected_statement.wait_for(state='visible')
assert selected_statement.is_visible()
```
