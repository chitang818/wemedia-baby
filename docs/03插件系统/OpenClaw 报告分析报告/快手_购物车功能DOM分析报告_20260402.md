## 页面结构与技术特征

### 结构概要

- 是否存在 **iframe**：否（已检查，关键操作区均在主文档）
- 是否存在 **Shadow DOM**：否（已检查，无 shadow-root 节点）
- 是否存在 **contenteditable** 主描述区：是（作品描述区为 contenteditable div）
- 其他：页面采用 React + Ant Design 组件，下拉框、弹窗等为浮层组件（挂载在 body 末位）

### 层级示意

```
主文档 body
  └─ div#root（React 根）
      └─ 发布页面布局
          └─ 作者服务区域（section/div）
              └─ 「选择服务类型」combobox
              └─ 「关联商品获得更多收入」combobox + 商品选择弹窗
```

### 对自动化的影响摘要

- Playwright 侧建议策略：主文档内常规 locator，注意浮层组件的异步加载
- 已知限制：商品选择弹窗为动态加载的下拉列表，需等待选项出现；输入搜索有即时过滤功能

## 自动化建议与注意事项

### 定位策略优先级
1. **首选角色+名称定位**：如 `get_by_role('combobox', name='选择服务类型')`
2. **文本定位**：如 `get_by_text('关联商品')`（用于选项选择）
3. **属性定位**：如 `[role='combobox'][aria-expanded='true']`

### 等待策略
1. 点击「选择服务类型」后需等待下拉菜单出现（`expanded=true`）
2. 选择「关联商品」后需等待「关联商品获得更多收入」框变为可用（非 disabled）
3. 输入搜索词后需等待过滤完成（列表项减少）
4. 点击商品后需等待下拉列表关闭（`expanded=false`）

### 易碎点标记
- 商品选择下拉列表的商品项 class 可能含随机哈希，避免直接使用
- 商品 JSON 数据结构可能变化，不要依赖其字段顺序
- 页面布局可能响应式调整，但核心文案（「选择服务类型」「关联商品获得更多收入」）相对稳定
