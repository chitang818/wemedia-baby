## 页面结构与技术特征

### 结构概要

- **微前端框架**：wujie（微前端容器）
- **Shadow DOM**：存在，open 模式
- **宿主元素**：`wujie-app`（class: `wujie_iframe`）
- **iframe**：存在但隐藏（用于预加载微前端子应用）

### 层级示意

```
主文档 body
  └─ wujie-app.wujie_iframe
      └─ #shadow-root (open)
          └─ div#app.finder-page.PostCreate
              └─ div.main-body
                  └─ div.post-edit-wrap.material-edit-wrap
                      └─ div.form
                          └─ div.form-item.cell-center.post-with-link  [链接表单项]
                              └─ div.post-link-wrap
                                  ├─ div.link-display-wrap  [步骤 1：点击这里选择链接类型]
                                  ├─ div.link-list-options  [下拉选项列表]
                                  │   └─ div.link-option-item  [商品选项]
                                  └─ div.link-input-wrap  [步骤 3：点击这里打开商品选择弹窗]
                                      └─ div.post-component-choose-wrap
                                          └─ div.content-wrap  [实际可点击区域]
```

### 对自动化的影响摘要

- **Playwright 策略**：必须通过 `evaluate` 在页内查询 shadowRoot，或使用链式 `locator` 穿透 Shadow DOM
- **关键难点**：
  1. 所有交互元素都在 Shadow DOM 内，常规 CSS 选择器无法直接访问
  2. "选择链接"和"选择需要添加的商品"是两个不同的点击区域
  3. 商品选择弹窗是独立对话框，需要等待出现

## 特殊情况记录

### Shadow DOM 穿透方案

由于页面使用 wujie 微前端框架，所有关键元素都在 Shadow DOM 内。推荐使用以下方案：

**方案 1：evaluate 直接查询**
```javascript
const wujie = document.querySelector('wujie-app');
const element = wujie.shadowRoot.querySelector('.target-class');
element.click();
```

**方案 2：完整路径查询**
```javascript
const element = document
  .querySelector('wujie-app')
  .shadowRoot
  .querySelector('.link-input-wrap .content-wrap');
element.click();
```

### 关键点击目标

1. **步骤 1**：点击 `.link-display-wrap`（不是 `.choosen-link-wrap`）
2. **步骤 3**：点击 `.link-input-wrap .content-wrap`（实际响应点击的区域）

### 弹窗关闭检测

弹窗关闭后，`add-commodity-dialog` 元素仍存在但 `display: none`。检测时应使用：
```javascript
const dialog = shadowRoot.querySelector('.add-commodity-dialog');
const isClosed = !dialog || window.getComputedStyle(dialog).display === 'none';
```

## Playwright 自动化建议代码

```javascript
// 进入 Shadow DOM 的辅助函数
function getShadowRoot() {
  return document.querySelector('wujie-app').shadowRoot;
}

// 步骤 1：点击选择链接
await page.evaluate(() => {
  const shadow = getShadowRoot();
  shadow.querySelector('.link-display-wrap').click();
});

// 步骤 2：点击商品选项
await page.evaluate(() => {
  const shadow = getShadowRoot();
  const options = Array.from(shadow.querySelectorAll('.link-option-item'));
  const commodity = options.find(el => el.textContent.includes('商品'));
  commodity.click();
});

// 步骤 3：点击选择需要添加的商品
await page.evaluate(() => {
  const shadow = getShadowRoot();
  const contentWrap = shadow.querySelector('.link-input-wrap .content-wrap');
  contentWrap.click();
});

// 步骤 4-5：输入商品链接并筛选
await page.evaluate(() => {
  const shadow = getShadowRoot();
  const dialog = shadow.querySelector('.add-commodity-dialog');
  const input = dialog.querySelector('input[placeholder*="商品名称"]');
  input.value = '#微信小店://心相印家清用品商城/yCxB0nqYKyjfVhs';
  input.dispatchEvent(new Event('input', { bubbles: true }));
  dialog.querySelector('.search-btn button').click();
});

// 步骤 7：选中商品
await page.evaluate(() => {
  const shadow = getShadowRoot();
  const dialog = shadow.querySelector('.add-commodity-dialog');
  const firstRow = dialog.querySelector('.ant-table-tbody tr');
  firstRow.click();
});

// 步骤 8：点击添加
await page.evaluate(() => {
  const shadow = getShadowRoot();
  const dialog = shadow.querySelector('.add-commodity-dialog');
  dialog.querySelector('.weui-desktop-btn_primary').click();
});
```
