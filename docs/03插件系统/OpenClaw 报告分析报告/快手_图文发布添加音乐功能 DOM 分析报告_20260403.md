## 特殊情况记录

### 1. 音乐选择抽屉行为

- 抽屉为右侧滑出式，非居中弹窗
- 点击"添加"按钮后抽屉**不会自动关闭**，可继续浏览/搜索其他音乐
- 抽屉可手动关闭（点击遮罩层或外部区域）

### 2. 悬停交互

- 音乐列表项默认不显示"添加"按钮
- **必须悬停**到音乐项上，"添加"按钮才会出现在该项右侧
- Playwright 自动化时需先 `hover()` 再 `click()`

### 3. 已添加音乐管理

- 添加后可通过"更换音乐"按钮重新选择
- 添加后可通过"删除"按钮移除音乐
- 两个按钮并排显示在音乐信息区右侧

### 4. 作品检测联动

- 未添加音乐时：作品检测显示"作品未添加音乐"（橙色提示）
- 已添加音乐后：作品检测显示"作品已添加音乐"（绿色提示）
- 该状态可用于自动化验证添加是否成功

## Playwright 代码示例

### 完整添加音乐流程

```javascript
// 步骤 1：点击添加音乐按钮，打开抽屉
await page.getByRole('button', { name: '添加音乐' }).click();

// 步骤 2：等待抽屉出现
await page.getByText('选择音乐').waitFor({ state: 'visible' });

// 步骤 3：悬停到目标音乐项上
const musicItem = page.getByText('春风何时来').first();
await musicItem.hover();

// 步骤 4：点击出现的"添加"按钮
await page.getByText('春风何时来').locator('..').getByText('添加').click();

// 步骤 5：验证添加成功
await expect(page.getByText('春风何时来').first()).toBeVisible();
await expect(page.getByRole('button', { name: '更换音乐' })).toBeVisible();
```

### 搜索后添加音乐

```javascript
// 打开音乐抽屉
await page.getByRole('button', { name: '添加音乐' }).click();

// 在搜索框输入关键词
const searchBox = page.getByPlaceholder('搜索音乐');
await searchBox.fill('周杰伦');

// 悬停并添加搜索结果
const targetMusic = page.getByText('稻香').first();
await targetMusic.hover();
await targetMusic.locator('..').getByText('添加').click();
```

### 更换已添加的音乐

```javascript
// 点击"更换音乐"按钮
await page.getByRole('button', { name: '更换音乐' }).click();

// 选择新音乐
const newMusic = page.getByText('新的音乐名称').first();
await newMusic.hover();
await newMusic.locator('..').getByText('添加').click();
```

### 删除已添加的音乐

```javascript
// 点击"删除"按钮
await page.getByRole('button', { name: '删除' }).click();

// 验证删除成功（回到"添加音乐"初始状态）
await expect(page.getByRole('button', { name: '添加音乐' })).toBeVisible();
```

### 验证作品检测状态

```javascript
// 检查作品检测状态

  console.log('✓ 音乐已成功添加');
```
