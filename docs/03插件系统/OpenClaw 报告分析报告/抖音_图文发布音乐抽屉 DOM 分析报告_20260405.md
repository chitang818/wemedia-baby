## 特殊情况记录

### 1. 「使用」按钮的动态出现行为
- **现象**：「使用」按钮不是常驻显示的，而是在点击音乐条目后才出现
- **自动化影响**：不能直接定位「使用」按钮，必须先点击音乐条目，等待「使用」按钮出现后再点击
- **建议策略**：
  1. 先点击音乐条目：`page.locator('[ref="e671"]').click()`
  2. 等待「使用」按钮出现：`page.locator('[ref="e1022"]').wait_for(state='visible')`
  3. 点击「使用」按钮：`page.locator('[ref="e1022"]').click()`

### 2. 音乐条目的重复结构
- **现象**：音乐列表中有多首音乐，每首结构相同（封面 + 歌名 + 歌手 + 时长 + 使用量）
- **自动化影响**：不能仅通过歌名定位，需通过列表中的位置（如第 N 首）或结合其他特征（如使用量）
- **建议策略**：使用 `nth` 选择器，如 `page.locator('[ref="e671"]').nth(0)` 选择第一首

### 3. 音乐抽屉的关闭方式
- **关闭方式 1**：点击「使用」按钮后自动关闭（正常流程）
- **关闭方式 2**：点击抽屉右上角关闭按钮（e627）
- **关闭方式 3**：点击抽屉外部遮罩层（可能有效，需验证）

### 4. 无特殊结构
- 抖音图文发布页为普通 DOM 结构，无 Shadow DOM、无 iframe、无 contenteditable
- 所有元素均可通过标准 Playwright API 直接定位和操作
