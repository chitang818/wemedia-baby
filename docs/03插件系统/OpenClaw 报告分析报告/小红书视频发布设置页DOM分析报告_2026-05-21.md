## 页面结构与技术特征

### 结构概要

- 是否存在 iframe：存在 1 个空 iframe，`name/title/src/class` 均为空；关键发布控件不在 iframe 内。
- 是否存在 Shadow DOM：未发现 open shadow host。
- 是否存在 contenteditable 主描述区：存在，正文编辑器为 `div[contenteditable="true"][role="textbox"]`，class 为 `tiptap ProseMirror`。
- 主应用挂载结构：关键区域位于主文档内，主容器链路大致为：

```text

  └─ div.main-page-container
      └─ main.main-container
          ├─ div.menu-container.menu-panel
          └─ div.microapp-container
              └─ div.publish-vue-container

```

### 对自动化的影响摘要

- 关键控件均可由主文档 `page.locator(...)` 直接定位，不需要 `frame_locator` 或 shadow 穿透。
- 标题是标准 `input[type="text"]`，placeholder 稳定。
- 正文是 ProseMirror 富文本编辑器，建议使用 `locator(".tiptap.ProseMirror[contenteditable='true']")` 或 `get_by_role("textbox").nth(...)`，并用点击后键盘输入方式更稳。
- 视频上传 input 为隐藏 input，仍可用 Playwright `set_input_files` 直接赋值。
- 公开可见下拉的候选浮层 DOM 已预渲染但尺寸为 0，点击下拉后应等待可见浮层再选项。
- 当前未出现最终“发布”按钮，可能需要滚动容器或填写必填字段后才显示/启用；本次未执行最终发布。
