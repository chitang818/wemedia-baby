## 页面结构与技术特征

### 结构概要

- 是否存在 iframe：存在 1 个 `iframe`，位于 `html > head > iframe`，尺寸为 0，`name/title/src/class` 均为空；关键发布控件不在 iframe 内。
- 是否存在 Shadow DOM：未发现 open shadow host；关键控件均在主文档可达 DOM 内。
- 是否存在 contenteditable 主描述区：存在，正文编辑器为 `div.tiptap.ProseMirror[contenteditable="true"][role="textbox"]`。
- 主应用挂载结构：主文档内 Vue 应用，关键区域链路大致如下。

```text
主文档 body
  └─ div.main-page-container
      └─ main.main-container
          └─ div.microapp-container
              └─ div#creator-publish-dom
                  └─ div#web.publish-vue-container
                      └─ div.outarea.publish-c
                          └─ div#publish-container.publish-video-container
                              └─ div.publish-page-container
                                  └─ div.publish-page
                                      ├─ div.publish-page-content
                                      │   ├─ div.publish-page-content-content-extra
                                      │   └─ div.publish-page-content-settings
                                      └─ div.publish-page-preview
```

### 对自动化的影响摘要

- Playwright 侧可用 `page.locator(...)` 直接定位，不需要 `frame_locator` 或 shadowRoot 穿透。
- 下拉/时间面板都挂载到 `body` 末尾的浮层，不在原表单项 DOM 内；自动化应先点击入口，再等待 body 级浮层可见。
- “公开可见”“添加内容类型声明”“添加地点”均使用 `d-select` 组件，但浮层内容结构不同，必须限定入口 class 或邻近文案。
- 定时发布开关打开后会新增时间输入框，点击输入框打开日期时间浮层；选择分钟后浮层自动关闭并回填时间。
- 页面存在多个 “更多”“收起”“公开可见”，定位时必须限定作用域。

### 操作说明

## 特殊情况记录

- 内容类型声明浮层点击外部可关闭；本次按 Escape 未关闭该浮层，建议自动化用点击空白区域或重新点击入口关闭。
- 地点入口未输入关键词时会提示“请先输入并搜索地点”；需要先聚焦并输入搜索词，再等待 POI 浮层。
- 地点、内容类型、公开可见都使用 `d-popover d-dropdown`，且地点/权限浮层都带 `custom-dropdown-44`，不能只靠 class 区分。
- 定时发布打开后会立即生成默认时间；点击输入框打开日期时间浮层。选择分钟后浮层自动关闭，不需要点击确定。
- 时间选择器中的日期、小时、分钟数字大量重复，不能用全局 `text=25` 等定位；必须限定在 `.post-time-date-picker-popover-class` 下，并进一步限定日历/小时列/分钟列。
- 页面右侧预览区也有“公开可见”，权限操作必须限定 `.publish-page-content-settings` 或 `.permission-card-select`。
