## 特殊情况记录

### 1. contenteditable 输入框特性

作品描述输入框不是标准的 `<input>` 或 `<textarea>`，而是 `contenteditable="true"` 的 `<div>`。这意味着：

- **不能使用** `page.locator('input').fill()` 的标准行为
- **需要使用** `.fill()` 配合 keyboard 输入，或直接用 `evaluate` 设置 `innerText`
- **清空操作**：`page.locator('#work-description-edit').press('Control+a').press('Delete')` 或 `evaluate(() => { el.innerText = ''; })`

### 2. class 名带哈希后缀

输入框的 class 名 `_description_17g9x_24` 包含随机哈希，网站改版后会变化：

- **不要使用** `.locator('._description_17g9x_24')` 作为主要定位方式
- **推荐使用** `#work-description-edit` id 选择器（稳定）
- **兜底方案**：`locator('[contenteditable="true"]').filter(has_text='作品描述')`

### 3. 辅助功能区域

输入框下方有多个辅助功能按钮，按从左到右顺序：

1. **智能文案** - AI 生成文案
2. **智能话题** - 推荐话题标签
3. **好友** - @好友功能
4. **推荐话题区** - 显示 4 个推荐话题 + "全部"按钮

这些按钮的 class 也可能带哈希，建议使用文案定位：
```javascript
page.getByRole('button', { name: '智能文案' })
page.getByRole('button', { name: '智能话题' })
page.getByRole('button', { name: '好友' })
```

### 4. 父容器结构

```
DIV._caption-v2-container_w7rw1_7     // 表单项容器（可能用于 tours 引导）
  └─ DIV._edit-desc-container_17g9x_7  // 描述编辑容器
      └─ DIV#work-description-edit     // 实际输入框
```

如果需要更精确的定位，可以使用：
```javascript
page.locator('._edit-desc-container_17g9x_7 > #work-description-edit')
```

## Playwright 代码示例

### 基础输入

```javascript
// 方式 1：使用 id 选择器（推荐）
await page.locator('#work-description-edit').fill('这是我的作品描述');

// 方式 2：使用 contenteditable 属性
await page.locator('[contenteditable="true"]').first().fill('这是我的作品描述');

// 方式 3：使用 evaluate（最可靠）
await page.evaluate((text) => {
  const el = document.getElementById('work-description-edit');
  el.innerText = text;
}, '这是我的作品描述');
```

### 清空后输入

```javascript
const descInput = page.locator('#work-description-edit');
await descInput.press('Control+a');
await descInput.press('Delete');
await descInput.fill('新的描述内容');
```

### 获取当前描述内容

```javascript
const description = await page.locator('#work-description-edit').innerText();
console.log('当前描述:', description);
```

### 验证输入框存在

```javascript
const isEditable = await page.locator('#work-description-edit').isVisible();
```
