## 1. 页面概述

### 1.1 页面功能
抖音视频发布页面用于上传视频、填写标题描述、设置封面、添加音乐、配置发布选项，并最终发布视频到抖音平台。

### 1.2 页面结构
页面分为左右两栏：
- **左栏**：基础信息、扩展信息、发布设置
- **右栏**：视频预览、发文助手、操作按钮

### 1.3 关键元素统计

## 8. 自动化代码示例

### 8.1 完整发布流程
```python
async def publish_video(page):
    # 1. 填写标题
    await page.fill('[ref=e212]', '我的视频标题')
    
    # 2. 填写描述
    await page.fill('[ref=e217]', '视频描述内容')
    
    # 3. 选择封面
    await page.click('[ref=e153]')
    await page.click('button:has-text("选择封面")')
    
    # 4. 添加音乐
    await page.click('[ref=e520]')
    # 等待音乐弹窗加载
    await page.wait_for_selector('[ref=e946]')
    # 选择音乐
    await page.click('[ref=e995]')
    await page.click('[ref=e1106]')
    
    # 5. 设置发布时间
    await page.click('[ref=e458]')  # 选择定时发布
    await page.fill('[ref=e463]', '2026-03-31 23:40')
    
    # 6. 点击发布
    await page.click('[ref=e476]')
    
    # 7. 等待页面跳转
    await page.wait_for_url('**/content/manage')
    
    # 8. 验证发布成功
    await page.wait_for_selector('text=作品管理')
    print("发布成功！")
```

### 8.2 发布成功判定
```python
async def verify_publish_success(page):
    # 方法 1: 等待页面跳转
    await page.wait_for_url('**/content/manage')
    
    # 方法 2: 等待作品管理标题出现
    await page.get_by_text('作品管理').wait_for()
    
    # 方法 3: 检查作品数量变化
    before_count = await page.locator('.work-count').text_content()
    # 发布后
    after_count = await page.locator('.work-count').text_content()
    assert int(after_count) > int(before_count)
    
    # 方法 4: 等待新作品出现
    await page.wait_for_selector('text=定时发布中')
```

## 9. 注意事项

### 9.1 Toast 提示
- **问题**：Toast 提示（如“发布成功”）显示时间短（2-3秒），难以捕获
- **解决方案**：优先通过页面跳转和作品列表更新判定发布成功

### 9.2 定时发布
- 当前设置：2026-03-31 23:40
- 支持范围：2小时后及14天内
- 修改方式：前往作品管理修改

### 9.3 封面缺失提示
- **提示**：横/竖双封面缺失
- **建议**：同时设置横版和竖版封面以增加流量

### 9.4 发文助手检测
