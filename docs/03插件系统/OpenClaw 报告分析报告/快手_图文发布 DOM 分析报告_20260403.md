## 特殊情况记录

### 1. 未发布内容恢复
- **现象**：进入页面时弹出"还有上次未发布的图集，是否继续编辑？"
- **弹窗按钮**：
  - "继续编辑"：加载上次未发布的内容
  - "放弃"：清空上次内容，从空白开始

### 2. 音乐选择弹窗
- **类型**：抽屉式弹窗（从底部滑出）
- **关闭方式**：选择后点击"添加"按钮 / 点击外部 / 按 Escape
- **搜索功能**：支持输入关键词过滤音乐列表

### 3. 作者声明菜单
- **类型**：下拉列表（listbox）
- **选项数量**：4 项固定选项
- **关闭方式**：选择后自动关闭 / 点击外部 / 按 Escape

### 4. 地点选择
- **两级联动**：先选择"所在地区"（省/市），再输入"详细地址"
- **禁用状态**：详细地址输入框默认禁用，选择地区后启用
