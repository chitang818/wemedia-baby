## 特殊情况记录

### 1. 弹窗触发条件
- **现象**：此弹窗不是用户主动触发的，而是系统在封面设置环节自动弹出
- **触发条件推测**：上传视频后未设置横封面时自动弹出
- **自动化影响**：需要等待此弹窗出现，而不是主动点击触发
- **建议策略**：
  1. 使用 `page.get_by_role('dialog').wait_for(state='visible', timeout=10000)` 等待弹窗
  2. 如果弹窗不出现（可能已设置过横封面），超时后继续正常流程

### 2. 弹窗的三种关闭方式
- **「暂不设置」按钮**：跳过横封面设置
- **「设置横封面」按钮**：进入设置流程
- **关闭按钮 ×**：同「暂不设置」

### 3. 推测：「设置横封面」点击后的行为
- 点击「设置横封面」后，可能：
  1. 关闭当前弹窗
  2. 打开横封面上传/选择界面
  3. 或在封面设置区域切换到「横封面」Tab
- 需进一步验证具体跳转行为

### 4. 无特殊结构
- 弹窗为普通 DOM 结构，无 Shadow DOM、无 iframe
- 所有元素均可通过标准 Playwright API 直接定位和操作

## 自动化代码示例（Python + Playwright）

```python
# 等待弹窗出现
dialog = page.get_by_role('dialog')
try:
    dialog.wait_for(state='visible', timeout=10000)
except TimeoutError:
    # 弹窗未出现，可能已设置过横封面，跳过
    print("横封面弹窗未出现，跳过")
    return

# 验证弹窗标题
title = page.get_by_text('设置横封面获更多流量')
assert title.is_visible(), "弹窗标题不匹配"

# 验证弹窗内容
desc = page.get_by_text('你的作品可能会在精选频道')
assert desc.is_visible(), "弹窗说明文字不匹配"

left_preview_title = page.get_by_text('推荐双列效果预览')
assert left_preview_title.is_visible(), "左侧预览标题不匹配"

right_preview_title = page.get_by_text('抖音精选频道效果预览')
assert right_preview_title.is_visible(), "右侧预览标题不匹配"

# 选项 1：点击「暂不设置」跳过
page.get_by_role('button', name='暂不设置').click()

# 选项 2：点击「设置横封面」进入设置流程
page.get_by_role('button', name='设置横封面').click()

# 选项 3：点击关闭按钮
page.get_by_label('关闭').click()

# 验证弹窗已关闭
dialog.wait_for(state='hidden')
```
