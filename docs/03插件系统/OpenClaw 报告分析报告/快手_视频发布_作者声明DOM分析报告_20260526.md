## 步骤4（进阶）：作者声明 — 完整自动化操作流程

### 推荐代码段

```python
from playwright.sync_api import Page

def set_author_declaration(page: Page, option: str):
    """
    设置作者声明
    :param page: Playwright Page 对象
    :param option: 可选值: '内容为AI生成' / '演绎情节，仅供娱乐' / '个人观点，仅供参考' / '素材来源于网络'
    """
    # 点击展开 select
    page.get_by_placeholder('为作品添加补充说明').click()
    page.wait_for_timeout(500)  # 等待动画
    
    # 选择选项
    page.get_by_role('option', name=option).click()
    page.wait_for_timeout(300)

def clear_author_declaration(page: Page):
    """清除作者声明"""
    page.locator('.ant-select-clear').click()
    page.wait_for_timeout(300)

def get_author_declaration(page: Page) -> str:
    """获取当前选中的作者声明文案"""
    select_value = page.locator('.ant-select-selection-item')
    if select_value.is_visible():
        return select_value.text_content()
    return ''  # 未选择
```

## 特殊情况记录

1. **Ant Design Select Portal 渲染**：下拉选项列表被渲染到 `<body>` 下，不在原表单 DOM 层级中。使用 `get_by_role('option')` 时无需指定作用域，因为 `role=option` 在页面中唯一。但如果页面有其他下拉同时展开，需注意隔离。

2. **工具提示图标**：「作者声明」标签右侧有一个信息图标（`<img>` 嵌入的 SVG 图标，宽14px），推测 hover 会显示 tooltip 文字提示。未进行 hover 测试，不影响功能自动化。

3. **Select 搜索输入框**：Ant Design Select 内嵌一个 readonly 的搜索 `<input type="search">`，`opacity: 0` 且只读，不能通过 `fill()` / `type()` 输入内容，仅通过点击选项交互。

4. **图片文件上传无关**：作者声明功能不涉及文件上传，仅为纯下拉选择交互。

5. **A/B 测试风险**：上述分析基于当前页面版本。快手可能进行 A/B 测试或 UI 改版，class 哈希名（如 `_edit-form-item_1quq7_7`）会变化。建议优先使用 `role`、`placeholder`、`name` 等稳定属性定位。
