## 2. Shadow DOM 架构说明

视频号创作者发布页大量使用 `wujie-app` 微前端框架，页面内容被封装在 **Shadow DOM** 中，常规 CSS 选择器无法直接访问。

### 2.1 Shadow DOM 穿透方式

所有步骤通过 `wujie_shadow.py` 提供的 `WUJIE_SHADOW_ROOT_JS` 常量穿透 Shadow DOM：

```javascript
// 降级路径顺序（优先完整路径，兜底遍历所有 wujie-app）
var paths = [
    '#container-wrap > ... > wujie-app',
    '#container-wrap > ... > wujie-app'  // 备用路径
];
// 最后兜底：遍历页面所有 wujie-app 元素
var all = document.querySelectorAll('wujie-app');
```

### 2.2 关键工具模块

| 模块 | 用途 |
|------|------|
| `wujie_shadow.py` | 提供 `WUJIE_SHADOW_ROOT_JS`（获取 shadow root）和 `WUJIE_SHADOW_QUERY_SELECTOR_FN_JS`（shadow 内 querySelector） |
| `shadow_mouse.py` | 提供 `get_shadow_el_center`、`real_mouse_click_xy`、`shadow_eval_center`，用于获取 Shadow DOM 内元素坐标后执行真实鼠标点击 |

### 2.3 为什么不能用普通点击

由于视频号使用 `wujie` + `Vue/Ant Design` 组件，`page.evaluate` 内的 `el.click()` 可能导致**假勾选**（Vue 响应式数据不触发）。关键操作（如声明原创的复选框、确认按钮）**必须使用 `page.mouse.click(x, y)` 真实鼠标点击**，不能用 JavaScript 注入点击。

## 3. 步骤链组装逻辑 (视频与图文对比)

视频号插件采用**单一步骤链**，对外统一为 **9 个阶段（步骤）**。其中第 5、8 步会包含多个子步骤（同一个步骤号内顺序执行），为方便对比，下表展示了视频和图文在共用步骤链下的具体行为：

| 步骤 | 核心类名 | 视频场景 (video) | 图文场景 (image) | 差异说明 |
|:---|:---|:---|:---|:---|
| **1. 导航首页** | `NavigateHomeStep` | ✓ 执行 | ✓ 执行 | 完全共用，检测登录状态 |
| **2. 进入发布页** | `EnterPublishEntryStep` | 点击「发表视频」 | 点击「发表图文」 | 触发不同的入口按钮 |
| **3. 上传文件** | `UploadMediaStep` | 传视频 | 传多图 | 读取 `file_type` 记录日志，上传机制相同 |
| **4. 封面设置** | `CoverSettingStep` | **首帧/自定义** | **首图/自定义** | 根据配置决定是否进行 DOM 操作 |
| **5A. 图文专属标题（第5步子步骤）** | `ImageTitleStep` | ✗ 跳过不加载 | ✓ 执行 | 图文发布专属，位于描述输入框上方，最多 22 字 |
| **5B. 描述与话题（第5步子步骤）** | `MetadataFillStep` | ✓ 执行 | ✓ 执行 | 完全共用，填写富文本 |
| **6. 位置设置** | `LocationSettingStep` | ✓ 执行 | ✓ 执行 | 完全共用 (条件执行) |
| **7. 链接挂载** | `LinkSettingStep` | ✓ 执行 | ✓ 执行 | 完全共用 (条件执行) |
| **8A. 图文背景音乐（第8步子步骤）** | `ImageTextMusicStep` | ✗ 跳过不加载 | ✓ 执行 | 仅图文支持（当前占位，用于步骤队列与进度展示） |
| **8B. 定时发表（第8步子步骤）** | `ScheduleSettingStep` | ✓ 执行 | ✓ 执行 | 完全共用 (条件执行) |
| **8C. 视频短标题（第8步子步骤）** | `ShortTitleStep` | ✓ 执行 | ✗ 跳过不加载 | 仅视频支持。严苛过滤特殊符号，限 6-16 字 |
| **8D. 声明原创（第8步子步骤）** | `OriginalDeclareStep` | ✓ 执行 | ✗ 跳过不加载 | 仅视频支持 (条件执行) |
| **9. 提交发布** | `SubmitStep` | ✓ 执行 | ✓ 执行 | 完全共用，真实鼠标点击发表 |

`publish_plugin.py` 中通过 `Step Pipeline` 动态组装代码如下：

```python
common_prefix_steps = [
    NavigateHomeStep(),       # 阶段1
    EnterPublishEntryStep(),  # 阶段2
    UploadMediaStep(),        # 阶段3
    CoverSettingStep(),       # 阶段4
]
common_suffix_steps = [
    LocationSettingStep(),    # 阶段6
    LinkSettingStep(),        # 阶段7
    ScheduleSettingStep(),    # 阶段8（视频链内：定时；与短标题/原创同属阶段8）
    SubmitStep(),             # 阶段9
]

if file_type == "image":
    steps = [
        *common_prefix_steps,
        ImageTitleStep(),      # 阶段5：图文标题
        MetadataFillStep(),    # 阶段5：描述
        LocationSettingStep(), # 阶段6
        LinkSettingStep(),     # 阶段7
        ImageTextMusicStep(),  # 阶段8A：图文背景音乐（占位）
        ScheduleSettingStep(), # 阶段8B：定时发表
        SubmitStep(),          # 阶段9
    ]
else:
    steps = [
        *common_prefix_steps,
        MetadataFillStep(),    # 阶段5：描述
        *common_suffix_steps[:3],
        ShortTitleStep(),      # 阶段8C：视频短标题
        OriginalDeclareStep(), # 阶段8D：声明原创
        *common_suffix_steps[3:],
    ]
```

## 4. 各步骤详细说明

### step_01_home.py — NavigateHomeStep

**功能**：导航到视频号创作者服务中心，检测登录状态。

**执行逻辑**：
1. `page.goto("https://channels.weixin.qq.com/platform", wait_until="domcontentloaded")`
2. 检测 URL 是否跳转到登录页（`/login`），若是则报 Cookie 失效
3. 检测风控弹窗（`Selectors.SECURITY.RISK_MODAL`）
4. 等待 `networkidle`，确保页面加载完成
5. **穿透 wujie-app Shadow DOM** 轮询检测「发表视频」按钮（最多 10 次，每次间隔 1 秒）
6. 找到按钮后写入 `metadata['_publish_btn_ready'] = True`，供步骤2快速使用

**Shadow DOM 穿透**：必须通过 JavaScript + `WUJIE_SHADOW_ROOT_JS` 访问 Shadow DOM 内的发布按钮

**成功判定**：在 Shadow DOM 内找到发布入口按钮

---

### step_02_entry.py — EnterPublishEntryStep

**功能**：进入视频或图文发布页面。

**执行逻辑**：
- `file_type == "video"`：通过 JS 穿透 Shadow DOM 点击「发表视频」按钮（`PUBLISH_VIDEO_BTN`）
- `file_type == "image"`：通过 JS 穿透 Shadow DOM 点击「发表图文」按钮（`PUBLISH_IMAGE_BTN`）
- 等待 URL 跳转到 `/post/create`
- 等待发布页上传区域加载完成

**关键字段**：`metadata["file_type"]`（`"video"` 或 `"image"`）

**Shadow DOM 特性**：使用 `shadow_mouse.py` 中的工具函数获取按钮坐标后执行真实鼠标点击

---

### step_03_upload.py — UploadMediaStep

**功能**：上传视频或图片文件。

**执行逻辑**：
- 通过 Shadow DOM 内的 file input 或 file chooser 机制上传文件
- 轮询等待 Shadow DOM 内出现「删除」类操作按钮，表示上传成功（`UPLOAD_SUCCESS_MARKER` = 「删除」按钮出现）
- 支持视频和图片两种上传方式

**成功判定**：Shadow DOM 内出现「删除」按钮（表示文件已上传并可管理）

---

### step_04_cover.py — CoverSettingStep

**功能**：封面设置（自定义封面或首帧默认）。

**cover_type 分支**：

**首帧封面（默认，`cover_type != "custom"` 或 `cover_path` 为空）**：
- 直接跳过，视频上传后平台自动选取首帧，无需操作

**本地封面（`cover_type == "custom"` 且 `cover_path` 有值）**：
1. 通过 JS 穿透 Shadow DOM，点击「个人主页和分享卡片(3:4)」封面入口
2. 等待「编辑封面」弹窗出现（轮询最多 5 秒）
3. 在 **弹窗 scope（COVER_DIALOG）子树内** 上传封面（通过 file input 或 file chooser），避免命中其它弹窗
4. 等待 2 秒后，仅在弹窗子树内点击「确认」按钮
5. 验证弹窗已关闭（最多等 10 秒）

**关键注意**：所有封面元素在 wujie-app Shadow DOM 内，必须使用 JS 穿透操作

**关键字段**：`metadata["cover_type"]`（`"custom"` 或 `"first_frame"`）、`metadata["cover_path"]`

---

### step_05B_description.py — MetadataFillStep

**功能**：在 Shadow DOM 内填写描述内容和话题标签。

**执行逻辑**：
- 定位 Shadow DOM 内的 `contenteditable` 富文本框
- 若有描述内容，依次写入正文和 `#话题` 标签
- 输入方式：通过 JavaScript 注入或 Playwright 键盘事件写入富文本编辑器

**关键字段**：`metadata["description"]`、`metadata["tags"]`

**平台限制**：
- 描述：最长 1000 字
- 话题：最多 3 个

---

### step_06_location.py — LocationSettingStep

**功能**：位置信息设置（条件执行）。

**执行逻辑**：
- 若配置了具体位置（`poi`）：当前步骤返回失败并报错「POI 位置挂载尚未实现」，防止带错误配置继续发布
- 若未配置位置：按配置选择「不显示位置」，或直接跳过不操作

**关键字段**：`metadata["poi"]`、`metadata["location_visible"]`（可配置是否显示位置区域）

---

### step_07_link.py — LinkSettingStep

**功能**：商品链接/购物车挂载（条件执行）。

**执行逻辑**：
- `metadata["cart_info"]` 非空时：在 Shadow DOM 内操作商品搜索，挂载商品链接
- 无配置时直接跳过

**关键字段**：`metadata["cart_info"]`

---

### step_08B_schedule.py — ScheduleSettingStep

**功能**：定时发表设置（条件执行）。

**执行逻辑**：
- `scheduled_publish_time` 为空时直接跳过（立即发布）
- 有定时时间时：
  1. 在 Shadow DOM 内找到定时发表选项并点击
  2. 使用日历组件填写日期（可信鼠标点击）
  3. 填写时和分
  4. 等待定时设置生效

**关键字段**：`metadata["scheduled_publish_time"]`

---

### step_08C_short_title.py — ShortTitleStep

**功能**：填写短标题（条件执行）。

**执行逻辑**：
- `title` 为空时直接跳过
- 有标题时：对标题字符串进行规范化处理（长度裁剪为 6-16 字符等规则），在 Shadow DOM 内的短标题输入框中填入

**短标题规则**：
- 长度要求：6-16 字
- 需过滤特殊字符，确保符合平台要求

**关键字段**：`metadata["title"]`

---

### step_08D_original.py — OriginalDeclareStep

**功能**：声明原创（条件执行）。

**触发条件**：`metadata["is_original"]` 为 `True` 时执行（支持多种格式：布尔值、字符串 `"true"/"1"/"yes"`）。

**执行逻辑（精细鼠标点击方案）**：
1. 幂等检查：若「声明原创」复选框已勾选，直接返回成功
2. 通过 `shadow_mouse.py` 获取主区域原创复选框坐标，**执行真实鼠标点击**（`page.mouse.click(x, y)`）
3. 等待「原创权益」弹窗出现
4. 在弹窗内找到协议复选框，**真实鼠标点击** `span.ant-checkbox`（优先 span 元素，避免仅点隐藏 input 导致 Vue 不响应）
5. **真实鼠标点击**弹窗中的「声明原创」确认按钮
6. 协议未勾选时重试；确认后等待弹窗关闭
7. 成功判据：主区域复选框保持勾选状态且弹窗已关闭

**关键技术点**：wujie + Vue/Ant Design 环境下，`evaluate` 内 `el.click()` 会导致假勾选（Vue 响应式数据不触发），因此必须使用 `page.mouse.click` 真实鼠标坐标点击。

**关键字段**：`metadata["is_original"]`（或 `metadata["privacy_settings"]["is_original"]`，支持嵌套 JSON）

---

### step_09_submit.py — SubmitStep

**功能**：点击「发表」按钮，验证发布成功。

**执行逻辑**：
1. 等待 Shadow DOM 内「发表」按钮变为可用（非 disabled 状态）
2. 偏右侧真实鼠标点击「发表」按钮（避免 Shadow DOM 内 Vue 事件响应问题）
3. 处理可能出现的错误提示或频控弹窗
4. 验证成功：URL 跳转、Toast 出现、或管理页特征 DOM 可见

**关键注意**：同样需要通过 Shadow DOM 穿透找到按钮坐标，然后使用真实鼠标点击

## 5. StepRunner 执行引擎

位于 `steps/step_runner.py`，与抖音/快手架构一致：

- **顺序执行**：对外统一 9 个阶段（步骤），内部子步骤按列表顺序依次执行
- **用户日志前缀**：各步骤内 `publish.user_log` 应使用 `BasePublishStep._step_prefix(metadata, 中文名)`，与 Runner 注入的 `[步骤X/9 …]` 一致，避免硬编码 `/11` 等旧分母
- **步骤重试**：每步最多 3 次，失败间隔 1.5 秒
- **NeedsAction 补救**：`need_supplement` 映射 → 重新执行 `[SubmitStep()]`

```python
runner = StepRunner(
    page=page,
    file_path=file_path,
    metadata=metadata,
    config=RunnerConfig(
        max_step_retries=3,
        step_retry_delay_seconds=1.5,
        max_submit_retries=2,
    ),
    action_handlers={
        "need_supplement": lambda: [SubmitStep()],
    },
)
```

失败时 `GenericStepRunner._diagnose()` 生成诊断包（`platform=wechat_video`）。**说明**：当前 `publish_plugin.py` **尚未**向 `metadata` 注入 `selector_probes`，故 `selector_probes.json` 常为空对象；通用文件（截图、HTML、dom_snapshot）仍会写入。建议后续补充 wujie/发表钮等探针键。详见 §9。

## 7. 表单字段（FormSchema）

`get_form_schema(content_type)` 返回的字段：

| 字段名 | 类型 | 必填 | 限制 | 说明 |
|--------|------|------|------|------|

| `scheduled_publish_time` | datetime | 否 | — | 定时发布时间 |
| `cart_info` | text | 否 | — | 商品挂载信息 |

## 8. 发布流程图

```
开始
  │
  ▼
step_01: 导航到视频号创作者中心
         ├── 检测登录态（URL跳转到login则报失效）
         └── Shadow DOM内轮询「发表视频」按钮就绪
  │
  ▼
step_02: 进入发布页
         ├── [video] Shadow DOM内点击「发表视频」
         └── [image] Shadow DOM内点击「发表图文」
         等待跳转到 /post/create
  │
  ▼
step_03: 上传媒体文件
         等待Shadow DOM内「删除」按钮出现 = 上传成功
  │
  ▼
step_04: 封面设置
         ├── [first_frame] 跳过（平台自动用首帧）
         └── [custom] JS穿透Shadow DOM进入封面弹窗上传
  │
  ▼
step_05: 填写描述和话题（Shadow DOM内富文本框）
  │
  ▼
step_06: 位置设置 ─[poi有值]─▶ 报错（未实现）
          └─[无位置]─▶ 选「不显示」或跳过
  │
  ▼
step_07: 链接/商品挂载 ─[cart_info有值]─▶ Shadow DOM内操作
          └─[无配置]─▶ 跳过
  │
  ▼
step_08: 高级设置
          ├─[图文]─▶ 背景音乐（占位）+ 定时设置（scheduled_publish_time）
          └─[视频]─▶ 定时设置（scheduled_publish_time）+ 短标题（title）+ 原创声明（is_original）
  │
  ▼
step_09: 点击「发表」（真实鼠标点击Shadow DOM内按钮）
          ├── [成功] URL跳转 / Toast确认
          └── [NeedsAction] need_supplement → 重试SubmitStep
```

## 9. 发布失败诊断

通用机制见 [3.1 第 5.5 节](../3.1插件系统标准化目录及结构.md)、[3.2 第 6.1 节](../3.2插件选择器标准化规范.md)。

**存储路径**：`%LOCALAPPDATA%\WeMediaBaby\debug\diagnostics\wechat_video\<YYYYMMDD>\<HHMMSS>_<StepName>_<reasonHash>/`

**通用文件**：与其它平台相同。因发布页在 `wujie-app` **Shadow DOM** 内，`dom_snapshot.json` 可能无法列出 Shadow 内全部控件，须结合 `screenshot.png` 与步骤内 Shadow 穿透日志排查。

**selector_probes**：当前未在 `publish_plugin.py` 配置（待补充）。建议探针键示例：`wujie_host`、`shadow_submit_btn`、`schedule_panel`（与 `selectors.py` 分组对应）。

**排错**：优先看截图与步骤失败日志；对照 [3.2 第 5.1 节](../3.2插件选择器标准化规范.md) Shadow 规范与 `wujie_shadow.py` / `shadow_mouse.py`。

## 10. 与其他平台插件的主要区别

| 特性 | 抖音 | 快手 | 视频号 |
|------|------|------|--------|
| Shadow DOM | 无（标准DOM） | 无（标准DOM） | **全页面 wujie-app Shadow DOM** |
| 点击方式 | 普通 locator.click | 普通 locator.click | **必须 page.mouse.click 真实坐标** |
| 步骤数 | 视频8步/图文9步（两条链） | 12步（单条链） | 9步（统一阶段，含子步骤） |
| 封面设置 | 三种模式（AI/首帧/本地） | 占位未实现 | 首帧跳过/本地上传 |
| 原创声明 | 无 | 无 | 有（步骤8D，条件执行） |
| 短标题 | 无 | 无 | 有（步骤8C，6-16字，条件执行） |
| 视频和图文 | 两套步骤链 | 共用一套 | 共用一套，步骤2入口不同 |
