## 2. Shadow DOM 架构说明

视频号创作者发布页大量使用 `wujie-app` 微前端框架，页面内容被封装在 **Shadow DOM** 中，常规 CSS 选择器无法直接访问。

### 2.1 Shadow DOM 穿透方式

所有步骤通过 `wujie_shadow.py` 提供的 `WUJIE_SHADOW_ROOT_JS` 常量穿透 Shadow DOM：

```javascript
// 降级路径顺序（优先完整路径，兜底遍历所有 wujie-app）
var paths = [
    '#container-wrap > ... > wujie-app',
    '#container-wrap > ... > wujie-app'  // 备用路径
];
// 最后兜底：遍历页面所有 wujie-app 元素
var all = document.querySelectorAll('wujie-app');
```

### 2.2 关键工具模块

| 模块 | 用途 |
|------|------|
| `wujie_shadow.py` | 提供 `WUJIE_SHADOW_ROOT_JS`（获取 shadow root）和 `WUJIE_SHADOW_QUERY_SELECTOR_FN_JS`（shadow 内 querySelector） |
| `shadow_mouse.py` | 提供 `get_shadow_el_center`、`real_mouse_click_xy`、`shadow_eval_center`，用于获取 Shadow DOM 内元素坐标后执行真实鼠标点击 |

### 2.3 为什么不能用普通点击

由于视频号使用 `wujie` + `Vue/Ant Design` 组件，`page.evaluate` 内的 `el.click()` 可能导致**假勾选**（Vue 响应式数据不触发）。关键操作（如声明原创的复选框、确认按钮）**必须使用 `page.mouse.click(x, y)` 真实鼠标点击**，不能用 JavaScript 注入点击。

## 3. 步骤链组装逻辑

### 3.1 统一步骤链（视频与图文共用）

视频号插件采用**单一步骤链**，共 **11 个步骤**。视频和图文发布使用完全相同的步骤列表，差异通过步骤2（点击不同按钮）和步骤3（上传不同类型文件）体现。

```
步骤1   NavigateHomeStep        → 导航到视频号创作者服务中心
步骤2   EnterPublishEntryStep   → 进入视频/图文发布页
步骤3   UploadMediaStep         → 上传视频/图片文件
步骤4   CoverSettingStep        → 封面设置（自定义封面或首帧跳过）
步骤5   MetadataFillStep        → 填写描述和话题
步骤6   LocationSettingStep     → 位置设置（条件执行）
步骤7   LinkSettingStep         → 链接/商品挂载（条件执行）
步骤8   ScheduleSettingStep     → 定时发表设置（条件执行）
步骤9   ShortTitleStep          → 短标题填写（条件执行）
步骤10  OriginalDeclareStep     → 声明原创（条件执行）
步骤11  SubmitStep              → 点击发表
```

`publish_plugin.py` 中组装代码：

```python
steps = [
    NavigateHomeStep(),       # 步骤1:  进入创作者服务中心
    EnterPublishEntryStep(),  # 步骤2:  查找发布入口并进入
    UploadMediaStep(),        # 步骤3:  上传视频/图片
    CoverSettingStep(),       # 步骤4:  封面设置
    MetadataFillStep(),       # 步骤5:  填写描述
    LocationSettingStep(),    # 步骤6:  位置设置
    LinkSettingStep(),        # 步骤7:  链接设置
    ScheduleSettingStep(),    # 步骤8:  定时发表设置
    ShortTitleStep(),         # 步骤9:  短标题
    OriginalDeclareStep(),    # 步骤10: 声明原创
    SubmitStep(),             # 步骤11: 点击发布
]
```

### 3.2 视频与图文的差异

| 步骤 | 视频场景 | 图文场景 | 差异说明 |
|------|---------|---------|---------|
| EnterPublishEntryStep | 点击「发表视频」按钮（`PUBLISH_VIDEO_BTN`） | 点击「发表图文」按钮（`PUBLISH_IMAGE_BTN`） | 入口按钮不同 |
| UploadMediaStep | 上传视频文件 | 上传图片文件 | 读取 `file_type` 记录日志，上传逻辑相同 |
| 其余步骤 | — | — | 完全相同，均通过字段是否为空决定是否执行 |

## 4. 各步骤详细说明

### step_01_home.py — NavigateHomeStep

**功能**：导航到视频号创作者服务中心，检测登录状态。

**执行逻辑**：
1. `page.goto("https://channels.weixin.qq.com/platform", wait_until="domcontentloaded")`
2. 检测 URL 是否跳转到登录页（`/login`），若是则报 Cookie 失效
3. 检测风控弹窗（`Selectors.SECURITY.RISK_MODAL`）
4. 等待 `networkidle`，确保页面加载完成
5. **穿透 wujie-app Shadow DOM** 轮询检测「发表视频」按钮（最多 10 次，每次间隔 1 秒）
6. 找到按钮后写入 `metadata['_publish_btn_ready'] = True`，供步骤2快速使用

**Shadow DOM 穿透**：必须通过 JavaScript + `WUJIE_SHADOW_ROOT_JS` 访问 Shadow DOM 内的发布按钮

**成功判定**：在 Shadow DOM 内找到发布入口按钮

---

### step_02_entry.py — EnterPublishEntryStep

**功能**：进入视频或图文发布页面。

**执行逻辑**：
- `file_type == "video"`：通过 JS 穿透 Shadow DOM 点击「发表视频」按钮（`PUBLISH_VIDEO_BTN`）
- `file_type == "image"`：通过 JS 穿透 Shadow DOM 点击「发表图文」按钮（`PUBLISH_IMAGE_BTN`）
- 等待 URL 跳转到 `/post/create`
- 等待发布页上传区域加载完成

**关键字段**：`metadata["file_type"]`（`"video"` 或 `"image"`）

**Shadow DOM 特性**：使用 `shadow_mouse.py` 中的工具函数获取按钮坐标后执行真实鼠标点击

---

### step_03_upload.py — UploadMediaStep

**功能**：上传视频或图片文件。

**执行逻辑**：
- 通过 Shadow DOM 内的 file input 或 file chooser 机制上传文件
- 轮询等待 Shadow DOM 内出现「删除」类操作按钮，表示上传成功（`UPLOAD_SUCCESS_MARKER` = 「删除」按钮出现）
- 支持视频和图片两种上传方式

**成功判定**：Shadow DOM 内出现「删除」按钮（表示文件已上传并可管理）

---

### step_04_cover.py — CoverSettingStep

**功能**：封面设置（自定义封面或首帧默认）。

**cover_type 分支**：

**首帧封面（默认，`cover_type != "custom"` 或 `cover_path` 为空）**：
- 直接跳过，视频上传后平台自动选取首帧，无需操作

**本地封面（`cover_type == "custom"` 且 `cover_path` 有值）**：
1. 通过 JS 穿透 Shadow DOM，点击「个人主页和分享卡片(3:4)」封面入口
2. 等待「编辑封面」弹窗出现（轮询最多 5 秒）
3. 在 **弹窗 scope（COVER_DIALOG）子树内** 上传封面（通过 file input 或 file chooser），避免命中其它弹窗
4. 等待 2 秒后，仅在弹窗子树内点击「确认」按钮
5. 验证弹窗已关闭（最多等 10 秒）

**关键注意**：所有封面元素在 wujie-app Shadow DOM 内，必须使用 JS 穿透操作

**关键字段**：`metadata["cover_type"]`（`"custom"` 或 `"first_frame"`）、`metadata["cover_path"]`

---

### step_05_description.py — MetadataFillStep

**功能**：在 Shadow DOM 内填写描述内容和话题标签。

**执行逻辑**：
- 定位 Shadow DOM 内的 `contenteditable` 富文本框
- 若有描述内容，依次写入正文和 `#话题` 标签
- 输入方式：通过 JavaScript 注入或 Playwright 键盘事件写入富文本编辑器

**关键字段**：`metadata["description"]`、`metadata["tags"]`

**平台限制**：
- 描述：最长 1000 字
- 话题：最多 3 个

---

### step_06_location.py — LocationSettingStep

**功能**：位置信息设置（条件执行）。

**执行逻辑**：
- 若配置了具体位置（`poi`）：当前步骤返回失败并报错「POI 位置挂载尚未实现」，防止带错误配置继续发布
- 若未配置位置：按配置选择「不显示位置」，或直接跳过不操作

**关键字段**：`metadata["poi"]`、`metadata["location_visible"]`（可配置是否显示位置区域）

---

### step_07_link.py — LinkSettingStep

**功能**：商品链接/购物车挂载（条件执行）。

**执行逻辑**：
- `metadata["cart_info"]` 非空时：在 Shadow DOM 内操作商品搜索，挂载商品链接
- 无配置时直接跳过

**关键字段**：`metadata["cart_info"]`

---

### step_08_schedule.py — ScheduleSettingStep

**功能**：定时发表设置（条件执行）。

**执行逻辑**：
- `scheduled_publish_time` 为空时直接跳过（立即发布）
- 有定时时间时：
  1. 在 Shadow DOM 内找到定时发表选项并点击
  2. 使用日历组件填写日期（可信鼠标点击）
  3. 填写时和分
  4. 等待定时设置生效

**关键字段**：`metadata["scheduled_publish_time"]`

---

### step_09_short_title.py — ShortTitleStep

**功能**：填写短标题（条件执行）。

**执行逻辑**：
- `title` 为空时直接跳过
- 有标题时：对标题字符串进行规范化处理（长度裁剪为 6-16 字符等规则），在 Shadow DOM 内的短标题输入框中填入

**短标题规则**：
- 长度要求：6-16 字
- 需过滤特殊字符，确保符合平台要求

**关键字段**：`metadata["title"]`

---

### step_10_original.py — OriginalDeclareStep

**功能**：声明原创（条件执行）。

**触发条件**：`metadata["is_original"]` 为 `True` 时执行（支持多种格式：布尔值、字符串 `"true"/"1"/"yes"`）。

**执行逻辑（精细鼠标点击方案）**：
1. 幂等检查：若「声明原创」复选框已勾选，直接返回成功
2. 通过 `shadow_mouse.py` 获取主区域原创复选框坐标，**执行真实鼠标点击**（`page.mouse.click(x, y)`）
3. 等待「原创权益」弹窗出现
4. 在弹窗内找到协议复选框，**真实鼠标点击** `span.ant-checkbox`（优先 span 元素，避免仅点隐藏 input 导致 Vue 不响应）
5. **真实鼠标点击**弹窗中的「声明原创」确认按钮
6. 协议未勾选时重试；确认后等待弹窗关闭
7. 成功判据：主区域复选框保持勾选状态且弹窗已关闭

**关键技术点**：wujie + Vue/Ant Design 环境下，`evaluate` 内 `el.click()` 会导致假勾选（Vue 响应式数据不触发），因此必须使用 `page.mouse.click` 真实鼠标坐标点击。

**关键字段**：`metadata["is_original"]`（或 `metadata["privacy_settings"]["is_original"]`，支持嵌套 JSON）

---

### step_11_submit.py — SubmitStep

**功能**：点击「发表」按钮，验证发布成功。

**执行逻辑**：
1. 等待 Shadow DOM 内「发表」按钮变为可用（非 disabled 状态）
2. 偏右侧真实鼠标点击「发表」按钮（避免 Shadow DOM 内 Vue 事件响应问题）
3. 处理可能出现的错误提示或频控弹窗
4. 验证成功：URL 跳转、Toast 出现、或管理页特征 DOM 可见

**关键注意**：同样需要通过 Shadow DOM 穿透找到按钮坐标，然后使用真实鼠标点击

## 5. StepRunner 执行引擎

位于 `steps/step_runner.py`，与抖音/快手架构一致：

- **顺序执行**：11 步按列表顺序依次执行
- **步骤重试**：每步最多 3 次，失败间隔 1.5 秒
- **NeedsAction 补救**：`need_supplement` 映射 → 重新执行 `[SubmitStep()]`

```python
runner = StepRunner(
    page=page,
    file_path=file_path,
    metadata=metadata,
    config=RunnerConfig(
        max_step_retries=3,
        step_retry_delay_seconds=1.5,
        max_submit_retries=2,
    ),
    action_handlers={
        "need_supplement": lambda: [SubmitStep()],
    },
)
```

## 9. 与其他平台插件的主要区别

| 特性 | 抖音 | 快手 | 视频号 |
|------|------|------|--------|
| Shadow DOM | 无（标准DOM） | 无（标准DOM） | **全页面 wujie-app Shadow DOM** |
| 点击方式 | 普通 locator.click | 普通 locator.click | **必须 page.mouse.click 真实坐标** |
| 步骤数 | 视频8步/图文9步（两条链） | 12步（单条链） | 11步（单条链） |
| 封面设置 | 三种模式（AI/首帧/本地） | 占位未实现 | 首帧跳过/本地上传 |
| 原创声明 | 无 | 无 | 有（步骤10） |
| 短标题 | 无 | 无 | 有（步骤9，6-16字） |
| 视频和图文 | 两套步骤链 | 共用一套 | 共用一套，步骤2入口不同 |
