## 2. 步骤链组装逻辑

视频发布与图文发布均为 **8 个主步骤**。步骤6由若干子步骤构成，子步骤内部根据字段配置自行决定是否执行，对外仍视为一个步骤位置。

### 2.1 视频发布（file_type == "video"）

```
步骤1  NavigateHomeStep        → 导航到创作者首页
步骤2  EnterPublishEntryStep   → 进入视频发布页
步骤3  UploadMediaStep         → 上传视频文件
步骤4  MetadataFillStep        → 填写标题和描述
步骤5  CoverVideoStep          → 设置视频封面
步骤6  ExtraInfoCommonStep     → 添加标签（POI/团购/购物车/小程序）
       TrendingStep            → 关联热点（占位，待实现）
步骤7  PublishSettingsStep     → 设置发布权限和时间
步骤8  SubmitStep              → 提交发布
```

### 2.2 图文发布（file_type == "image"）

```
步骤1  NavigateHomeStep        → 导航到创作者首页
步骤2  EnterPublishEntryStep   → 进入图文发布页
步骤3  UploadMediaStep         → 上传图片（支持多图）
步骤4  MetadataFillStep        → 填写标题和描述
步骤5  CoverImageStep          → 图文封面设置（通常跳过 DOM 操作）
步骤6  SelectMusicStep         → 选择背景音乐（可选）
       ExtraInfoCommonStep     → 添加标签（POI/团购/购物车/小程序）
       TrendingStep            → 关联热点（占位，待实现）
步骤7  PublishSettingsStep     → 设置发布权限和时间
步骤8  SubmitStep              → 提交发布
```

### 2.3 步骤6 子步骤分布

| 子步骤 | 类名 | 视频 | 图文 | 说明 |
|--------|------|:----:|:----:|------|

| step_06b_extra_info.py | `ExtraInfoCommonStep` | ✓ | ✓ | 无配置则跳过并关闭弹窗 |
| step_06c_trending.py | `TrendingStep` | ✓ | ✓ | 占位，当前直接跳过 |

## 3. 各步骤详细说明

### step_01_home.py — NavigateHomeStep

**功能**：导航到抖音创作者首页，确认登录状态。

**执行逻辑**：
- `page.goto("https://creator.douyin.com/creator-micro/home")`
- 检测风控弹窗（`RISK_MODAL` 选择器），若存在则等待人工处理
- 扫描页面文案判断是否已登录（检测「扫码登录」「登录」等关键词）
- 确认当前 URL 包含 `creator.douyin.com`

**关键选择器**：`RISK_MODAL`

**成功判定**：URL 确认在创作者域名，无登录弹窗

---

### step_02_entry.py — EnterPublishEntryStep

**功能**：从首页进入对应类型的发布页面。

**执行逻辑**：
- 根据 `metadata["file_type"]` 选择点击「发布视频」或「发布图文」按钮
- 等待 URL 跳转到发布页
- 轮询发布页特征 DOM 元素（发布页 markers）
- 若需要，进行 Tab 切换（视频/图文页签）

**关键字段**：`metadata["file_type"]`（`"video"` 或 `"image"`）

**成功判定**：URL 跳转成功，发布页特征元素可见

---

### step_03_upload.py — UploadMediaStep

**功能**：上传视频或图片文件。

**执行逻辑**：
- **视频**：定位 `FILE_INPUT`，调用 `set_input_files` 传入视频路径，轮询 `VIDEO_UPLOAD_SUCCESS_MARKER`（出现「重新上传」文案说明上传成功）
- **图文**：定位 `IMAGE_FILE_INPUT`，支持多图上传，等待 `IMAGE_UPLOAD_SUCCESS_MARKER`（出现「已添加N张图片」+「继续添加」按钮）
- 上传超时默认约 180 秒

**关键选择器**：`FILE_INPUT`、`IMAGE_FILE_INPUT`、`VIDEO_UPLOAD_SUCCESS_MARKER`、`IMAGE_UPLOAD_SUCCESS_MARKER`

**成功判定**：检测到对应上传成功标记元素可见

---

### step_04_description.py — MetadataFillStep

**功能**：填写作品标题和描述内容（含话题）。

**执行逻辑**：
- 对话题（`#话题`）进行预处理（去重、规范化间距）
- 定位 `TITLE_INPUT`，使用 `human_type_text` 拟人方式输入标题
- 定位 `DESC_EDITOR`（富文本编辑器），逐字输入描述内容
- 话题使用 `#` 前缀方式插入，输入后验证 `innerText` 非空
- 有标题字段但找不到输入框时，直接返回失败

**关键字段**：`metadata["title"]`、`metadata["description"]`

**关键选择器**：`TITLE_INPUT`、`DESC_EDITOR`

**平台限制**：
- 标题：最长 55 字
- 描述：最长 500 字
- 话题：最多 10 个

---

### step_05_cover_video.py — CoverVideoStep（视频专用）

**功能**：为视频设置封面（支持三种模式）。

**cover_type 分支**：

**AI 推荐模式（`cover_type = "ai"`）**：
- 在页面主区域「AI智能推荐封面」红框内，直接点击第一个推荐缩略图（`COVER_AI_RECOMMEND_FIRST`）
- 不进入弹窗，等待主页面出现「封面效果检测通过」

**首帧/本地模式（`cover_type = "first_frame"` 或 `"custom"`）**：
1. 点击「选择封面」入口（`COVER_BTN`）打开封面弹窗
2. 弹窗内若出现「设置竖封面获更多流量」推广弹窗，先关闭
3. 在弹窗 scope 内点击「设置横封面」按钮（`COVER_HORIZONTAL_BTN`）
4. 点击「完成」按钮（`COVER_CONFIRM_BTN`）
5. 等待主页面「封面效果检测通过」（`COVER_SUCCESS_INDICATOR`）

**本地上传（`cover_type = "custom"`，有 `cover_path`）**：
- 弹窗内点击「上传封面」，通过 `COVER_FILE_INPUT` 上传本地图片
- 再依次点击「设置横封面」→「完成」

**成功判定**：
- 主页面出现「封面效果检测通过」（`COVER_SUCCESS_INDICATOR`）
- 或出现「X封面存在N个问题」（有质量提醒但已上传，仍视为成功）
- 若出现「横/竖双封面缺失」（`COVER_MISSING_INDICATOR`），判定失败

**关键字段**：`metadata["cover_type"]`（`"ai"` / `"first_frame"` / `"custom"`）、`metadata["cover_path"]`

---

### step_05_cover_image.py — CoverImageStep（图文专用）

**功能**：图文发布的封面设置（多数情况下无需操作）。

**执行逻辑**：
- 默认情况下（未配置 `image_cover_interactive`）直接跳过 DOM 操作，返回成功
- 配置了交互模式时：
  - `custom` + 路径：弹窗内上传本地封面
  - `ai`：点击 AI 推荐封面
  - `first_image`：选择第一张图作为封面（按 ref 排序）

---

### step_06a_music.py — SelectMusicStep（图文专用）

**功能**：为图文内容选择背景音乐（可选步骤）。

**触发条件**：`music_keyword`、`music_name`、`music_category` 三者任意一个有值则执行；均为空则直接跳过。

**执行逻辑**：
1. 检测「修改音乐」文案是否已存在，有则跳过（幂等）
2. 滚动扩展信息区入视口
3. 点击「选择音乐」打开右侧抽屉面板
4. 若配置 `music_category`，切换对应分类标签页（推荐/热门榜/收藏/纯音乐等）
5. 若配置 `music_keyword`，在搜索框输入关键词并回车
6. 等待列表出现使用量或时长信号（`\d+万人使用` / `00:\d{2}`）
7. 若配置 `music_name`，按精确→含包含→正则三级匹配定位目标行；否则取第一条
8. hover 目标行约 2s 后出现「使用」按钮，点击
9. 等待「修改音乐」文案出现，成功后日志记录已选歌曲名称

**关键字段**：
- `metadata["music_keyword"]`：搜索关键词
- `metadata["music_name"]`：指定歌曲名称（精确/模糊匹配）
- `metadata["music_category"]`：分类标签页文案（如 `热门榜`、`纯音乐`）
- `metadata["music_use_hover_ms"]`：hover 等待毫秒数，默认 2200
- `metadata["skip_select_music"]`：`True` 时整步跳过

**关键选择器**：`MUSIC_ENTRY_SELECT`、`MUSIC_ENTRY_MODIFY`、`MUSIC_PANEL_SEARCH_INPUT`、`MUSIC_PANEL_TABS`、`MUSIC_USE_BTN`、`MUSIC_SELECTED_NAME`

---

### step_06b_extra_info.py — ExtraInfoCommonStep（视频/图文共用）

**功能**：处理补充信息弹窗，按需填写位置/商品/小程序等扩展标签。

**执行逻辑**：
1. 关闭「补充信息」引导弹窗（若出现）
2. 滚动到扩展信息区域
3. 按优先级选择一种信息类型填写：
   - `poi_info`（位置信息）> `anchor_info`（团购）> `cart_info`（购物车）> `micro_app_info`（小程序）

**关键字段**：`metadata["poi_info"]`、`metadata["anchor_info"]`、`metadata["cart_info"]`、`metadata["micro_app_info"]`

### step_07_settings.py — PublishSettingsStep

**功能**：配置发布设置（可见性、保存权限、发布时间）。

**执行逻辑**：
- 滚动到页面底部的设置区域
- 设置「谁可以看」权限（radio 按钮）
- 设置「保存权限」
- 发布时间：
  - 立即发布：无需额外操作
  - 定时发布：读取 `schedule_time` 或 `scheduled_publish_time`，分段填写年月日时分

**关键字段**：`metadata["schedule_time"]`、`metadata["scheduled_publish_time"]`

---

### step_08_submit.py — SubmitStep

**功能**：点击发布按钮，验证发布成功。

**执行逻辑**：
1. 通过 role 选择器和 `SUBMIT_BTN` 定位发布按钮
2. 等待按钮变为可点击状态（非 disabled）
3. 多级点击降级策略（`_click_submit_with_fallback`）：普通点击 → 强制点击
4. 检测成功标志：
   - URL 跳转到内容管理页
   - 出现成功 Toast
5. 若失败，返回 `NeedsAction`（封面/补充信息）触发 StepRunner 补救

**NeedsAction 补救映射**：

| 触发条件 | 视频补救步骤 | 图文补救步骤 |
|---------|-------------|-------------|
| `need_cover` | `CoverVideoStep` | `CoverImageStep` |
| `need_supplement` | `ExtraInfoCommonStep` | `SelectMusicStep` + `ExtraInfoCommonStep` |

## 4. StepRunner 执行引擎

位于 `steps/step_runner.py`，核心能力：

- **顺序执行**：按 `steps` 列表依次执行每个步骤
- **步骤重试**：每步最多重试 `max_step_retries` 次（默认 3 次），失败间隔 `step_retry_delay_seconds`
- **NeedsAction 补救**：`SubmitStep` 返回 `NeedsAction` 时，从 `action_handlers` 映射中找对应的补救步骤链执行，之后继续重试提交
- **日志阶段**：`MAIN_PHASES` 按阶段映射用户日志前缀（如 `[步骤5/8 视频封面]`）
- **防风控钩子**：`optional_browse_before_action`（步骤前随机浏览）、`step_interval`（步骤间等待）

```python
runner = StepRunner(
    page=page,
    file_path=file_path,
    metadata=metadata,
    config=RunnerConfig(
        max_step_retries=3,
        step_retry_delay_seconds=1.5,
        max_submit_retries=2,
    ),
    action_handlers=action_handlers,
)
result = await runner.run(steps)
```

## 5. 选择器策略

选择器定义在 `selectors.py`，采用分层策略：

- **L1（最优先）**：`get_by_role`、`get_by_placeholder`、`get_by_text` 等语义选择器（稳定性最高）
- **L2**：CSS 类名选择器（如 `div.cover-Jg3T4p`、`input[placeholder='搜索音乐']`）
- **L3（兜底）**：`[ref=eXXX]` 抖音 DOM ref 属性（会话内临时值，仅作最后备选）

所有步骤均按优先级遍历选择器列表，取第一个命中的可见元素。弹窗内操作必须在弹窗 scope（`Locator`）内定位，避免误触主页面元素。

## 6. 防风控配置

从 `config/platforms/douyin.json` 的 `anti_risk` 节读取，主要配置项：

| 字段 | 说明 |
|------|------|
| `operation_delay_range` | 每次操作前随机延迟范围（秒） |
| `typing_interval_range` | 拟人输入的每键间隔范围（毫秒） |
| `scroll_before_action` | 操作前是否随机滚动 |
| `pause_on_risk_modal` | 检测到风控弹窗时暂停等待人工处理 |

`human_type_text`、`human_click` 等工具函数封装在 `src/infrastructure/anti_risk/human_like.py`。

## 8. 发布流程图

```
开始
  │
  ▼
步骤1: 导航到创作者首页（检测登录/风控）
  │
  ▼
步骤2: 进入发布页（视频/图文 按 file_type 分支）
  │
  ▼
步骤3: 上传媒体文件（视频 或 多图）
  │
  ▼
步骤4: 填写标题和描述
  │
  ├─[video]─▶ 步骤5: 设置视频封面（ai/首帧/本地上传）
  │                │
  │                ▼
  │           步骤6: 扩展信息
  │                ├─ step_06b: 添加标签（POI/团购/购物车/小程序）
  │                └─ step_06c: 关联热点（占位）
  │
  └─[image]─▶ 步骤5: 图文封面（通常跳过）
                   │
                   ▼
              步骤6: 扩展信息
                   ├─ step_06a: 选择背景音乐（可选）
                   ├─ step_06b: 添加标签（POI/团购等）
                   └─ step_06c: 关联热点（占位）
  │
  ▼
步骤7: 发布设置（可见性/定时）
  │
  ▼
步骤8: 提交发布
  │
  ├─[成功]─▶ URL跳转管理页 / Toast确认
  │
  └─[NeedsAction]─▶ 执行补救步骤 ─▶ 重试提交
```
