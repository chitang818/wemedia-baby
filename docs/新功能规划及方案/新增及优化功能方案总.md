## 一、当前已落地或已接入主线的优化

- **版本与发行模式**：当前代码基准为 1.4.3，发行模式读取顺序为 APP_DIST_MODE > config/dist_mode.json，当前工作区 dist_mode.json 为 PRO。
- **页面懒加载与导航**：主窗口导航由 NavigationConfig 管理，PageFactory 按需导入页面，Pro 页面可缺失并在打开时降级提示。
- **真实 Chrome 浏览器策略**：默认 browser_trust_mode=real_browser，发布默认可见浏览器；compat_stealth 保留为兼容模式。
- **小红书账号登录专项**：新增普通 Chrome 打开、关闭后 Cookie/昵称同步、Profile 占用检测与相关单测。
- **发布诊断**：通用诊断包支持截图、HTML、DOM 摘要、metadata，小红书扩展环境快照与按钮状态分析。
- **发布任务字段**：publish_records 已扩展位置、购物车、锚点、小程序、音乐、诊断路径、平台账号 ID、账号组 ID 等字段，并由 schema_migrations 兼容旧库。

## 二、仍需继续推进的事项

- **小红书发布入口接入**：src/plugins/pro/xiaohongshu 代码存在，但 PluginManager.PLUGIN_REGISTRY 仍未注册，正式发布入口需要单独评审。
- **无 CDP/系统真实输入方案**：仍处于方案讨论，尚未进入主发布链路。
- **公开/闭源同步流程**：继续使用 scripts/git/publish_oss_to_public.ps1，禁止直接推 public main。
- **组件规范落地**：新增页面继续复用 AppMessageBoxBase、标准表格模型/视图、RoundMenu 工具和页面 controller。
