## 🌟 软件简介

WeMediaBaby 是一个面向自媒体运营的本地自动化发布工具。它的核心能力是帮你**集中管理多个平台的账号**，并且通过浏览器自动化技术，把你的视频或图文**一键自动分发**到各个创作者平台。

在这个短视频和图文爆发的时代，每个人都可能有几个甚至几十个账号。纯手工发布不仅费时费力，而且容易出错。本软件就是为了消灭这些“机械重复劳动”而生的。

## ✨ 核心功能亮点

1. **多平台账号管理隔离**
   - 采用独立的浏览器指纹和运行环境。
   - 数据完全本地保存（SQLite），每个账号独立文件夹，不怕串号，安全防封。
2. **自动化发布流水线**
   - 支持并发发布，后台静默/半静默运行，不影响电脑正常使用。
   - 完整记录发布日志，成功失败一目了然。
3. **漂亮现代的 UI 界面**
   - 告别简陋的传统辅助工具界面。基于 Fluent Design 风格开发，暗黑/明亮模式丝滑切换，颜值在线！
4. **纯本地化，无数据隐私担忧**
   - 你的账号 Cookie、配置、素材全部存在你自己电脑的 `%LOCALAPPDATA%\WeMediaBaby` 目录下，绝不上传任何云端。

## 🛠 给懂技术的朋友看的（技术栈）

如果你也对 Python 桌面开发或自动化感兴趣，欢迎来看看源码：
- **核心语言**：Python 3.12
- **桌面 UI**：PySide6 + PySide6-Fluent-Widgets (界面极其美观)
- **异步控制**：qasync (完美结合 asyncio 与 Qt 事件循环)
- **自动化核心**：Patchright (高匿名、防风控的浏览器驱动)
- **数据库**：aiosqlite + Tortoise ORM
